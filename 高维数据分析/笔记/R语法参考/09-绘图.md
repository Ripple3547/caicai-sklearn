# 第九章 绘图

## 一、两类绘图函数

base R 的绘图函数分两层。**高级函数**开一张新图并画坐标系，如 `plot()`、`hist()`、`boxplot()`、`barplot()`、`pairs()`；**低级函数**在当前图上叠加元素，如 `points()`、`lines()`、`abline()`、`text()`、`legend()`、`segments()`。顺序必须是先高级后低级，反过来会把已有内容清掉。

```r
plot(mpg ~ wt, data = mtcars,
     pch = 19, col = "steelblue",
     xlab = "车重（千磅）", ylab = "每加仑英里数",
     main = "车重与油耗")
abline(lm(mpg ~ wt, data = mtcars), lty = 2, col = "firebrick")
```

`plot()` 是泛型函数，行为取决于第一个参数的类型：给两个数值向量画散点，给公式 `y ~ x` 按公式画，给数据框画散点图矩阵，给 `lm` 对象画诊断图。`type` 参数控制画法：

| `type` | 含义 |
| :--- | :--- |
| `"p"` | 点（默认） |
| `"l"` | 连线 |
| `"b"` | 点与线，线不穿过点 |
| `"o"` | 点与线，线穿过点 |
| `"h"` | 从 0 到点的垂线 |
| `"s"` / `"S"` | 阶梯线 |
| `"n"` | 只画坐标系，不画内容 |

`"n"` 常用来先定坐标范围，再手工叠加：

```r
plot(mpg ~ wt, data = mtcars, type = "n",
     xlim = c(1.5, 5.5), ylim = c(10, 35))
points(mpg ~ wt, data = mtcars, pch = 21,
       bg = ifelse(mtcars$am == 1, "tomato", "gray70"))
lines(lowess(mtcars$wt, mtcars$mpg), col = "blue", lwd = 2)
legend("topright", legend = c("自动挡", "手动挡"),
       pch = 21, pt.bg = c("gray70", "tomato"))
```

## 二、图形参数

图形参数用 `par()` 设置，或在高级函数里直接作为参数传入（只对那一次调用有效）。最常用的一组：

| 参数 | 作用 | 常用值 |
| :--- | :--- | :--- |
| `pch` | 点的形状 | `19` 实心圆、`21` 可填充圆、`1` 空心圆 |
| `col` | 颜色 | `"red"`、`"#FF0000"`、`2`（调色板序号） |
| `cex` | 缩放倍数 | `0.8` 缩小、`1.5` 放大 |
| `lty` | 线型 | `1` 实线、`2` 虚线、`3` 点线 |
| `lwd` | 线宽 | `2` 加粗 |
| `xlim` / `ylim` | 坐标范围 | `c(0, 10)` |
| `main` / `sub` | 主标题 / 副标题 | 字符串 |
| `xlab` / `ylab` | 轴标签 | 字符串 |
| `las` | 轴刻度文字方向 | `1` 水平、`2` 垂直 |
| `bty` | 边框形状 | `"o"` 全框、`"l"` 左下、`"n"` 无框 |
| `log` | 对数坐标轴 | `"x"`、`"y"`、`"xy"` |
| `asp` | 纵横比 | `1` 表示等比例 |

```r
par(las = 1, bty = "l", mar = c(4, 4, 2, 1))
plot(mpg ~ wt, data = mtcars, pch = 19, cex = 1.2,
     col = rgb(0.2, 0.3, 0.8, 0.7))
```

`pch` 取 21 到 25 时可以用 `bg` 填色、`col` 描边，前面的 `19` 是纯色实心点，没有填充概念。颜色可以用名称（`colors()` 列出全部 657 个）、十六进制、`rgb()`（第四个参数是透明度），或调色板序号。

## 三、一页多图

`par(mfrow = c(2, 2))` 把页面分成 2×2，按行依次填充；`mfcol` 按列填充。设置后一直有效，直到再次修改或关闭设备。画完一组图后把原来的参数存下来再恢复，是避免"后面的图全被挤在小格子里"的标准做法：

```r
op <- par(mfrow = c(1, 2), mar = c(4, 4, 2, 1))
hist(mtcars$mpg, breaks = 10, main = "油耗分布", xlab = "mpg")
boxplot(mpg ~ cyl, data = mtcars, main = "按缸数分组", xlab = "缸数", ylab = "mpg")
par(op)
```

`layout()` 支持不等大的分块，用矩阵指定每块占的位置；`split.screen()` 更灵活但少用。多图布局下，`main` 只作用于当前子图，整页标题用 `mtext(..., outer = TRUE)` 配合 `oma`。

## 四、常用图形

散点图矩阵用 `pairs()`，快速看多个变量两两之间的关系：

```r
pairs(~ mpg + wt + hp + disp, data = mtcars,
      pch = 19, col = rgb(0, 0, 0, 0.4))
```

直方图用 `hist()`，`freq = FALSE` 时纵轴是密度，可以叠加密度曲线；`breaks` 可以是组数、断点向量或 `"FD"` 等规则：

```r
hist(mtcars$mpg, breaks = "FD", freq = FALSE,
     main = "油耗分布与核密度", xlab = "mpg")
lines(density(mtcars$mpg), lwd = 2, col = "firebrick")
```

箱线图用 `boxplot(y ~ g)`。`car` 包的 `Boxplot()` 是增强版，会把离群点标号并返回这些点的标签，作业里常用：

```r
boxplot(mpg ~ cyl, data = mtcars, col = "lightgray",
        xlab = "缸数", ylab = "mpg")
```

条形图用 `barplot()`，输入通常是 `table()` 的结果；`beside = TRUE` 把分组并排，默认堆叠：

```r
counts <- table(mtcars$cyl, mtcars$am)
barplot(counts, beside = TRUE, legend.text = c("自动", "手动"),
        args.legend = list(x = "topright"), xlab = "缸数", ylab = "频数")
```

函数曲线用 `curve()`，它直接接受表达式，画理论密度、回归曲线都方便：

```r
curve(dnorm(x), from = -4, to = 4, lwd = 2,
      xlab = "x", ylab = "密度", main = "标准正态密度")
```

## 五、图例、文字与坐标轴

`legend()` 的第一个参数是位置，可以写 `"topright"`、`"bottomleft"` 等，也可以给坐标。图例内容要和图中元素一一对应，顺序不能错。

```r
plot(mpg ~ wt, data = mtcars, pch = 19,
     col = ifelse(mtcars$am == 1, "tomato", "gray40"),
     xlab = "车重", ylab = "mpg")
abline(h = mean(mtcars$mpg), lty = 3)
text(4.8, 32, "手动挡车型整体更省油", cex = 0.9)
legend("topright", legend = c("自动挡", "手动挡", "总体均值"),
       pch = c(19, 19, NA), lty = c(NA, NA, 3),
       col = c("gray40", "tomato", "black"))
```

坐标轴不满意时，先用 `axes = FALSE` 关掉默认轴，再用 `axis()` 自定义刻度与标签；`mtext()` 在图的四边加文字。`segments()`、`arrows()` 画线段与箭头，`polygon()` 填充区域，`grid()` 加网格线。

## 六、图形设备与保存

R 在交互式窗口里画到屏幕上，在脚本里画到默认设备（通常是 `Rplots.pdf`）。要保存成文件，显式打开设备，画完用 `dev.off()` 关闭：

```r
png(file.path(tempdir(), "scatter.png"),
    width = 900, height = 600, res = 150)
plot(mpg ~ wt, data = mtcars, pch = 19)
dev.off()
```

`png()` 的宽高默认单位是像素，`res` 控制分辨率；`pdf()` 的单位是英寸。`dev.off()` 会关闭当前设备并返回切换到的设备名（交互式会话里通常显示 `null device 1`），看到这类输出是正常的。

> [!warning] 关设备与中文
>
> 忘记 `dev.off()` 会让文件只写了一半或完全为空；循环里每张图都要"开设备—画图—关设备"配对。中文显示按 [[01-环境与常见坑]] 的结论处理：本机默认 `png()` 正常，`pdf()` 要加 `family = "GB1"`，`cairo_pdf()` 要加 `family = "SimSun"`。

一次画多张并分别保存，用循环配 `file.path()` 生成文件名，不要用 `paste0` 拼反斜杠：

```r
for (v in c("mpg", "wt", "hp")) {
  f <- file.path(tempdir(), paste0("hist_", v, ".png"))
  png(f, width = 600, height = 400)
  hist(mtcars[[v]], main = v, xlab = v)
  dev.off()
}
```

## 七、`car` 与 `alr4` 的绘图函数

课程代码大量使用 `car` 包的绘图函数（`alr4` 加载时会一并加载 `car`）。它们比 base R 多了分组、平滑、离群点标注等便利：

```r
library(alr4)
scatterplot(lifeExpF ~ log(ppgdp) | group, data = UN11,
            smooth = FALSE, boxplots = FALSE,
            ylab = "女性预期寿命")
Boxplot(lifeExpF ~ group, data = UN11, id.n = 2)
#> [1] "Turkey"      "Japan"       "Afghanistan" "Kiribati"    "Nauru"
```

`scatterplot()` 的 `| group` 表示按组着色并分别画；`smooth = TRUE` 会加平滑曲线，`boxplots = TRUE` 会在边缘加箱线图。`Boxplot()` 返回被标出的离群点标签，方便在报告里点名。

回归诊断相关的图在 [[10-回归诊断与结果解读]] 展开，包括 `residualPlots()`、`crPlots()`、`avPlots()`、`influenceIndexPlot()`、`qqPlot()`。

## 八、常见问题

| 现象 | 原因 | 处理 |
| :--- | :--- | :--- |
| 图没出现 | 脚本运行在非交互环境，画到了默认设备 | 显式 `png()`/`pdf()` 并 `dev.off()` |
| 保存的图是空白 | 没关设备，或 `dev.off()` 前报错 | 检查设备配对；用 `tryCatch` 确保关闭 |
| 中文变方框 | 设备没配中文字体 | 见第一章；`family = "GB1"` 或 `"SimSun"` |
| 叠加的元素不见了 | 先 `points()` 后 `plot()`，图被重画 | 高级函数在前，低级函数在后 |
| 后面的图挤成小格 | `par(mfrow)` 没恢复 | `op <- par(...)`；结束 `par(op)` |
| 坐标范围不够 | 默认按第一层数据定范围 | 先 `type = "n"` 加 `xlim`/`ylim` |
| 图例挡住数据 | 位置没选好 | 换 `"topright"` 等，或给具体坐标 |
| `pch` 设了却没填充色 | `pch` 是 19 等无填充的形状 | 用 21–25 并设 `bg` |
| 线条颜色没变 | `col` 传给了 `plot()` 而 `lines()` 另设了默认 | 每个低级函数单独给 `col`、`lty` |
