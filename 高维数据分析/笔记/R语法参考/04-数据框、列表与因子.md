# 第四章 数据框、列表与因子

## 一、数据框的创建与查看

数据框（`data.frame`）是"等长的列"组成的表，每列类型可以不同，这是 R 里最常用的数据结构。构造时列名即参数名；R 4.0 以后字符串默认不转成因子，所以 `group` 列默认是字符型。

```r
d <- data.frame(
  id = 1:5,
  group = c("A", "B", "A", "B", "A"),
  score = c(88, 92, 79, 95, 85)
)
d
#>   id group score
#> 1  1     A    88
#> 2  2     B    92
#> 3  3     A    79
#> 4  4     B    95
#> 5  5     A    85
str(d)
#> 'data.frame':	5 obs. of  3 variables:
#>  $ id   : int  1 2 3 4 5
#>  $ group: chr  "A" "B" "A" "B" ...
#>  $ score: num  88 92 79 95 85
```

`str()` 是最该先用的函数，一次给出维度、列名、类型和前几个值。`head()`、`tail()` 看首尾，`summary()` 给每列的数值汇总或频数，`dim()`、`nrow()`、`ncol()`、`names()` 取结构信息。

```r
dim(d)
#> [1] 5 3
names(d)
#> [1] "id"    "group" "score"
summary(d)
#>        id          group       score      
#>  Min.   :1   Length   :5   Min.   :79.0  
#>  1st Qu.:2   N.unique :2   1st Qu.:85.0  
#>  Median :3   N.blank  :0   Median :88.0  
#>  Mean   :3   Min.nchar:1   Mean   :87.8  
#>  3rd Qu.:4   Max.nchar:1   3rd Qu.:92.0  
#>  Max.   :5                 Max.   :95.0
```

> [!tip] 查看数据不要用 `View()`
>
> `View(d)` 在 RStudio 里打开表格窗口，但它不能在脚本里运行，批处理时会卡住或报错。脚本里用 `head()`、`str()` 代替；交互式查看再另开一行写 `View(d)`。

## 二、取子集

取一列有四种写法，结果类型不同，这是数据框最容易出错的地方。`d$score` 与 `d[, "score"]` 返回**向量**；`d["score"]` 返回只含一列的**数据框**；`d[["score"]]` 返回向量，且不能接行下标。

```r
d$score
#> [1] 88 92 79 95 85
d[["score"]]
#> [1] 88 92 79 95 85
class(d[, "score"])
#> [1] "numeric"
class(d["score"])
#> [1] "data.frame"
```

取行用 `d[i, ]`，逗号不能省：`d[1, ]` 是第一行，`d[, 1]` 是第一列，`d[1]` 是第一列（不是第一行）。取多列用列名向量，需要保持数据框结构时加 `drop = FALSE`。

```r
d[2, ]
#>   id group score
#> 2  2     B    92
d[1:3, c("id", "score")]
#>   id score
#> 1  1    88
#> 2  2    92
#> 3  3    79
d[, "score", drop = FALSE]
#>   score
#> 1    88
#> 2    92
#> 3    79
#> 4    95
#> 5    85
```

按条件筛行有两种写法。方括号里放逻辑向量，长度必须等于行数；`subset()` 更简洁，且会自动排除条件为 `NA` 的行。

```r
d[d$score >= 90, ]
#>   id group score
#> 2  2     B    92
#> 4  4     B    95
subset(d, score >= 90)
#>   id group score
#> 2  2     B    92
#> 4  4     B    95
subset(d, score >= 90, select = c(id, score))
#>   id score
#> 2  2    92
#> 4  4    95
```

> [!warning] `$` 会做部分匹配
>
> `mtcars$cy` 能取到 `cyl` 列，因为 `$` 允许用唯一前缀匹配列名。这种写法在列名相近时非常危险：`mtcars$d` 同时匹配 `disp` 和 `drat`，返回 `NULL`。用 `[[` 或 `[, "完整列名"]` 不会部分匹配，写作业时优先用它们。

```r
mtcars$cy
#>  [1] 6 6 4 6 8 6 8 4 4 6 6 8 8 8 8 8 8 4 4 4 4 8 8 8 8 4 4 4 8 6 8 4
mtcars$d
#> NULL
```

`with()` 在数据框内部求值，避免反复写 `d$`；`within()` 还能返回修改后的数据框；`transform()` 用于加列。

```r
with(d, mean(score))
#> [1] 87.8
with(d, score / max(score))
#> [1] 0.9263158 0.9684211 0.8315789 1.0000000 0.8947368
```

## 三、增删改与排序

新增列直接赋值，删除列赋 `NULL`，改名用 `names()` 定位后替换。这些操作都是"重新赋值给 `d`"，不会原地修改。

```r
d$passed <- d$score >= 90
d$score2 <- d$score * 2
d$passed <- NULL
names(d)[names(d) == "score"] <- "grade"
names(d)
#> [1] "id"    "group" "grade" "score2"
```

排序用 `order()` 给出行号，再按行号取：

```r
d[order(d$grade, decreasing = TRUE), ]
#>   id group grade score2
#> 4  4     B    95    190
#> 2  2     B    92    184
#> 1  1     A    88    176
#> 5  5     A    85    170
#> 3  3     A    79    158
```

多列排序按参数顺序逐级比较；升降序不一致时用 `decreasing = c(FALSE, TRUE)`，长度与排序列数相同。行名会跟着走，若希望重新编号，用 `rownames(d) <- NULL`。

## 四、缺失值处理

`is.na()` 逐元素判断，`anyNA()` 判断整体，`complete.cases()` 判断整行是否完整，`na.omit()` 删掉含缺失值的行。数据框里按列统计缺失数，用 `colSums(is.na(df))`。

```r
air <- airquality
sum(is.na(air))
#> [1] 44
colSums(is.na(air))
#>   Ozone Solar.R    Wind    Temp   Month     Day 
#>      37       7       0       0       0       0
air_clean <- na.omit(air)
nrow(air_clean)
#> [1] 111
```

`na.omit()` 返回的对象带 `na.action` 属性，记录被删掉的行号；`nrow()` 不受影响，但 `attr(air_clean, "na.action")` 能看到删了哪些。若希望保留行位置、让残差等结果与原数据对齐，建模时用 `na.exclude` 而不是 `na.omit`。

## 五、合并与分组汇总

按共同列合并用 `merge()`，`by` 指定键，`all = TRUE` 做全连接，`all.x`、`all.y` 做左、右连接。两边的键名不同时用 `by.x`、`by.y`。

```r
info <- data.frame(group = c("A", "B"), teacher = c("张", "李"))
merge(d, info, by = "group")
#>   group id grade score2 teacher
#> 1     A  1    88    176      张
#> 2     A  3    79    158      张
#> 3     A  5    85    170      张
#> 4     B  2    92    184      李
#> 5     B  4    95    190      李
```

`rbind()` 纵向拼接要求两边列名完全一致，否则报"列名不匹配"；列顺序不同也会报错。`cbind()` 横向拼接按位置对齐，不检查行是否对应，用之前要确认两边的行序一致。

分组汇总有三种常用写法：`tapply()` 返回数组，`aggregate()` 返回数据框，`split()` 加 `lapply()` 最灵活。

```r
tapply(d$grade, d$group, mean)
#>    A    B 
#> 84.0 93.5
aggregate(grade ~ group, data = d, FUN = mean)
#>   group grade
#> 1     A  84.0
#> 2     B  93.5
```

## 六、列表

列表（`list`）可以装任意类型的对象，长度不要求一致。回归结果、`summary()` 的输出、`prcomp()` 的结果都是列表，所以必须会取列表元素。

```r
person <- list(name = "李雷", age = 21, scores = c(88, 92, 79))
person$name
#> [1] "李雷"
person[["age"]]
#> [1] 21
person["age"]
#> $age
#> [1] 21
```

`person["age"]` 返回的是**子列表**，`person[["age"]]` 返回元素本身；`person$age` 等价于后者。这个区别在取模型结果时很关键：`m["coefficients"]` 是列表，`m$coefficients` 是数值向量。

```r
m <- lm(mpg ~ wt, data = mtcars)
class(m)
#> [1] "lm"
m$coefficients
#> (Intercept)          wt 
#>   37.285126   -5.344472
names(m)[1:4]
#> [1] "coefficients" "residuals"    "effects"      "rank"
```

列表的批量操作靠 `lapply()`（返回列表）与 `sapply()`（尝试简化成向量或矩阵）。`unlist()` 把列表压平，`str()` 看嵌套结构。

```r
lapply(1:3, function(i) i^2)
#> [[1]]
#> [1] 1
#> 
#> [[2]]
#> [1] 4
#> 
#> [[3]]
#> [1] 9
sapply(1:3, function(i) i^2)
#> [1] 1 4 9
unlist(list(a = 1, b = 2))
#> a b 
#> 1 2
```

## 七、因子

因子（`factor`）用来表示分类变量，内部存的是整数编码，外加一张水平（levels）表。建模时 R 依据因子的水平生成虚拟变量，所以**分类变量必须先转成因子**，否则会被当成连续变量。

```r
f <- factor(c("低", "高", "中", "高", "低"), levels = c("低", "中", "高"))
f
#> [1] 低 高 中 高 低
#> Levels: 低 中 高
levels(f)
#> [1] "低" "中" "高"
as.integer(f)
#> [1] 1 3 2 3 1
table(f)
#> f
#> 低 中 高 
#>  2  1  2
```

`levels` 的顺序决定基准类（第一个水平）和虚拟变量的排列，必要时用 `relevel()` 改基准类，用 `droplevels()` 删掉没有观测的水平。`ordered = TRUE` 表示水平有顺序，但回归里仍按虚拟变量处理（除非用多项式对比）。

```r
g <- factor(c("b", "a", "c", "a"))
levels(g)
#> [1] "a" "b" "c"
levels(relevel(g, ref = "b"))
#> [1] "b" "a" "c"
droplevels(g)
#> [1] b a c a
#> Levels: a b c
```

> [!warning] 因子转数值的经典错误
>
> `as.numeric(factor(c("10", "2", "30")))` 返回的是**编码** `1 2 3`，不是 `10 2 30`。正确写法是先转字符再转数值：`as.numeric(as.character(x))`。若因子水平本身就是数字顺序，也可以 `as.numeric(levels(x))[x]`，但前一种更直观。

```r
g2 <- factor(c("10", "2", "30"))
as.numeric(g2)
#> [1] 1 2 3
as.numeric(as.character(g2))
#> [1] 10  2 30
```

连续变量分组用 `cut()`。默认区间左开右闭，第一段不含最小值，所以常加 `include.lowest = TRUE`；`labels` 指定组名，`breaks` 给组数时按等宽切分。

```r
age <- c(15, 22, 35, 48, 61)
cut(age, breaks = c(0, 20, 40, 60, 100))
#> [1] (0,20]   (20,40]  (20,40]  (40,60]  (60,100]
#> Levels: (0,20] (20,40] (40,60] (60,100]
cut(age, breaks = 2)
#> [1] (15,38] (15,38] (15,38] (38,61] (38,61]
#> Levels: (15,38] (38,61]
```

## 八、因子与设计矩阵

`model.matrix()` 把公式展开成设计矩阵，可以直观看到因子如何变成虚拟变量。默认使用**处理对比**（treatment contrast）：第一个水平为基准，其余水平各对应一列。

```r
d3 <- data.frame(y = c(1, 2, 3, 4), g = factor(c("a", "a", "b", "b")))
contrasts(d3$g)
#>   b
#> a 0
#> b 1
model.matrix(~ g, data = d3)
#>   (Intercept) gb
#> 1           1  0
#> 2           1  0
#> 3           1  1
#> 4           1  1
```

打印结果末尾还会列出 `assign` 与 `contrasts` 两个属性：前者记录每一列来自公式中的第几项，后者记录该因子用了哪种对比编码。它们不影响矩阵取值，但看 `assign` 能确认"这一列到底是哪个变量生成的"。

`contr.sum`（和对比）、`contr.helmert` 等可以通过 `contrasts()` 或 `options(contrasts = ...)` 全局修改，这部分在 [[08-公式语法与回归建模]] 展开。

## 九、常见坑速查

| 现象 | 原因 | 处理 |
| :--- | :--- | :--- |
| 取一列得到奇怪的结构 | `d["x"]` 返回数据框 | 用 `d$x`、`d[["x"]]` 或 `d[, "x"]` |
| `d[1]` 不是第一行 | 单下标取的是列 | 取行写 `d[1, ]`，逗号不能省 |
| 筛选后行数不对 | 条件里有 `NA` | 用 `subset()`，或 `d[which(cond), ]` |
| `rbind` 报列名不匹配 | 两边列名或顺序不同 | 先统一 `names()`，或改用 `merge()` |
| 因子变数值后全错 | `as.numeric(factor)` 得到编码 | `as.numeric(as.character(x))` |
| 回归把分类变量当连续变量 | 列是字符或数值，不是因子 | `factor(x)` 或 `as.factor(x)` |
| `$` 取到 `NULL` | 列名前缀有歧义 | 用完整列名和 `[[` |
| 合并后行数变多 | 键在一侧有重复 | 先 `table()` 检查键唯一性 |
