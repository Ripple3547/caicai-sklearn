# 第六章 函数与控制流

## 一、条件分支

`if` 的语法是 `if (条件) 表达式 else 表达式`。条件必须是长度为 1 的逻辑值，传入多元素向量会报"条件的长度大于 1"。分支超过一行时用花括号，且 `else` 必须与前面的 `}` 在同一行，否则 R 会把 `if` 当成一条完整语句，`else` 变成语法错误。

```r
x <- 7
if (x %% 2 == 0) {
  "偶数"
} else {
  "奇数"
}
#> [1] "奇数"
```

`if` 本身有返回值，可以直接赋给变量；`else if` 用于多分支。分支多且都是"按值匹配"时，改用 `switch()` 更清楚：

```r
pick <- function(type) {
  switch(type,
    mean = "平均数",
    median = "中位数",
    "未知类型"
  )
}
c(pick("mean"), pick("median"), pick("sd"))
#> [1] "平均数"   "中位数"   "未知类型"
```

需要向量化判断时用 `ifelse(test, yes, no)`，它对每个元素分别选值。注意 `ifelse()` 的返回值类型由 `yes` 和 `no` 共同决定，两者类型不同时会被强制转换：

```r
ifelse(c(1, 5, 10) > 3, "big", "small")
#> [1] "small" "big"   "big"
ifelse(c(TRUE, FALSE), 1, "a")
#> [1] "1" "a"
```

第二行把数值 1 也变成了字符 `"1"`，因为两个分支类型不同时按"更宽"的类型统一。例外是 `test` 只有一个值、且 `yes`、`no` 也都是长度 1 时，`ifelse()` 会直接返回对应分支的原值，不做类型提升；依赖这个捷径写代码容易在换成向量后悄悄改变类型，不推荐。

## 二、循环

`for` 按顺序遍历一个向量或列表。遍历下标时用 `seq_along(x)`，不要用 `1:length(x)`：后者在 `x` 为空时会变成 `1:0`，多跑一次并取到 `NA`。

```r
total <- 0
for (i in 1:5) total <- total + i
total
#> [1] 15

out <- numeric(5)
for (i in seq_along(out)) out[i] <- i^2
out
#> [1] 1 4 9 16 25
```

循环内不断用 `c()` 追加元素会让向量反复复制，数据量大时非常慢。正确做法是先 `numeric(n)` 预分配，再按下标赋值；`out <- c(out, x)` 只适合循环次数很少的场合。

`while` 在条件为真时反复执行，`repeat` 配合 `break` 至少执行一次。`next` 跳过本轮剩余部分，`break` 跳出整个循环。

```r
n <- 1
while (n < 100) n <- n * 2
n
#> [1] 128

for (i in 1:10) {
  if (i %% 2 == 0) next
  if (i > 7) break
  cat(i, "")
}
cat("\n")
#> 1 3 5 7
```

`for` 的循环变量在循环结束后仍保留最后一个值，这不是作用域问题；若后面还要用同名变量，先重新赋值。

## 三、自定义函数

函数用 `function(参数) 函数体` 定义，函数体的最后一个表达式的值就是返回值，也可以用 `return()` 提前返回。参数可以有默认值；没传且没有默认值的参数，在被用到时才报错（惰性求值）。

```r
se <- function(x) sd(x) / sqrt(length(x))
se(c(1, 2, 3, 4, 5))
#> [1] 0.7071068

zscore <- function(x, na.rm = TRUE) {
  (x - mean(x, na.rm = na.rm)) / sd(x, na.rm = na.rm)
}
zscore(c(1, 2, 3))
#> [1] -1  0  1
```

`missing()` 判断某个参数是否被传入，适合做"不传就用另一种算法"的默认逻辑。`...` 把不定数量的参数原样转交给内部函数，`list(...)` 可以把它们收集成列表。

```r
add <- function(x, y) {
  if (missing(y)) y <- x
  x + y
}
c(add(3), add(3, 4))
#> [1] 6 7

summ <- function(...) {
  xs <- c(...)
  c(n = length(xs), mean = mean(xs))
}
summ(1, 2, 3)
#>    n mean 
#>    3    2
```

参数匹配的顺序是：先按名字精确匹配，再按名字前缀部分匹配，最后按位置匹配。调用时写全参数名最稳；只写部分名字（如 `me =` 匹配 `mean`）虽然能跑，但可读性差，且以后函数加参数时容易出错。

```r
f <- function(x, y = 2) x * y
c(f(3), f(3, 4), f(y = 4, x = 3))
#> [1]  6 12 12
```

> [!warning] 函数内的赋值默认是局部的
>
> 函数体内 `x <- 1` 创建的是局部变量，不会改变外部的 `x`。要修改外部变量得用 `<<-`，它会沿作用域向上找同名变量并赋值；找不到就在全局环境创建。`<<-` 让数据流难以追踪，除了交互式调试，脚本里尽量不用。

```r
z <- 10
local_change <- function() {
  z <- 1
  z
}
local_change()
#> [1] 1
z
#> [1] 10
```

## 四、apply 家族

`apply()` 对矩阵或数组按行或按列套函数，第二个参数 `MARGIN` 取 `1` 表示行、`2` 表示列。`apply()` 会把结果拼成向量或矩阵，所以套用的函数返回值长度必须一致。

```r
m <- matrix(1:6, nrow = 2)
apply(m, 1, sum)
#> [1]  9 12
apply(m, 2, mean)
#> [1] 1.5 3.5 5.5
```

`lapply()` 对列表或向量逐元素套函数，**总是返回列表**；`sapply()` 是它的简化版，能简化成向量就简化，不能就仍返回列表；`vapply()` 要求显式给出返回类型和长度，类型不符直接报错，是三者中最安全的。

```r
lapply(1:3, function(i) i^2)
#> [[1]]
#> [1] 1
#> 
#> [[2]]
#> [1] 4
#> 
#> [[3]]
#> [1] 9
sapply(1:3, function(i) i^2)
#> [1] 1 4 9
vapply(1:3, function(i) i^2, numeric(1))
#> [1] 1 4 9
```

对数据框逐列算统计量，`sapply()` 最方便；但数据框里混有字符列时，结果会被强制成字符，这一点要留意：

```r
sapply(mtcars[, c("mpg", "wt", "hp")], mean)
#>      mpg       wt       hp 
#> 20.09062  3.21725 146.68750
vapply(mtcars[, c("mpg", "wt")], mean, numeric(1))
#>      mpg       wt 
#> 20.09062  3.21725
```

`mapply()` 把多个参数向量按位置一一配对后套函数，`Map()` 是它返回列表的版本；`tapply()` 按分组因子算统计量；`split()` 先按因子拆成列表，再配合 `lapply()` 做更复杂的处理。

```r
mapply(function(x, y) x + y, 1:3, 4:6)
#> [1] 5 7 9
tapply(mtcars$mpg, mtcars$cyl, mean)
#>        4        6        8 
#> 26.66364 19.74286 15.10000
```

`replicate()` 把同一段表达式重复多次，返回结果组成的向量或矩阵，写模拟时最常用：

```r
set.seed(1)
means <- replicate(1000, mean(rnorm(30)))
mean(means)
#> [1] -0.001057484
```

`Reduce()` 把二元运算沿列表累积，`do.call()` 把列表拆成参数调用函数，常用来合并一批数据框：

```r
Reduce(`+`, 1:5)
#> [1] 15
do.call(rbind, list(data.frame(a = 1), data.frame(a = 2)))
#>   a
#> 1 1
#> 2 2
```

> [!tip] 什么时候不必用 apply
>
> 如果现成函数已经向量化（`mean()`、`sum()`、`log()`、`lm()` 等），直接传向量即可，套 `apply` 只会更慢。`rowSums()`、`colMeans()` 比 `apply(m, 1, sum)` 快一个量级。只有在"每个元素都要跑一段自定义逻辑"时，才需要 apply 家族。

## 五、模拟与自助法

统计作业里的模拟通常分三步：设定随机种子、重复抽样或重复生成数据、汇总结果。`set.seed()` 保证结果可复现，交作业时把种子写进代码。

```r
set.seed(42)
x <- mtcars$mpg
boot_mean <- replicate(2000, mean(sample(x, replace = TRUE)))
quantile(boot_mean, c(0.025, 0.975))
#>     2.5%    97.5% 
#> 18.20297 22.15633
```

`sample(x, size, replace = FALSE, prob = NULL)` 从 `x` 中抽样；`replace = TRUE` 是有放回抽样（自助法），`prob` 给不等概率。`rnorm()`、`runif()`、`rbinom()` 等 `r` 开头的函数生成随机数，参数与分布对应，详见 [[07-描述统计与分布函数]]。

## 六、管道

R 4.1 起自带管道 `|>`，把左边的结果作为右边函数的第一个参数，省去层层嵌套。R 4.2 起可以用 `_` 占位符把左边结果放到任意参数位置。

```r
mtcars |>
  subset(cyl == 4) |>
  lm(mpg ~ wt, data = _) |>
  coef()
#> (Intercept)          wt 
#>   39.571196   -5.647025
```

匿名函数用 `\(x)` 简写，等价于 `function(x)`：

```r
c(1, 2, 3) |> sapply(\(x) x * 2)
#> [1] 2 4 6
```

管道适合"一串变换"，不适合"需要多次引用同一个中间结果"的场合；后者还是先赋给变量更清楚。

## 七、运行其他脚本

把常用函数写在单独文件里，用 `source()` 载入，等价于把那个文件的内容粘贴到当前位置。`source()` 默认在当前工作目录找文件，路径同样要用 `file.path()` 或正斜杠：

```r
# source("R/helpers.R")
```
