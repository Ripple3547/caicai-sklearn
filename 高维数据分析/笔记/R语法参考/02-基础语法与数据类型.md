# 第二章 基础语法与数据类型

## 一、注释、赋值与命名

注释以 `#` 开头，行内行尾都可以；R 没有多行注释语法，多行注释只能每行加 `#`。赋值用 `<-`，等号 `=` 只在两种场合出现：函数调用里给参数赋值，以及在控制台最外层做赋值。写脚本时统一用 `<-`，避免和"等于"混淆。

```r
x <- 3          # 数值
y = 4           # 合法，但不推荐
x + y
#> [1] 7
```

对象名由字母、数字、点号、下划线组成，不能以数字或下划线开头，区分大小写。`my.data`、`my_data`、`myData` 是三个不同的对象。中文名可以写，但输入法切换和编码问题会带来麻烦，不推荐。

```r
a <- 1
A <- 2
a == A
#> [1] FALSE
exists("A")
#> [1] TRUE
rm(a)
exists("a")
#> [1] FALSE
```

> [!warning] 不要覆盖内置名
>
> `c`、`t`、`data`、`df`、`T`、`F` 这些名字在 R 里已经有含义。把 `T` 赋成 0 之后，所有写 `T` 的地方都会变成 0，而且不会报错。`df` 虽然只是习惯名，但它是 `df()` 密度函数的名字，冲突时同样难查。

## 二、对象与类型

R 里最小的数据单位是**向量**，单个数字只是长度为 1 的向量。常用原子类型有五类：数值型（`double`，也叫 `numeric`）、整型（`integer`）、字符型（`character`）、逻辑型（`logical`）、复数型（`complex`）。判断类型用 `class()` 或 `typeof()`，转换用 `as.*()`。

```r
class(1)
#> [1] "numeric"
typeof(1)
#> [1] "double"
class(1L)
#> [1] "integer"
is.integer(1)
#> [1] FALSE
is.numeric(1L)
#> [1] TRUE
```

`class()` 返回的是"面向对象意义上的类"，`typeof()` 返回存储类型，两者对向量通常一致，对 `data.frame`、`lm` 对象这类复合对象则不同，后面会反复用到。

类型转换有优先级：逻辑型 → 整型 → 数值型 → 字符型。混合类型的向量会被统一提升到"最宽"的那一类，且不报错：

```r
c(1, TRUE)
#> [1] 1 1
c(1, TRUE, "a")
#> [1] "1"    "TRUE" "a"
```

第二行把数字和逻辑都变成了字符。这类隐式转换是"读进来的数怎么变成字符了"的常见原因。显式转换失败时通常返回 `NA` 并给警告，而不是报错：

```r
as.numeric("3.5")
#> [1] 3.5
as.numeric("3.5kg")
#> [1] NA
# 警告信息: 强制改变过程中产生了NA
as.integer(3.9)
#> [1] 3
as.logical(c("TRUE", "FALSE", "yes"))
#> [1]  TRUE FALSE    NA
```

注意 `as.integer()` 是**截断**而不是四舍五入，3.9 变成 3；要取整用 `round()`、`floor()`、`ceiling()`。

## 三、缺失值与特殊值

R 有四种"不是正常数"的值，含义不同：

| 值 | 含义 | 判断函数 |
| :--- | :--- | :--- |
| `NA` | 缺失值（missing） | `is.na()` |
| `NaN` | 不是数（not a number），如 `0/0` | `is.nan()`，`is.na()` 也为真 |
| `Inf` / `-Inf` | 正负无穷，如 `1/0` | `is.infinite()`、`is.finite()` |
| `NULL` | 空对象，长度为 0 | `is.null()` |

```r
0 / 0
#> [1] NaN
1 / 0
#> [1] Inf
is.na(c(NA, NaN, 1))
#> [1]  TRUE  TRUE FALSE
is.nan(c(NA, NaN, 1))
#> [1] FALSE  TRUE FALSE
length(NULL)
#> [1] 0
c(1, NULL, 3)
#> [1] 1 3
```

`NA` 会传染：任何含 `NA` 的算术或统计结果都是 `NA`，除非显式去掉。

```r
z <- c(1, NA, 3)
mean(z)
#> [1] NA
mean(z, na.rm = TRUE)
#> [1] 2
sum(z, na.rm = TRUE)
#> [1] 4
```

`NA` 本身是逻辑型，放进数值向量时会自动转成 `NA_real_`；需要指定类型时用 `NA_integer_`、`NA_character_`。`NULL` 则不同，它在 `c()` 里会直接消失，常用来表示"没有这个元素"。

## 四、运算符

算术运算符包括 `+ - * / ^`，以及整除 `%/%`、取模 `%%`。取模结果的符号跟随**除数**，这一点与某些语言不同：

```r
c(-1 %% 3, -1 %/% 3)
#> [1]  2 -1
```

运算优先级里，`^` 高于一元负号，所以 `-2^2` 是 -4 而不是 4：

```r
-2^2
#> [1] -4
(-2)^2
#> [1] 4
```

比较运算符是 `== != < <= > >=`，返回逻辑向量；`=` 不是比较运算符。浮点数比较不能直接用 `==`：

```r
0.1 + 0.2 == 0.3
#> [1] FALSE
identical(0.1 + 0.2, 0.3)
#> [1] FALSE
all.equal(0.1 + 0.2, 0.3)
#> [1] TRUE
```

`all.equal()` 带容差，判断"数值上是否足够接近"；`identical()` 要求完全相同。涉及浮点累加的结果（如回归系数、模拟均值）都用前者或 `round()` 后比较。

逻辑运算符分两种。`&`、`|`、`!` 是**向量化**的，对每个元素分别运算；`&&`、`||` 只看第一个元素，并且短路（左边能定结果就不算右边），用于 `if` 条件：

```r
c(TRUE, FALSE) & c(TRUE, TRUE)
#> [1]  TRUE FALSE
TRUE && FALSE
#> [1] FALSE
FALSE && stop("右侧不会执行")
#> [1] FALSE
```

`&&` 与 `||` 只接受长度为 1 的操作数，传入多元素向量会直接报错，这一点与 `&`、`|` 不同。短路特性使得 `FALSE && stop(...)` 不会真的停止执行，`if (x > 0 && log(x) > 0)` 这种写法才安全。

`%in%` 判断元素是否属于某个集合，返回与左边等长的逻辑向量，比写一串 `|` 清楚：

```r
c(1, 5, 9) %in% c(1, 2, 3)
#> [1]  TRUE FALSE FALSE
```

取整相关的函数容易混：`round()` 四舍五入（采用"银行家舍入"，.5 取偶），`floor()` 向下取整，`ceiling()` 向上取整，`trunc()` 向零截断，`signif()` 保留有效数字。

```r
c(round(2.5), round(3.5), round(-2.5))
#> [1]  2  4 -2
c(floor(-3.9), ceiling(-3.9), trunc(-3.9))
#> [1] -4 -3 -3
```

## 五、字符串

字符串用单引号或双引号都行，字符串内部要出现引号时用反斜杠转义，或换另一种引号。`\n` 是换行，`\t` 是制表符，`\\` 是一个反斜杠。

```r
s <- "高维数据分析"
nchar(s)
#> [1] 6
toupper("abc")
#> [1] "ABC"
substr(s, 1, 2)
#> [1] "高维"
```

拼接字符串用 `paste()`（默认空格分隔）与 `paste0()`（无分隔符）；要把一个向量压成单个字符串，用 `collapse` 参数：

```r
paste("a", "b")
#> [1] "a b"
paste0("a", "b")
#> [1] "ab"
paste(c("a", "b", "c"), collapse = ", ")
#> [1] "a, b, c"
```

格式化输出用 `sprintf()`，格式串沿袭 C 语言：`%d` 整数、`%f` 定点小数、`%s` 字符串、`%.2f` 保留两位：

```r
sprintf("%.2f%%", 3.14159)
#> [1] "3.14%"
sprintf("第 %d 组，均值 %.3f", 2, 1.23456)
#> [1] "第 2 组，均值 1.235"
```

拆分与查找用 `strsplit()`、`grep()`、`grepl()`、`sub()`、`gsub()`。`grep()` 返回匹配位置，`grepl()` 返回逻辑向量，`sub()` 只替换第一处，`gsub()` 替换全部：

```r
strsplit("a,b,c", ",")[[1]]
#> [1] "a" "b" "c"
grepl("^a", c("abc", "bcd"))
#> [1]  TRUE FALSE
gsub("a", "A", "banana")
#> [1] "bAnAnA"
trimws("  x  ")
#> [1] "x"
```

> [!warning] 字符与数值的比较
>
> 字符串比较按字典序，逐字符进行。`"10" < "9"` 为 `TRUE`，因为 `"1"` 排在 `"9"` 前面。如果一列数字被读成了字符型，比较和排序都会悄悄出错，而且不报错。

## 六、日期与时间

日期用 `as.Date()` 生成，内部存的是"自 1970-01-01 起的天数"，显示时才格式化。`format()` 控制显示格式，`%Y` 四位年、`%m` 月、`%d` 日：

```r
d <- as.Date("2026-10-21")
d
#> [1] "2026-10-21"
format(d, "%Y年%m月%d日")
#> [1] "2026年10月21日"
d + 7
#> [1] "2026-10-28"
```

日期相减得到 `difftime` 对象，用 `units` 指定单位；`weekdays()` 给星期几：

```r
difftime(as.Date("2026-11-01"), d, units = "days")
#> Time difference of 11 days
weekdays(d)
#> [1] "星期三"
```

带时分秒的时间用 `as.POSIXct()`，需要指定时区（本机为 `Asia/Shanghai`）。纯日期分析用 `Date` 就够，不要把一个日期列当字符串处理：`"2026-10-9"` 和 `"2026-10-10"` 按字符串排序会得到错误顺序。

## 七、帮助与代码风格

不确定函数用法时，`?` 打开帮助页，`??` 做全文搜索，`args()` 只列参数，`example()` 直接跑示例：

```r
args(mean)
#> function (x, ...) 
#> NULL
```

代码风格上，赋值号与运算符两侧留空格，逗号后留空格，一行只写一个完整表达式；过长的调用按参数对齐换行。注释写"为什么这样做"，不写"这一行在干什么"——后者看代码就知道。
