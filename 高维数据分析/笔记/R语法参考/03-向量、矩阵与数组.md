# 第三章 向量、矩阵与数组

## 一、向量的创建

`c()` 是最基本的构造函数，`:` 生成等差整数序列，`seq()` 控制步长或长度，`rep()` 重复。预分配空向量用 `numeric(n)`、`character(n)`、`logical(n)`，它们的初值分别是 0、`""`、`FALSE`。

```r
x <- c(3, 1, 4, 1, 5, 9)
length(x)
#> [1] 6
seq(1, 10, by = 2)
#> [1] 1 3 5 7 9
seq(0, 1, length.out = 5)
#> [1] 0.00 0.25 0.50 0.75 1.00
rep(1:2, times = 3)
#> [1] 1 2 1 2 1 2
rep(1:2, each = 3)
#> [1] 1 1 1 2 2 2
```

> [!warning] `1:n` 的陷阱
>
> 当 `n` 为 0 时，`1:0` 得到的是 `c(1, 0)`，而不是空向量；循环里写 `for (i in 1:n)` 会多跑一次并取到错误下标。改用 `seq_len(n)` 或 `seq_along(x)`，它们在 `n = 0` 时返回空向量。

```r
1:0
#> [1] 1 0
seq_len(0)
#> integer(0)
numeric(3)
#> [1] 0 0 0
```

## 二、索引

R 的下标从 1 开始。方括号里可以放四类东西：正整数（取对应位置）、负整数（排除对应位置）、逻辑向量（取 `TRUE` 的位置）、字符向量（按名字取）。

```r
x <- c(3, 1, 4, 1, 5, 9)
x[2]
#> [1] 1
x[c(1, 6)]
#> [1] 3 9
x[-1]
#> [1] 1 4 1 5 9
x[x > 3]
#> [1] 4 5 9
```

逻辑下标会按需循环：`x[c(TRUE, FALSE)]` 等价于每隔一个取一个。若逻辑向量比 `x` 短且长度不整除，R 会补到等长，不报错，这类"看起来取对了其实错位"的问题最难查。

```r
x[c(TRUE, FALSE)]
#> [1] 3 4 5
x[c(1, 1, 2)]
#> [1] 3 3 1
```

越界与负号混用有明确规则：正下标超出长度返回 `NA`，负下标超出长度被忽略，正负混用直接报错。

```r
x[10]
#> [1] NA
x[-10]
#> [1] 3 1 4 1 5 9
```

给元素赋值也用下标，超出长度赋值会把向量自动延长，中间补 `NA`。下面用另一个向量演示，避免改动前面的 `x`：

```r
w <- c(3, 1, 4, 1, 5, 9)
w[7] <- 2
w
#> [1] 3 1 4 1 5 9 2
w[w < 3] <- 0
w
#> [1] 3 0 4 0 5 9 0
```

按位置查值用 `which()`，它返回满足条件的位置；`which.max()`、`which.min()` 返回极值位置。需要"值"而不是"位置"时，直接用逻辑下标即可。

```r
which(x > 3)
#> [1] 3 5 6
which.max(x)
#> [1] 6
match(c(9, 3), x)
#> [1] 6 1
```

## 三、循环规则

两个长度不同的向量做运算时，短的会从头重复，补到与长的等长，这叫**循环**（recycling）。长度成整倍数时静默进行；不成整倍数时给出警告，但**仍然计算**。

```r
c(1, 2, 3, 4) + c(10, 20)
#> [1] 11 22 13 24
c(1, 2, 3) + c(10, 20)
#> [1] 11 22 13
# 警告信息: 长的对象长度不是短的对象长度的整倍数
```

第二种情况几乎总是笔误。看到这条警告，应当检查两边的长度，而不是用 `suppressWarnings()` 压掉。

## 四、向量化运算与常用函数

R 的算术、比较、数学函数都是逐元素作用在向量上的，不需要写循环。`log()`、`exp()`、`sqrt()`、`abs()` 直接收向量；`sum()`、`mean()`、`prod()` 把向量压成一个数；`cumsum()`、`cumprod()`、`diff()` 返回等长或略短的向量。

```r
sum(1:5)
#> [1] 15
cumsum(1:5)
#> [1]  1  3  6 10 15
diff(c(1, 4, 9))
#> [1] 3 5
prod(1:5)
#> [1] 120
```

排序相关的函数要分清：`sort()` 返回值排好序的向量，`order()` 返回"排好序时各元素原来的位置"，`rank()` 返回每个元素的秩。数据框按某列排序时用的是 `order()`，因为需要的是行号。

```r
sort(x)
#> [1] 1 1 3 4 5 9
order(x)
#> [1] 2 4 1 3 5 6
rank(x)
#> [1] 3.0 1.5 4.0 1.5 5.0 6.0
x[order(x)]
#> [1] 1 1 3 4 5 9
```

集合运算有 `unique()`、`duplicated()`、`union()`、`intersect()`、`setdiff()`；`%in%` 判断归属。`any()`、`all()` 把逻辑向量压成一个值，带 `NA` 时需要 `na.rm = TRUE` 才有确定结果。

```r
unique(c(1, 2, 2, 3))
#> [1] 1 2 3
intersect(1:3, 2:4)
#> [1] 2 3
setdiff(1:3, 2:4)
#> [1] 1
any(c(FALSE, TRUE))
#> [1] TRUE
```

`ifelse()` 是向量化的"三目运算"，对每个元素分别判断，返回等长向量：

```r
ifelse(c(1, 5, 10) > 3, "big", "small")
#> [1] "small" "big"   "big"
```

## 五、矩阵

`matrix()` 按**列**填充，除非指定 `byrow = TRUE`。矩阵本质上是"带 `dim` 属性的向量"，所以它有长度、可以按单个下标取元素（按列优先），也保留着向量的一切运算规则。

```r
A <- matrix(1:6, nrow = 2, byrow = TRUE)
A
#>      [,1] [,2] [,3]
#> [1,]    1    2    3
#> [2,]    4    5    6
dim(A)
#> [1] 2 3
length(A)
#> [1] 6
A[5]
#> [1] 3
```

`A[i, j]` 取元素，`A[i, ]` 取整行，`A[, j]` 取整列。**默认会降维**：取一行得到向量而不是 1×3 矩阵，取一列同理。需要保持矩阵结构时加 `drop = FALSE`。

```r
A[1, ]
#> [1] 1 2 3
A[, 2]
#> [1] 2 5
A[1, , drop = FALSE]
#>      [,1] [,2] [,3]
#> [1,]    1    2    3
```

`rbind()`、`cbind()` 按行或按列拼接，`t()` 转置，`rownames()`、`colnames()`、`dimnames()` 设置名字。矩阵的乘法是 `%*%`，`*` 是逐元素相乘，两者不可混用。

```r
B <- matrix(c(1, 0, 0, 1), nrow = 2)
A %*% t(A)
#>      [,1] [,2]
#> [1,]   14   32
#> [2,]   32   77
A * A
#>      [,1] [,2] [,3]
#> [1,]    1    4    9
#> [2,]   16   25   36
```

线性代数函数：`solve()` 求逆或解方程，`det()` 行列式，`diag()` 取对角或构造单位阵，`crossprod()` 计算 `t(X) %*% Y`，`eigen()` 特征分解，`svd()` 奇异值分解，`qr()` QR 分解。

```r
M <- matrix(c(2, 1, 1, 2), nrow = 2)
solve(M)
#>            [,1]       [,2]
#> [1,]  0.6666667 -0.3333333
#> [2,] -0.3333333  0.6666667
det(M)
#> [1] 3
eigen(M)$values
#> [1] 3 1
diag(3)
#>      [,1] [,2] [,3]
#> [1,]    1    0    0
#> [2,]    0    1    0
#> [3,]    0    0    1
```

> [!warning] 三个常见误写
>
> `A^-1` 是对每个元素取倒数，不是矩阵求逆；矩阵求逆用 `solve(A)`。`A / B` 是逐元素相除，不是矩阵右乘 `B` 的逆。`solve(A)` 只对方阵且可逆的矩阵有效，奇异矩阵会报 Lapack 的奇异错误（如"系统正好是奇异的"），此时应检查共线性，而不是加个微小扰动硬算。

行、列汇总用 `rowSums()`、`colSums()`、`rowMeans()`、`colMeans()`，比 `apply()` 快且不易出错：

```r
rowSums(A)
#> [1]  6 15
colMeans(A)
#> [1] 2.5 3.5 4.5
```

数组是更高维的矩阵，用 `array()` 构造，第三个维度常用来存"多个矩阵"：

```r
arr <- array(1:8, dim = c(2, 2, 2))
dim(arr)
#> [1] 2 2 2
arr[, , 1]
#>      [,1] [,2]
#> [1,]    1    3
#> [2,]    2    4
```

## 六、矩阵与最小二乘

课程里的回归系数可以用矩阵公式直接算一遍，这能帮助理解 `lm()` 在做什么。设 $\mathbf{X}$ 为设计矩阵、$\mathbf{y}$ 为响应向量，最小二乘解为 $\hat{\boldsymbol\beta}=(\mathbf{X}^{\top}\mathbf{X})^{-1}\mathbf{X}^{\top}\mathbf{y}$。

```r
X <- model.matrix(~ wt + hp, data = mtcars)
y <- mtcars$mpg
beta <- solve(crossprod(X), crossprod(X, y))
as.vector(beta)
#> [1] 37.22727012 -3.87783074 -0.03177295
coef(lm(mpg ~ wt + hp, data = mtcars))
#> (Intercept)          wt          hp 
#>  37.22727012  -3.87783074  -0.03177295
```

`crossprod(X)` 就是 $\mathbf{X}^{\top}\mathbf{X}$，`crossprod(X, y)` 就是 $\mathbf{X}^{\top}\mathbf{y}$。`model.matrix()` 负责把公式转成设计矩阵，因子会自动展开成虚拟变量，这部分在 [[08-公式语法与回归建模]] 展开。
