# 第八章 公式语法与回归建模

## 一、公式对象

R 用公式（formula）描述模型结构，写法是 `响应 ~ 解释项`。公式本身是一个对象，`class()` 是 `"formula"`，可以存进变量、传给函数，也可以修改。

```r
f <- mpg ~ wt + hp
class(f)
#> [1] "formula"
deparse(f)
#> [1] "mpg ~ wt + hp"
```

公式里的符号有固定含义，和数学写法差别很大，尤其是 `^`：

| 符号 | 含义 | 例子 | 展开后的项 |
| :--- | :--- | :--- | :--- |
| `+` | 加一项 | `y ~ x1 + x2` | `x1`、`x2` |
| `-` | 去掉一项 | `y ~ . - x2` | 除 `x2` 外的所有变量 |
| `-1` 或 `+0` | 去掉截距 | `y ~ x - 1` | `x`，无截距 |
| `:` | 交互项 | `y ~ x1:x2` | `x1:x2` |
| `*` | 主效应加交互 | `y ~ x1 * x2` | `x1`、`x2`、`x1:x2` |
| `^n` | 到 $n$ 阶的交互 | `y ~ (x1 + x2)^2` | 同 `x1 * x2` |
| `I()` | 保护算术运算 | `y ~ I(x^2)` | $x^2$ |
| `poly()` | 多项式基 | `y ~ poly(x, 2)` | 正交二次项 |
| `.` | 其余所有变量 | `y ~ .` | 除 `y` 外全部列 |

`^` 表示**交互阶数**而不是幂，这是最容易错的一处。`y ~ x^2` 展开后仍然只有 `x` 一项，要平方必须写 `I(x^2)` 或用 `poly(x, 2)`：

```r
attr(terms(mpg ~ wt^2), "term.labels")
#> [1] "wt"
attr(terms(mpg ~ wt * hp), "term.labels")
#> [1] "wt"    "hp"    "wt:hp"
attr(terms(mpg ~ wt + I(wt^2)), "term.labels")
#> [1] "wt"      "I(wt^2)"
```

`*` 会自动补上两个主效应，`:` 只加交互项。写 `y ~ x1 * x2` 与 `y ~ x1 + x2 + x1:x2` 完全等价。

## 二、`lm()` 的调用与 `summary()` 解读

`lm()` 的常用形式是 `lm(formula, data = ...)`。用 `data =` 指定数据框有两个好处：公式里的变量名在数据框内解析，不会误取全局环境中同名的旧变量；`predict()`、`update()` 等后续函数也能复用同一份数据。

先把 `cyl` 转成因子，否则 R 会把它当连续变量：

```r
d <- transform(mtcars, cyl = factor(cyl))
m <- lm(mpg ~ wt + hp + cyl, data = d)
summary(m)
#> 
#> Call:
#> lm(formula = mpg ~ wt + hp + cyl, data = d)
#> 
#> Residuals:
#>     Min      1Q  Median      3Q     Max 
#> -4.2612 -1.0320 -0.3210  0.9281  5.3947 
#> 
#> Coefficients:
#>             Estimate Std. Error t value Pr(>|t|)    
#> (Intercept) 35.84600    2.04102  17.563 2.67e-16 ***
#> wt          -3.18140    0.71960  -4.421 0.000144 ***
#> hp          -0.02312    0.01195  -1.934 0.063613 .  
#> cyl6        -3.35902    1.40167  -2.396 0.023747 *  
#> cyl8        -3.18588    2.17048  -1.468 0.153705    
#> ---
#> Signif. codes:  0 '***' 0.001 '**' 0.01 '*' 0.05 '.' 0.1 ' ' 1
#> 
#> Residual standard error: 2.44 on 27 degrees of freedom
#> Multiple R-squared:  0.8572,	Adjusted R-squared:  0.8361 
#> F-statistic: 40.53 on 4 and 27 DF,  p-value: 4.869e-11
```

输出分四块，逐块读：

第一块 `Residuals` 是残差的五数概括，用来粗看是否有极端值、分布是否大致对称。若最小值与最大值相差悬殊，先检查异常点，不要急着解释系数。

第二块 `Coefficients` 是系数表。`Estimate` 是点估计，`Std. Error` 是标准误，`t value` 是估计除以标准误，`Pr(>|t|)` 是对"该系数为 0"的双侧检验 p 值。这里的基准类是 `cyl = 4`，所以 `cyl6` 的 -3.359 解释为"在 `wt`、`hp` 相同的条件下，6 缸车比 4 缸车平均少 3.36 mpg"，而不是"6 缸车的平均油耗"。截距 35.846 是 `wt = 0`、`hp = 0`、`cyl = 4` 时的预测值，属于外推，没有实际意义。

第三块 `Residual standard error` 是 $\hat\sigma=\sqrt{\mathrm{RSS}/(n-p)}$，单位与响应变量相同；`Multiple R-squared` 是解释的方差比例，`Adjusted R-squared` 对参数个数做了惩罚，比较不同参数个数的模型时看后者。

第四块 `F-statistic` 检验"所有斜率同时为 0"。p 值很小只说明**至少有一个**预测变量有用，不说明每个都有用，也不说明模型设定正确。

`cyl` 有两个虚拟变量，说明如下：

```r
contrasts(d$cyl)
#>   6 8
#> 4 0 0
#> 6 1 0
#> 8 0 1
```

三水平的因子需要 $3-1=2$ 个虚拟变量。若加满三个，会与截距完全共线（虚拟变量陷阱），`lm()` 会自动丢弃一个，表现为某个系数为 `NA`。

## 三、因子与基准类

基准类由因子水平的顺序决定，默认是第一个水平。改基准类用 `relevel()`，它不改变数据，只改变对比方式：

```r
coef(lm(mpg ~ wt + hp + relevel(cyl, ref = "6"), data = d))
#>              (Intercept)                       wt                       hp relevel(cyl, ref = "6")4 
#>             32.48697042              -3.18140405              -0.02311981               3.35902490 
#> relevel(cyl, ref = "6")8 
#>               0.17314045
```

换成 6 缸为基准后，截距变成 6 缸车在 `wt = 0`、`hp = 0` 时的预测值，`cyl4` 的系数 +3.359 正好是原来 `cyl6` 系数 -3.359 的相反数，`cyl8` 变成 +0.173，等于原来两项之差 $-3.186-(-3.359)$。`wt`、`hp` 的系数完全不变。系数随基准类重新参数化，但模型拟合、残差、$R^2$ 都不变，这是判断"对比方式是否只影响解释"的依据。

因子进入模型前必须确认类型。字符列会被 `lm()` 自动转成因子，但数值编码的类别（如 `1`、`2`、`3`）不会，必须手动 `factor()`：

```r
class(mtcars$cyl)
#> [1] "numeric"
attr(terms(lm(mpg ~ cyl, data = mtcars)), "dataClasses")
#>       mpg       cyl 
#> "numeric" "numeric"
```

## 四、结果提取

`summary()` 只是一份打印稿，真正要用的是模型对象里的分量。`coef()`、`confint()`、`vcov()`、`sigma()`、`nobs()`、`df.residual()` 都有对应的提取函数，比从打印结果里抄数字可靠。

```r
coef(m)
#> (Intercept)          wt          hp        cyl6        cyl8 
#> 35.84599532 -3.18140405 -0.02311981 -3.35902490 -3.18588444
confint(m)
#>                   2.5 %       97.5 %
#> (Intercept) 31.65817010 40.033820531
#> wt          -4.65790334 -1.704904751
#> hp          -0.04764369  0.001404071
#> cyl6        -6.23501360 -0.483036192
#> cyl8        -7.63933188  1.267562990
sigma(m)
#> [1] 2.440231
nobs(m)
#> [1] 32
```

`summary(m)$coefficients` 是矩阵，可以按行列取：`summary(m)$coefficients["wt", "Pr(>|t|)"]` 直接得到 wt 的 p 值。`fitted()` 取拟合值，`residuals()` 取残差，`rstandard()` 取标准化残差，`hatvalues()` 取杠杆值，`cooks.distance()` 取 Cook 距离——这些在 [[10-回归诊断与结果解读]] 里展开。

## 五、模型比较与变量选择

嵌套模型用 `anova(m0, m1)` 做偏 F 检验，检验"新增的项是否显著改善拟合"。非嵌套模型不能这样比，要看 AIC、BIC 或交叉验证。

```r
m0 <- lm(mpg ~ wt, data = d)
m1 <- lm(mpg ~ wt + hp, data = d)
anova(m0, m1)
#> Analysis of Variance Table
#> 
#> Model 1: mpg ~ wt
#> Model 2: mpg ~ wt + hp
#>   Res.Df    RSS Df Sum of Sq      F   Pr(>F)   
#> 1     30 278.32                                
#> 2     29 195.05  1    83.274 12.381 0.001451 **
#> ---
#> Signif. codes:  0 '***' 0.001 '**' 0.01 '*' 0.05 '.' 0.1 ' ' 1
AIC(m0, m1)
#>    df      AIC
#> m0  3 166.0294
#> m1  4 156.6523
```

`anova(m)`（只给一个模型）给出的是**序贯**方差分析表，各项的平方和依赖进入顺序，换顺序结果就变；检验"某个变量在已有变量基础上的增量"时，它才与偏 F 检验一致。

`drop1()` 逐个尝试删掉一项，`add1()` 逐个尝试加入一项，`step()` 按 AIC 自动双向搜索。`step()` 的结果依赖起始模型和搜索方向，只能当作候选，不能当作"最优模型"的证明：

```r
step(lm(mpg ~ ., data = d), direction = "both", trace = 0)
#> 
#> Call:
#> lm(formula = mpg ~ wt + qsec + am, data = d)
#> 
#> Coefficients:
#> (Intercept)           wt         qsec           am  
#>       9.618       -3.917        1.226        2.936
```

`update()` 用公式的 `.` 表示"保持原有部分"，改一项很方便：

```r
update(m1, . ~ . - hp)
#> 
#> Call:
#> lm(formula = mpg ~ wt, data = d)
#> 
#> Coefficients:
#> (Intercept)           wt  
#>      37.285       -5.344
```

## 六、预测

`predict()` 对新数据给预测值。`interval = "confidence"` 是**均值**的置信区间，`interval = "prediction"` 是**单个新观测**的预测区间，后者总是更宽；`se.fit = TRUE` 同时返回标准误。

```r
newd <- data.frame(wt = c(2.5, 3), hp = c(100, 150))
predict(m1, newdata = newd, interval = "confidence")
#>        fit      lwr      upr
#> 1 24.35540 23.15968 25.55111
#> 2 20.82784 19.83556 21.82012
predict(m1, newdata = newd, interval = "prediction")
#>        fit      lwr      upr
#> 1 24.35540 18.91817 29.79263
#> 2 20.82784 15.43169 26.22398
```

> [!warning] `newdata` 的因子水平
>
> 新数据里的因子必须与建模时**完全相同的水平集合**。只出现部分水平时，`predict()` 会报"因子有新水平"；水平名拼错也会报错。稳妥写法是 `factor(x, levels = levels(d$g))`，显式对齐。数值变量外推到数据范围之外时 R 不报错，但预测区间的可靠性会迅速下降。

## 七、多项式、样条与交互

二次项有两种写法：`I(x^2)` 是原始幂，`poly(x, 2)` 是正交多项式。两者拟合值完全相同，系数不可直接比较；解释曲线形状时用原始幂，做数值稳定的拟合时用正交多项式。

```r
mp <- lm(mpg ~ poly(wt, 2), data = d)
mr <- lm(mpg ~ wt + I(wt^2), data = d)
coef(mp)
#>  (Intercept) poly(wt, 2)1 poly(wt, 2)2 
#>    20.090625   -29.115722     8.635768
coef(mr)
#> (Intercept)          wt     I(wt^2) 
#>  49.930811  -13.380337    1.171087
max(abs(fitted(mp) - fitted(mr)))
#> [1] 2.131628e-14
```

样条用 `splines::bs()`（B 样条）或 `splines::ns()`（自然样条），`df` 控制自由度，也就是节点数加多项式阶数。样条项没有单独的系数解释，看整体拟合与图形：

```r
coef(lm(mpg ~ splines::bs(wt, df = 3), data = d))
#>              (Intercept) splines::bs(wt, df = 3)1 splines::bs(wt, df = 3)2 
#>                 32.24820                -12.28634                -19.99469 
#> splines::bs(wt, df = 3)3 
#>                -20.37705
```

交互项 `x * g` 让不同组有不同的斜率。下面的模型中，`wt` 的系数是 4 缸车的斜率，`wt:cyl6` 是 6 缸车相对 4 缸车的斜率增量：

```r
coef(lm(mpg ~ wt * cyl, data = d))
#> (Intercept)          wt        cyl6        cyl8     wt:cyl6     wt:cyl8 
#>  39.571196   -5.647025  -11.162351  -15.703167    2.866919    3.454587
```

于是三组的斜率分别是 -5.647、-2.780、-2.192。交互项显著与否，决定的是"斜率是否有组间差异"；主效应显著与否，只说明"在基准组里该变量是否有作用"。中心化（减去均值）不改变拟合，但能让主效应的解释从"`wt = 0` 时"变成"在平均体重处"，通常更好读。

## 八、logistic 回归与 GLM

二分类响应用 `glm(..., family = binomial)`。`Donner` 数据来自 `alr4`，先加载包；其中 `y` 是因子，水平为 `died`、`survived`，R 把第一个水平当失败、第二个当成功：

```r
library(alr4)
g <- glm(y ~ age + sex, data = Donner, family = binomial)
summary(g)
#> 
#> Call:
#> glm(formula = y ~ age + sex, family = binomial, data = Donner)
#> 
#> Coefficients:
#>             Estimate Std. Error z value Pr(>|z|)   
#> (Intercept)  1.62180    0.50279   3.226  0.00126 **
#> age         -0.03561    0.01525  -2.336  0.01952 * 
#> sexMale     -1.06798    0.48229  -2.214  0.02680 * 
#> ---
#> Signif. codes:  0 '***' 0.001 '**' 0.01 '*' 0.05 '.' 0.1 ' ' 1
#> 
#> (Dispersion parameter for binomial family taken to be 1)
#> 
#>     Null deviance: 120.86  on 87  degrees of freedom
#> Residual deviance: 108.87  on 85  degrees of freedom
#>   (因为不存在，3个观察量被删除了)
#> AIC: 114.87
#> 
#> Number of Fisher Scoring iterations: 4
```

系数是**对数优势比**，取指数才是优势比。`age` 的系数 -0.0356 表示年龄每增加一岁，生存优势比乘以 0.965；`sexMale` 的 -1.068 表示男性相对女性的优势比为 0.344：

```r
exp(cbind(OR = coef(g), confint(g)))
#> Waiting for profiling to be done...
#>                    OR     2.5 %     97.5 %
#> (Intercept) 5.0622023 1.9975778 14.6351234
#> age         0.9650211 0.9348223  0.9930661
#> sexMale     0.3437032 0.1289826  0.8662985
```

`confint()` 对 GLM 用剖面似然，会打印"Waiting for profiling..."，这是正常提示不是错误。预测时要加 `type = "response"` 才会得到概率，默认返回的是线性预测值（logit 尺度）：

```r
nd <- data.frame(age = c(30, 40),
                 sex = factor(c("Male", "Female"), levels = levels(Donner$sex)))
predict(g, newdata = nd, type = "response")
#>         1         2 
#> 0.3741782 0.5492375
anova(g, test = "Chisq")
#> Analysis of Deviance Table
#> 
#> Model: binomial, link: logit
#> 
#> Response: y
#> 
#> Terms added sequentially (first to last)
#> 
#> 
#>      Df Deviance Resid. Df Resid. Dev Pr(>Chi)   
#> NULL                    87     120.86            
#> age   1   6.8368        86     114.02  0.00893 **
#> sex   1   5.1509        85     108.87  0.02323 * 
#> ---
#> Signif. codes:  0 '***' 0.001 '**' 0.01 '*' 0.05 '.' 0.1 ' ' 1
```

`glm()` 的残差、AIC、`anova(test = "Chisq")` 与 `lm()` 的用法一致，但**不能**看 R²，也不能用 `anova(m1, m2)` 的 F 检验；模型比较用偏差分析、AIC 或交叉验证。

## 九、常见错误

| 现象 | 原因 | 处理 |
| :--- | :--- | :--- |
| 报 `object 'x' not found` | 公式里的变量不在数据框、也不在全局环境 | 检查列名；用 `data =` |
| `^` 写了却没平方项 | `^` 是交互阶数 | 用 `I(x^2)` 或 `poly(x, 2)` |
| 因子被当成连续变量 | 列是数值或字符 | `factor(x)`；用 `str()` 确认 |
| 系数出现 `NA` | 完全共线或虚拟变量陷阱 | 删掉冗余列；检查因子水平数 |
| 预测报"因子有新水平" | `newdata` 的水平集合与建模时不同 | 用 `levels()` 对齐 |
| `summary()` 的 p 值与 `anova()` 不一致 | 前者是偏 t 检验，后者是序贯检验 | 明确要检验的是哪一项 |
| 加入变量后系数符号翻转 | 共线性 | 看 `vif()`；不要单独解释系数 |
| 残差图有明显弯曲 | 模型设定不足 | 加二次项、交互或变换 |
