# 第十二章 报错与调试

## 一、消息的三类

R 把反馈分成三类：**错误**（Error）中止当前表达式，**警告**（Warning）继续执行但提示结果可能不可靠，**消息**（Message）只是提示，比如 `library()` 加载依赖包时的"载入需要的程序包"。警告默认会攒到当前顶层调用结束后一起打印，所以看到警告时，它对应的不一定是你刚敲的那一行。

```r
tryCatch(nosuchobject, error = function(e) conditionMessage(e))
#> [1] "找不到对象'nosuchobject'"
tryCatch(as.integer("x"), warning = function(w) conditionMessage(w))
#> [1] "强制改变过程中产生了NA"
```

本机的 R 使用中文 locale，部分报错被翻译成中文，而翻译后的措辞往往不利于搜索。需要英文原始信息时，在会话里临时切换语言：

```r
Sys.setenv(LANGUAGE = "en")
tryCatch("a" + 1, error = function(e) conditionMessage(e))
#> [1] "non-numeric argument to binary operator"
Sys.unsetenv("LANGUAGE")
```

也可以在 `.Renviron` 里固定 `LANGUAGE=en`。中文报错看懂即可，排查时用英文关键词去搜更容易找到答案。

## 二、常见报错对照

下表左列是本机实际输出的中文信息，右列是英文原文与常见原因。报错文本会随 R 版本和 locale 变化，判断时看的是"哪一类问题"，不是逐字匹配。

| 中文报错 | 英文原文 | 常见原因 | 处理 |
| :--- | :--- | :--- | :--- |
| `找不到对象'x'` | object 'x' not found | 变量名拼错、未赋值、作用域不对 | `ls()`、`exists("x")`；检查拼写 |
| `没有"f"这个函数` | could not find function "f" | 包未加载、函数名拼错 | `library()`；`??f` 搜索 |
| `二进列运算符中有非数值参数` | non-numeric argument to binary operator | 字符参与算术；因子被当数值 | `str()` 查类型；`as.numeric()` |
| `数学函数中用了非数值参数` | non-numeric argument to mathematical function | 同上，出现在 `log()`、`sqrt()` 等 | 同上 |
| `下标出界` | subscript out of bounds | 矩阵下标超过维度；列表取不存在的元素 | `dim()`、`length()` 检查 |
| `选择了未定义的列` | undefined columns selected | 列名不存在或拼错 | `names()` 查看真实列名 |
| `替换数据里有2行，但数据有3` | replacement has 2 rows, data has 3 | 赋值向量长度与行数不匹配 | 检查两边长度；用 `ifelse()` |
| `参数没有用(3)` | unused argument (3) | 多传了参数，或参数名拼错 | `args(f)` 看签名 |
| `需要TRUE/FALSE值的地方不可以用缺少值` | missing value where TRUE/FALSE needed | `if` 的条件是 `NA` | 先处理缺失值；`isTRUE()` |
| `条件的长度大于1`（英文） | the condition has length > 1 | `if` 收到向量 | 用 `ifelse()` 或 `all()`/`any()` |
| `对比只适用于因子` | contrasts can be applied only to factors | 对数值列取 `contrasts()` | 先 `factor()` |
| `系统正好是奇异的` | system is computationally singular | 矩阵不可逆、完全共线 | 删冗余列；`ginv()` |
| `非整合参数` | non-conformable arguments | 矩阵乘法维度不匹配 | `dim()` 检查左右矩阵 |
| `因子g里出现了新的水平c` | factor g has new levels c | `predict()` 的新数据有未见过的水平 | 用 `levels()` 对齐 |
| `无法打开链结` | cannot open the connection | 路径错、文件不存在、被占用 | `file.exists()`；关闭 Excel |
| `不存在叫'pkg'这个名称的程序包` | there is no package called 'pkg' | 包未安装或拼错 | `install.packages()` |
| `强制改变过程中产生了NA` | NAs introduced by coercion | 字符转数值失败 | 先清洗字符串 |
| `产生了NaNs` | NaNs produced | `log()` 负数、`sqrt()` 负数 | 检查定义域 |
| `长的对象长度不是短的对象长度的整倍数` | longer object length is not a multiple of shorter object length | 向量循环长度不整除 | 检查两边 `length()` |
| `拟合概率算出来是数值零或一` | fitted probabilities numerically 0 or 1 | logistic 完全分离 | 检查数据；正则化；精确检验 |

## 三、警告不能一律压掉

最常见的三条警告是：强制转换产生 `NA`、向量长度不整除、数学函数产生 `NaN`。它们都意味着"结果可能不是你想要的"，而不是"无关紧要"。不整除那条尤其危险，因为 R 仍然会算出一个结果。

```r
x <- c(1, 2, 3) + c(10, 20)
x
#> [1] 11 22 13
# 警告信息: 长的对象长度不是短的对象长度的整倍数
```

`suppressWarnings()` 只是把提示藏起来，不解决问题。确实确认无害时（例如 `as.numeric()` 已知会有无法解析项），也应先把脏数据挑出来，而不是事后压警告。

要看本轮攒下的所有警告，用 `warnings()`；把警告升级为错误，用 `options(warn = 2)`，适合批处理脚本：

```r
options(warn = 1)   # 立即打印，不等到调用结束
options(warn = 0)   # 恢复默认：攒到最后
```

## 四、调试工具

报错后第一件事是看调用栈。交互式会话里 `traceback()` 打印最近一次错误的调用链；脚本里可以在启动时设 `options(error = traceback)`，出错即打印。更深一层的交互式排查用 `recover()`，它会让你选择进入某一层调用环境。

在函数内部插 `browser()` 会停在那一行，进入调试提示符，可以逐句执行、查看变量；`debug(f)` 对函数 `f` 的每次调用开启调试，`debugonce(f)` 只调试一次，`undebug(f)` 取消。这些都需要交互式会话，批处理脚本里用不了。

```r
f <- function(x) {
  y <- x * 2
  if (y > 10) stop("y 太大了")
  y
}
tryCatch(f(6), error = function(e) conditionMessage(e))
#> [1] "y 太大了"
```

不打断执行地给出更清楚的错误信息，用 `stopifnot()` 做前置检查，用 `stop()` 主动报错，用 `warning()` 提示但不中止：

```r
check_positive <- function(x) {
  stopifnot(is.numeric(x), all(x > 0, na.rm = TRUE))
  sqrt(x)
}
tryCatch(check_positive(c(1, -2)), error = function(e) conditionMessage(e))
#> [1] "不是所有的all(x > 0, na.rm = TRUE)都是TRUE"
```

`tryCatch()` 用来捕获错误、警告或消息并做替代处理，`try()` 是它的简化版：出错时返回一个 `try-error` 对象，脚本继续跑。写循环批量拟合时，`try()` 能让一个失败的文件不拖垮整批任务：

```r
fit_one <- function(formula, data) {
  tryCatch(lm(formula, data = data), error = function(e) NULL)
}
res <- lapply(list(mtcars[1:5, ], mtcars), function(d) fit_one(mpg ~ wt, d))
sapply(res, is.null)
#> [1] FALSE FALSE
```

## 五、静默错误

比报错更麻烦的是不报错但结果错。下面几类在本课程的数据里都出现过：

| 现象 | 机制 | 检查方法 |
| :--- | :--- | :--- |
| 取到了别的列 | `$` 按前缀部分匹配 | 用 `[[` 或 `[, "完整名"]` |
| 因子当连续变量 | 数值编码的类别没转因子 | `str()`；`class()` |
| 因子转数值得到 1、2、3 | `as.numeric(factor)` 取编码 | `as.numeric(as.character(x))` |
| 浮点数比较为假 | `0.1 + 0.2 != 0.3` | `all.equal()` 或 `round()` |
| `attach()` 后变量被遮蔽 | 搜索路径上有同名对象 | 避免 `attach()`；用 `with()` |
| `T`、`F` 被重定义 | 它们是普通变量，可被赋值 | 写 `TRUE`、`FALSE` |
| `sample(5)` 返回 1:5 的排列 | 单个数值被当成 `1:n` | `sample(c(5), 1)` |
| 筛选后少了行 | 条件是 `NA` 的行被丢掉 | `sum(is.na(cond))` |
| 读入列名带点号 | `check.names = TRUE` 改了名 | 读入时设 `FALSE` |
| 模型系数出现 `NA` | 完全共线、秩亏 | `qr()$rank`；`alias()` |

## 六、排查流程

遇到跑不通的代码，按下面的顺序走，通常能在几分钟内定位：

第一步，**换一个干净会话**。用 `Rscript --vanilla` 或重启 R，确认问题不是上次残留的对象或选项造成的。

第二步，**确认工作目录和文件**。`getwd()`、`file.exists("data.csv")`、`list.files()` 三件事先做掉。

第三步，**检查数据**。`str()` 看类型，`dim()` 看维度，`names()` 看列名，`summary()` 看异常值，`anyNA()` 看缺失。

第四步，**二分定位**。把脚本从中间注释掉一半，看错误出现在哪一半，重复几次就能锁定到行。长脚本里这比逐行读快得多。

第五步，**构造最小复现**。把出错的那几行连同必要的变量单独拿出来，能复现就有救；不能复现，说明问题出在被省略的上下文里。

第六步，**记录环境**。`sessionInfo()` 给出 R 版本、平台和包版本，换机器或问别人时附上它。
