# 第七章 描述统计与分布函数

## 一、描述统计

一组数进来，先看位置和离散程度。`summary()` 一次给出五分位数与均值；`mean()`、`median()`、`sd()`、`var()`、`IQR()`、`range()` 分别取单个指标。所有这些函数遇到 `NA` 都返回 `NA`，除非加 `na.rm = TRUE`。

```r
x <- c(2, 4, 4, 4, 5, 5, 7, 9)
summary(x)
#>    Min. 1st Qu.  Median    Mean 3rd Qu.    Max. 
#>     2.0     4.0     4.5     5.0     5.5     9.0
c(mean = mean(x), median = median(x), sd = sd(x), var = var(x))
#>     mean   median       sd      var 
#> 5.000000 4.500000 2.138090 4.571429
IQR(x)
#> [1] 1.5
range(x)
#> [1] 2 9
```

`quantile()` 可以指定任意分位数，默认用类型 7（线性插值），与 `summary()` 的口径一致；`fivenum()` 给的是另一种口径（Tukey 的五数概括），两者在样本量小时可能不同。写作业报告时注明用的是哪一种。

```r
quantile(x, probs = c(0.1, 0.5, 0.9))
#>  10%  50%  90% 
#>  3.4  4.5  7.6
fivenum(x)
#> [1] 2.0 4.0 4.5 6.0 9.0
```

`scale()` 做中心化和标准化，返回矩阵而不是向量，且带 `scaled:center`、`scaled:scale` 两个属性：

```r
z <- scale(x)
z
#>            [,1]
#> [1,] -1.4031215
#> [2,] -0.4677072
#> [3,] -0.4677072
#> [4,] -0.4677072
#> [5,]  0.0000000
#> [6,]  0.0000000
#> [7,]  0.9354143
#> [8,]  1.8708287
#> attr(,"scaled:center")
#> [1] 5
#> attr(,"scaled:scale")
#> [1] 2.13809
```

需要普通向量时用 `as.numeric(z)`；需要还原时用 `z * attr(z, "scaled:scale") + attr(z, "scaled:center")`。`scale()` 默认对列操作，对矩阵会逐列标准化。

协方差与相关系数用 `cov()`、`cor()`，后者可选 `"pearson"`、`"spearman"`、`"kendall"`。含缺失值时 `use = "complete.obs"` 做配对删除：

```r
cor(mtcars$mpg, mtcars$wt)
#> [1] -0.8676594
cor(mtcars[, c("mpg", "wt", "hp")])
#>            mpg         wt         hp
#> mpg  1.0000000 -0.8676594 -0.7761684
#> wt  -0.8676594  1.0000000  0.6587479
#> hp  -0.7761684  0.6587479  1.0000000
```

## 二、频数表与列联表

`table()` 统计频数，`prop.table()` 转成比例，`addmargins()` 加行列合计。`prop.table()` 的第二个参数 `margin = 1` 按行求比例，`margin = 2` 按列；不写则按全表总数。

```r
tab <- table(mtcars$cyl, mtcars$am)
tab
#>    
#>      0  1
#>   4  3  8
#>   6  4  3
#>   8 12  2
prop.table(tab, margin = 1)
#>    
#>              0         1
#>   4 0.2727273 0.7272727
#>   6 0.5714286 0.4285714
#>   8 0.8571429 0.1428571
addmargins(tab)
#>      
#>        0  1 Sum
#>   4    3  8  11
#>   6    4  3   7
#>   8   12  2  14
#>   Sum 19 13  32
```

`xtabs()` 用公式写列联表，读起来更接近模型；`cut()` 把连续变量分组后再 `table()`：

```r
xtabs(~ cyl + am, data = mtcars)
#>    am
#> cyl  0  1
#>   4  3  8
#>   6  4  3
#>   8 12  2
table(cut(mtcars$mpg, breaks = c(0, 15, 25, 40)))
#> 
#>  (0,15] (15,25] (25,40] 
#>       6      20       6
```

## 三、分布函数

R 对每个常见分布提供四个函数，前缀含义固定：`d` 密度（或概率质量）、`p` 分布函数、`q` 分位数函数、`r` 随机数生成。参数名对应分布的参数，例如正态是 `mean`、`sd`，t 分布是 `df`，二项分布是 `size`、`prob`。

| 分布 | 名称 | 参数 | 密度函数 |
| :--- | :--- | :--- | :--- |
| 正态 | `norm` | `mean`, `sd` | `dnorm` |
| t | `t` | `df` | `dt` |
| 卡方 | `chisq` | `df` | `dchisq` |
| F | `f` | `df1`, `df2` | `df` |
| 二项 | `binom` | `size`, `prob` | `dbinom` |
| 泊松 | `pois` | `lambda` | `dpois` |
| 指数 | `exp` | `rate` | `dexp` |
| 均匀 | `unif` | `min`, `max` | `dunif` |
| 对数正态 | `lnorm` | `meanlog`, `sdlog` | `dlnorm` |

```r
dnorm(0)
#> [1] 0.3989423
pnorm(1.96)
#> [1] 0.9750021
qnorm(0.975)
#> [1] 1.959964
qt(0.975, df = 10)
#> [1] 2.228139
pchisq(3.84, df = 1, lower.tail = FALSE)
#> [1] 0.05004352
```

`lower.tail = FALSE` 表示求右尾概率 $P(X > x)$，默认是左尾 $P(X \le x)$。求 $t$ 分布的上侧临界值时这两种写法等价：`qt(0.975, 10)` 等于 `qt(0.025, 10, lower.tail = FALSE)`。

课程第一次作业里算过 `qt(0.005, 150, lower.tail = FALSE)`，它给出自由度为 150 的 $t$ 分布右尾 0.005 处的分位数，也就是 99% 双侧区间的临界值：

```r
qt(0.005, 150, lower.tail = FALSE)
#> [1] 2.609003
qt(0.995, 150)
#> [1] 2.609003
```

离散分布用 `dbinom()` 算概率质量、`pbinom()` 算累积概率：

```r
dbinom(2, size = 10, prob = 0.3)
#> [1] 0.2334744
pbinom(2, size = 10, prob = 0.3)
#> [1] 0.3827828
dpois(3, lambda = 2)
#> [1] 0.180447
pexp(1, rate = 2)
#> [1] 0.8646647
```

随机数生成先 `set.seed()` 固定种子，再调用 `r` 系列函数：

```r
set.seed(2026)
rnorm(5, mean = 10, sd = 2)
#> [1] 11.041178  7.840618 10.278476  9.830502  8.666721
```

## 四、抽样

`sample()` 从向量中有放回或无放回地抽，`sample.int()` 从 `1:n` 中抽。不等概率抽样用 `prob`；`replace = TRUE` 时才可能出现重复值。自助法（bootstrap）就是"有放回抽同样大小"。

```r
set.seed(7)
sample(1:10, size = 5)
#> [1] 10  3  7  4  2
sample(c("A", "B"), size = 10, replace = TRUE, prob = c(0.8, 0.2))
#>  [1] "A" "B" "A" "A" "A" "A" "A" "A" "A" "A"
```

> [!warning] `sample()` 的历史陷阱
>
> 当 `x` 是长度为 1 的数值时，`sample(x)` 会把 `x` 当成 `1:x` 的简写。`sample(5)` 返回的是 `1:5` 的一个全排列（五个数），而不是抽一个 5，也不是一个随机数。要抽一个数写 `sample(c(5), 1)` 或 `sample.int(5, 1)`。这个行为是为兼容旧代码保留的。

## 五、假设检验

`t.test()` 覆盖单样本、双样本与配对检验。单样本用 `mu` 给原假设均值；双样本可以给两个向量，也可以用公式 `y ~ g`；配对加 `paired = TRUE`。`alternative` 取 `"two.sided"`、`"greater"`、`"less"`，`conf.level` 控制置信水平。

```r
t.test(mtcars$mpg, mu = 20)
#> 
#> 	One Sample t-test
#> 
#> data:  mtcars$mpg
#> t = 0.08506, df = 31, p-value = 0.9328
#> alternative hypothesis: true mean is not equal to 20
#> 95 percent confidence interval:
#>  17.91768 22.26357
#> sample estimates:
#> mean of x 
#>  20.09062
```

双样本检验给两个向量或公式；方差是否齐性由 `var.equal` 控制，默认 `FALSE`（Welch 校正）：

```r
t.test(mpg ~ am, data = mtcars)
#> 
#> 	Welch Two Sample t-test
#> 
#> data:  mpg by am
#> t = -3.7671, df = 18.332, p-value = 0.001374
#> alternative hypothesis: true difference in means between group 0 and group 1 is not equal to 0
#> 95 percent confidence interval:
#>  -11.280194  -3.209684
#> sample estimates:
#> mean in group 0 mean in group 1 
#>        17.14737        24.39231
```

其他常用检验：`var.test()` 方差齐性，`chisq.test()` 列联表独立性，`fisher.test()` 小样本列联表，`prop.test()` 比例检验，`shapiro.test()` 正态性，`ks.test()` 分布拟合，`cor.test()` 相关系数检验。

```r
chisq.test(table(mtcars$cyl, mtcars$am))
#> 
#> 	Pearson's Chi-squared test
#> 
#> data:  table(mtcars$cyl, mtcars$am)
#> X-squared = 8.7407, df = 2, p-value = 0.01265
shapiro.test(mtcars$mpg)
#> 
#> 	Shapiro-Wilk normality test
#> 
#> data:  mtcars$mpg
#> W = 0.94756, p-value = 0.1229
```

方差分析用 `aov()`，结果交给 `summary()`：

```r
summary(aov(mpg ~ factor(cyl), data = mtcars))
#>             Df Sum Sq Mean Sq F value   Pr(>F)    
#> factor(cyl)  2  824.8   412.4    39.7 4.98e-09 ***
#> Residuals   29  301.3    10.4                     
#> ---
#> Signif. codes:  0 '***' 0.001 '**' 0.01 '*' 0.05 '.' 0.1 ' ' 1
```

检验结果本身是列表，可以取出具体分量，便于在报告里引用或做模拟：

```r
res <- t.test(mtcars$mpg, mu = 20)
c(p = res$p.value, lower = res$conf.int[1], upper = res$conf.int[2])
#>          p      lower      upper 
#>  0.9327606 17.9176785 22.2635715
```

样本量与功效用 `power.t.test()`，给定其中若干项可以反解其余项：

```r
power.t.test(n = 20, delta = 0.5, sd = 1, sig.level = 0.05,
             type = "one.sample")$power
#> [1] 0.5644829
```
