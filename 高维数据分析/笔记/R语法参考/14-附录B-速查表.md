# 附录 B　速查表

## 一、基本操作

| 目的 | 写法 |
| :--- | :--- |
| 赋值 | `x <- 1`（推荐）／`x = 1` |
| 查看对象 | `ls()`；`str(x)`；`class(x)`；`dim(x)`；`names(x)` |
| 删除对象 | `rm(x)`；`rm(list = ls())` |
| 判断存在 | `exists("x")` |
| 帮助 | `?lm`；`??regression`；`args(lm)`；`example(lm)` |
| 清屏 | 快捷键或 `cat("\014")` |
| 退出 | `q()` |

## 二、数据结构

| 结构 | 创建 | 取元素 |
| :--- | :--- | :--- |
| 向量 | `c(1, 2, 3)`；`1:5`；`seq(1, 9, 2)`；`rep(1:2, each = 3)` | `x[2]`；`x[-1]`；`x[x > 2]` |
| 矩阵 | `matrix(1:6, nrow = 2, byrow = TRUE)` | `A[i, j]`；`A[i, ]`；`A[, j, drop = FALSE]` |
| 数组 | `array(1:8, dim = c(2, 2, 2))` | `arr[, , 1]` |
| 数据框 | `data.frame(x = 1:3, y = c("a", "b", "c"))` | `d$x`；`d[, "x"]`；`d[i, ]`；`subset(d, x > 1)` |
| 列表 | `list(a = 1, b = 2)` | `l$a`；`l[["a"]]`；`l["a"]`（子列表） |
| 因子 | `factor(x, levels = c("低", "中", "高"))` | `levels(f)`；`as.integer(f)`；`table(f)` |

常用属性与转换：`length()`、`dim()`、`names()`、`rownames()`、`colnames()`、`as.numeric()`、`as.character()`、`as.factor()`、`as.data.frame()`、`unlist()`。

## 三、统计与分布

| 类别 | 函数 |
| :--- | :--- |
| 位置 | `mean()`、`median()`、`quantile(x, probs)`、`summary()` |
| 离散 | `sd()`、`var()`、`IQR()`、`mad()`、`range()` |
| 相关 | `cor()`、`cov()`、`cor.test()` |
| 标准化 | `scale(x)`（返回矩阵） |
| 频数 | `table()`、`prop.table()`、`addmargins()`、`xtabs(~ a + b, data)` |
| 分组 | `tapply(x, g, mean)`、`aggregate(y ~ g, data, mean)`、`split(x, g)` |
| 分布 | `dnorm`/`pnorm`/`qnorm`/`rnorm`，把 `norm` 换成 `t`、`chisq`、`f`、`binom`、`pois`、`exp`、`unif` |
| 临界值 | `qnorm(0.975)`；`qt(0.975, df)`；`qchisq(0.95, df)`；`qf(0.95, df1, df2)` |
| 检验 | `t.test()`、`var.test()`、`chisq.test()`、`fisher.test()`、`prop.test()`、`shapiro.test()`、`ks.test()` |
| 方差分析 | `aov(y ~ g, data)` + `summary()` |
| 抽样 | `sample(x, n, replace = TRUE, prob = NULL)`；`set.seed(1)` |

## 四、apply 家族

| 函数 | 输入 | 输出 |
| :--- | :--- | :--- |
| `apply(X, MARGIN, FUN)` | 矩阵/数组 | 向量或矩阵 |
| `lapply(X, FUN)` | 向量/列表 | 列表 |
| `sapply(X, FUN)` | 向量/列表 | 尽量简化成向量/矩阵 |
| `vapply(X, FUN, FUN.VALUE)` | 向量/列表 | 指定类型的向量 |
| `mapply(FUN, ...)` | 多个向量 | 向量 |
| `tapply(x, INDEX, FUN)` | 向量 + 因子 | 数组 |
| `replicate(n, expr)` | 表达式 | 向量/矩阵 |
| `Reduce(f, x)` | 二元函数 | 单个值 |
| `do.call(f, args)` | 函数 + 参数列表 | 调用结果 |

## 五、公式与建模

| 目的 | 写法 |
| :--- | :--- |
| 公式 | `y ~ x1 + x2`；`y ~ .`；`y ~ x - 1` |
| 交互 | `y ~ x * g`（主效应+交互）；`y ~ x:g`（仅交互） |
| 幂与多项式 | `I(x^2)`；`poly(x, 2)`；`poly(x, 2, raw = TRUE)` |
| 样条 | `splines::bs(x, df = 3)`；`splines::ns(x, df = 3)` |
| 拟合 | `lm(y ~ x, data = d)`；`glm(y ~ x, family = binomial, data = d)` |
| 摘要 | `summary(m)`；`coef(m)`；`confint(m)`；`vcov(m)`；`sigma(m)` |
| 提取 | `fitted(m)`；`residuals(m)`；`hatvalues(m)`；`cooks.distance(m)` |
| 比较 | `anova(m0, m1)`；`AIC(m0, m1)`；`BIC(m1)`；`drop1(m, test = "F")` |
| 选择 | `step(m, direction = "both")` |
| 更新 | `update(m, . ~ . - x)` |
| 预测 | `predict(m, newdata, interval = "confidence")`；`interval = "prediction"` |
| 诊断图 | `plot(m, which = 1:6)`；`car::residualPlots(m)`；`car::vif(m)` |

## 八、作业流程模板

```r
d <- mtcars
str(d)
m <- lm(mpg ~ wt + hp + factor(cyl), data = d)
summary(m)
anova(m)
op <- par(mfrow = c(2, 2))
plot(m)
par(op)
newd <- data.frame(wt = 3, hp = 120, cyl = factor(4, levels = c(4, 6, 8)))
predict(m, newdata = newd, interval = "prediction")
#>        fit      lwr      upr
#> 1 23.52741 18.11753 28.93728
```

## 九、报错关键词

| 关键词 | 先查什么 |
| :--- | :--- |
| `找不到对象` | 变量名拼写、是否已赋值、作用域 |
| `没有…这个函数` | 包是否 `library()`、函数名 |
| `非数值参数` | `str()` 看列类型、因子是否被当数值 |
| `下标出界` | `dim()`、`length()` |
| `选择了未定义的列` | `names()` |
| `奇异` | 共线性、`p > n`、常数列 |
| `新的水平` | `predict()` 的 `newdata` 因子水平 |
| `无法打开` | `getwd()`、`file.exists()`、文件占用 |
| `产生了NA` | 字符转数值失败，先清洗数据 |
