# 第十一章 降维与矩阵运算

## 一、从矩阵看高维问题

回归的设计矩阵 $\mathbf{X}$ 是 $n\times p$。当 $p$ 接近或超过 $n$，或者列之间高度相关时，$\mathbf{X}^{\top}\mathbf{X}$ 接近奇异，`solve()` 会直接报错。先看两个诊断量：矩阵的**秩**（`qr()$rank`）与**条件数**（`kappa()`）。条件数越大，解对数据的微小扰动越敏感。

```r
set.seed(1)
Xb <- matrix(rnorm(100), nrow = 5)
yb <- rnorm(5)
dim(Xb)
#> [1]  5 20
qr(Xb)$rank
#> [1] 5
try(solve(crossprod(Xb)))
#> Error in solve.default(crossprod(Xb)) : 
#>   系统计算上是奇异的: 倒条件数=1.71395e-19
```

$5\times20$ 的矩阵秩最多是 5，$\mathbf{X}^{\top}\mathbf{X}$ 是 $20\times20$ 但秩只有 5，当然不可逆。此时有两种出路：用广义逆求最小范数解，或者加正则项。`MASS::ginv()` 给 Moore-Penrose 广义逆：

```r
library(MASS)
dim(ginv(Xb))
#> [1] 20  5
mfit <- lm(yb ~ Xb)
sum(is.na(coef(mfit)))
#> [1] 16
```

`lm()` 不会报错，而是用 QR 分解选出 5 个线性无关的列，其余 16 个系数记为 `NA`。看到大量 `NA` 系数，说明设计矩阵秩亏，不是数据坏了。

## 二、特征分解与奇异值分解

对称矩阵用 `eigen()` 做特征分解，返回特征值（降序）与特征向量。任意矩阵用 `svd()` 做奇异值分解 $\mathbf{X}=\mathbf{U}\mathbf{D}\mathbf{V}^{\top}$，`d` 是奇异值向量。对中心化后的数据矩阵，奇异值的平方除以 $n-1$ 就是各主成分的方差。

```r
X <- matrix(c(2, 1, 1, 2), nrow = 2)
eigen(X)$values
#> [1] 3 1
svd(X)$d
#> [1] 3 1
kappa(X)
#> [1] 3.5
```

`kappa()` 是最大奇异值与最小奇异值之比。经验上条件数超过 30 就提示共线性，超过 1000 时数值结果已不可靠。标准化会改变条件数，这也是建模前常做中心化、标准化的原因之一：

```r
kappa(mtcars[, c("mpg", "disp", "hp")])
#> [1] 19.11717
kappa(scale(mtcars[, c("mpg", "disp", "hp")]))
#> [1] 4.207799
```

## 三、主成分分析

`prcomp()` 用奇异值分解实现 PCA，数值上比 `princomp()`（对协方差矩阵做特征分解）更稳定，优先用它。参数 `center = TRUE`、`scale. = TRUE` 表示先中心化再标准化；只中心化不标准化时，方差大的变量会主导第一主成分。

```r
vars <- c("mpg", "disp", "hp", "wt", "qsec")
p <- prcomp(mtcars[, vars], center = TRUE, scale. = TRUE)
summary(p)
#> Importance of components:
#>                           PC1    PC2     PC3     PC4     PC5
#> Standard deviation     1.9227 0.9803 0.39310 0.36215 0.23764
#> Proportion of Variance 0.7394 0.1922 0.03091 0.02623 0.01129
#> Cumulative Proportion  0.7394 0.9316 0.96247 0.98871 1.00000
```

对象里有五个常用分量：`sdev` 是各主成分的标准差，`rotation` 是载荷矩阵（每列一个主成分，行是原变量），`x` 是得分矩阵（每行一个样本），`center` 与 `scale` 记录预处理用的均值与标准差：

```r
p$sdev
#> [1] 1.9227127 0.9803146 0.3931047 0.3621521 0.2376418
round(p$rotation[, 1:2], 3)
#>        PC1    PC2
#> mpg  -0.484 -0.179
#> disp  0.490  0.171
#> hp    0.475 -0.281
#> wt    0.453  0.464
#> qsec -0.308  0.803
head(round(p$x[, 1:2], 3), 3)
#>                 PC1    PC2
#> Mazda RX4    -0.644 -0.881
#> Mazda RX4 Wag -0.622 -0.509
#> Datsun 710   -1.621 -0.113
```

第一主成分在 `disp`、`hp`、`wt` 上载荷为正，在 `mpg`、`qsec` 上为负，可以解释为"车重与动力"对"油耗与加速"的对比轴。载荷的**正负号是任意的**：整体乘以 -1 后，得分也整体变号，方差解释比例不变，解释时只需保持前后一致。

保留几个主成分，看方差累计比例与碎石图。常用三条依据：累计方差达到 80%–90%、碎石图拐点、特征值大于 1（对标准化数据）：

```r
screeplot(p, type = "lines", main = "碎石图")
biplot(p, main = "PCA 双标图")
```

`predict(p, newdata)` 把新样本投影到已有主成分上，用的是训练时的中心与尺度，不会重新计算：

```r
dim(predict(p, newdata = mtcars[1:5, vars]))
#> [1] 5 5
```

> [!warning] 主成分不是原始变量
>
> 主成分是原变量的线性组合，系数可正可负，通常没有直接业务含义。用主成分做解释时，要回到载荷矩阵说明"这个成分主要由哪几个变量构成、方向如何"，不能写成"PC1 是车重"。

## 四、主成分回归

样本量小、变量多且高度相关时，可以先用前几个主成分作为自变量做回归，这就是主成分回归（PCR）。它解决共线性，代价是主成分的选择带有主观性，且丢弃的成分里可能含有与响应相关的信息。

```r
z <- p$x[, 1:2]
m <- lm(mtcars$mpg ~ z)
coef(m)
#> (Intercept)        zPC1        zPC2 
#>  20.090625   -2.918231   -1.080015
summary(m)$r.squared
#> [1] 0.8975691
```

用两个主成分解释了约 89.8% 的油耗变异，而五个原始变量全放进去的模型 $R^2$ 约为 0.90，说明降维损失很小。注意这里的 `z` 已经是得分，回归的系数是"主成分每变化一个单位"的效果，不能直接和原始变量的系数比较。

## 五、其他降维与分类方法

`cmdscale()` 做经典多维标度（MDS），输入是距离矩阵，输出是低维坐标，使点间距离尽量保持：

```r
dmat <- dist(USArrests)
mds <- cmdscale(dmat, k = 2)
dim(mds)
#> [1] 50  2
```

`MASS::lda()` 做线性判别分析，同时完成降维与分类。`lda()` 返回的 `svd` 是判别方向上的奇异值，`predict()` 给出类别与后验概率：

```r
ld <- lda(Species ~ ., data = iris)
ld$svd
#> [1] 48.642644  4.579983
table(predict(ld)$class, iris$Species)
#>             
#>              setosa versicolor virginica
#>   setosa         50          0         0
#>   versicolor      0         48         1
#>   virginica       0          2        49
```

层次聚类用 `hclust(dist(x))` 配 `cutree()`，$k$ 均值用 `kmeans(x, centers = k)`，它们与 PCA 同属无监督方法，但目标不同：PCA 保留方差，聚类保留"分组结构"。课程后续会分别展开。

## 六、常见问题

| 现象 | 原因 | 处理 |
| :--- | :--- | :--- |
| `solve()` 报奇异矩阵 | 共线、$p>n$、常数列 | 删冗余列；`ginv()`；正则化 |
| 系数大量 `NA` | 设计矩阵秩亏 | `qr()$rank` 检查；精简变量 |
| 第一主成分几乎等于某个变量 | 未标准化，方差大的变量主导 | `scale. = TRUE` |
| 载荷符号换了 | 特征向量方向不唯一 | 解释时固定方向，或以某个载荷为正 |
| 方差解释比例之和不等于 1 | 只取了部分主成分 | 看 `summary(p)` 的累计比例 |
| `princomp` 与 `prcomp` 结果略有差异 | 算法不同（相关阵 vs SVD） | 统一用 `prcomp` |
| 新样本投影结果异常 | `newdata` 列顺序或列名与训练不一致 | 用同一组变量名与顺序 |
