# 第十章 回归诊断与结果解读

## 一、诊断看什么

线性回归的推断依赖几条假设：误差与解释变量无关、误差同方差、误差近似正态、观测相互独立，以及模型形式（线性、可加）设定正确。诊断图不能"证明"假设成立，只能暴露明显违反；它也不能替代对数据来源和变量含义的判断。

诊断要区分三类问题：**模型形式不对**（残差有弯曲、漏斗形）、**个别点影响过大**（高杠杆、强影响点）、**推断前提不满足**（正态性、独立性）。处理方法不同，先分清再动手。

## 二、`plot(m)` 的六张图

对 `lm` 对象调用 `plot()` 会画诊断图。默认只画四张（`which = c(1, 2, 3, 5)`），要看全部六张用 `which = 1:6`：

```r
d <- transform(mtcars, cyl = factor(cyl))
m <- lm(mpg ~ wt + hp + cyl, data = d)
library(car)
op <- par(mfrow = c(2, 3), mar = c(4, 4, 2, 1))
plot(m, which = 1:6)
par(op)
```

六张图分别看：

| `which` | 图 | 看什么 |
| :--- | :--- | :--- |
| 1 | 残差 vs 拟合值 | 有没有弯曲（非线性）、漏斗（异方差） |
| 2 | 正态 Q-Q 图 | 点是否沿直线分布；两端偏离说明尾部厚 |
| 3 | 尺度-位置图 | $\sqrt{\lvert\text{标准化残差}\rvert}$ 与拟合值是否同水平 |
| 4 | Cook 距离 | 哪些点对系数影响大 |
| 5 | 残差 vs 杠杆值 | 高杠杆点与强影响点，图上带 Cook 等值线 |
| 6 | Cook 距离 vs 杠杆值 | 同时看影响与杠杆 |

读图的基本判断：图 1 出现明显 U 形或倒 U 形，说明应加二次项或对自变量做变换；出现"喇叭口"，说明方差不齐，可考虑对响应变量取对数或加权最小二乘；图 2 两端翘起说明残差厚尾，样本量小时会削弱 t 检验的可靠性；图 5 中落在虚线等值线外侧的点需要逐个检查。

## 三、数值诊断

图给印象，数值给依据。杠杆值、Cook 距离、学生化残差都能直接取出：

```r
head(hatvalues(m), 3)
#>     Mazda RX4 Mazda RX4 Wag    Datsun 710 
#>    0.16766369    0.15142749    0.09357006
which.max(cooks.distance(m))
#> Chrysler Imperial 
#>                17
max(cooks.distance(m))
#> [1] 0.261744
```

经验判据：杠杆值 $h_i$ 的平均值是 $p/n$，超过 $2p/n$ 或 $3p/n$ 就值得注意；Cook 距离大于 1 通常认为影响很大，也有用 $4/n$ 作宽松门槛的。这些阈值只是筛查线，不是"超过就必须删点"的规定。

`influence.measures()` 一次给出 DFBETAS、DFFITS、协方差比、Cook 距离和杠杆值；`car::outlierTest()` 用学生化残差做 Bonferroni 校正的离群点检验；`shapiro.test()` 对残差做正态性检验：

```r
influence.measures(m)$infmat[1:2, c("dfb.1_", "dffit", "cook.d", "hat")]
#>                     dfb.1_       dffit       cook.d       hat
#> Mazda RX4     -0.042743733 -0.12054965 0.0030098781 0.1676637
#> Mazda RX4 Wag  0.008189187  0.03739412 0.0002903329 0.1514275
outlierTest(m)
#> No Studentized residuals with Bonferroni p < 0.05
#> Largest |rstudent|:
#>                rstudent unadjusted p-value Bonferroni p
#> Toyota Corolla 2.586738           0.015639      0.50044
shapiro.test(residuals(m))
#> 
#> 	Shapiro-Wilk normality test
#> 
#> data:  residuals(m)
#> W = 0.95228, p-value = 0.1673
```

`outlierTest()` 的结论是"没有 Bonferroni 校正后显著的离群点"，最大学生化残差 2.59 未经校正时 p 约 0.016，校正后为 0.50。写报告时要说明用的是哪一种口径。

## 四、针对具体假设的检验

**非线性**用成分残差图（component-plus-residual plot）和残差弯曲检验。`residualPlots()` 对每个数值自变量做弯曲检验，并画成分残差图：

```r
residualPlots(m)
#>            Test stat Pr(>|Test stat|)   
#> wt            2.1693         0.039388 * 
#> hp            1.6485         0.111274   
#> cyl                                     
#> Tukey test    2.7228         0.006473 **
```

`wt` 项的弯曲检验 p 约 0.039，提示线性设定可能不足；Tukey 检验整体 p 约 0.006，也指向同样结论。此时应尝试 `I(wt^2)` 或样条，而不是直接接受原模型。

**异方差**用 `ncvTest()`（Breusch-Pagan 类检验）和 `spreadLevelPlot()`；**自相关**用 `durbinWatsonTest()`，适用于时间顺序明确的数据；**共线性**用 `vif()`，因子会按自由度给出 GVIF：

```r
set.seed(1)
ncvTest(m)
#> Non-constant Variance Score Test 
#> Variance formula: ~ fitted.values 
#> Chisquare = 3.374465, Df = 1, p = 0.066214
durbinWatsonTest(m)
#>  lag Autocorrelation D-W Statistic p-value
#>    1      0.07434128      1.789949   0.378
#>  Alternative hypothesis: rho != 0
vif(m)
#>        GVIF Df GVIF^(1/(2*Df))
#> wt  2.580877  1        1.606511
#> hp  3.496014  1        1.869763
#> cyl 5.105811  2        1.503198
```

`durbinWatsonTest()` 的 p 值来自重抽样，不设种子时每次运行会略有不同；要复现就加 `set.seed()`。

VIF 的常用经验线是 5 或 10；对带自由度的 GVIF，看最后一列 $\mathrm{GVIF}^{1/(2\,df)}$，超过约 $\sqrt{5}\approx 2.24$ 才算值得处理。这里 `wt`、`hp` 的 GVIF 都低于 5，共线性不严重。

## 五、诊断图的替代读法

`car` 包提供几个更直观的图：`crPlots(m)` 画成分残差图，直接看每个自变量与响应的边际关系是否线性；`avPlots(m)` 画偏回归图（added-variable plot），看"控制其他变量后"该变量的作用；`influenceIndexPlot(m)` 把杠杆、Cook 距离、学生化残差画在同一组图上，便于定位行号。

```r
crPlots(m)
avPlots(m)
influenceIndexPlot(m)
qqPlot(residuals(m))
```

`qqPlot()` 是 `car` 版的正态 Q-Q 图，带置信带，比 `plot(m, which = 2)` 更容易判断偏离是否显著。它会把落在置信带外的点作为返回值打印出来，形式是行名加行号，可以直接用来定位观测。

## 六、结果怎么写

一段完整的回归结果解读应包含五件事：模型整体是否显著、哪些系数显著、系数的大小与方向、拟合优度、诊断结论与局限。以本节模型为例：

> 以 `mpg` 为响应变量，`wt`、`hp` 与气缸数 `cyl` 为解释变量拟合线性模型，整体 F 检验显著（$F=40.53$，$p<0.001$），$R^2=0.857$，调整后 $R^2=0.836$。在控制其他变量后，车重每增加 1000 磅，油耗平均下降 3.18 mpg（95% CI：-4.66 至 -1.70）；马力每增加 1 单位，油耗平均下降 0.023 mpg，但在 5% 水平上不显著（$p=0.064$）。以 4 缸车为基准，6 缸车平均低 3.36 mpg（$p=0.024$），8 缸车的差异不显著（$p=0.154$）。残差诊断未发现明显的异方差或强影响点，但 `wt` 项存在弯曲迹象（$p=0.039$），提示线性设定可能不足，后续可尝试二次项或样条。

这段话里的每个数字都来自模型对象，不靠肉眼从图里估。注意三点：系数解释必须带"控制其他变量"；不显著的系数不等于"没有影响"；$R^2$ 高不等于模型正确，也不等于因果。

## 七、样本外评估

$R^2$、AIC 都是样本内指标。要判断预测能力，应划分训练集与测试集，或做交叉验证。最简单的单次划分：

```r
set.seed(1)
n <- nrow(mtcars)
idx <- sample(n, size = round(0.7 * n))
train <- mtcars[idx, ]
test <- mtcars[-idx, ]
fit <- lm(mpg ~ wt + hp, data = train)
pred <- predict(fit, newdata = test)
sqrt(mean((test$mpg - pred)^2))
#> [1] 3.1455
mean(abs(test$mpg - pred))
#> [1] 2.50843
```

RMSE 与响应变量同单位，MAE 对极端误差不如 RMSE 敏感。单次划分的方差很大，报告时最好重复多次或做 $k$ 折交叉验证，给出均值与标准差，而不是只报一个数。

## 八、常见问题

| 现象 | 可能原因 | 处理 |
| :--- | :--- | :--- |
| 残差图呈 U 形 | 漏了二次项或交互 | 加 `I(x^2)`、`poly()` 或交互项 |
| 残差呈漏斗形 | 异方差 | 变换响应变量；加权最小二乘；稳健标准误 |
| Q-Q 图两端偏离 | 厚尾或离群点 | 检查离群点；样本大时可依赖渐近性质 |
| 某点 Cook 距离很大 | 强影响点 | 核对数据录入；报告删除前后结果 |
| 杠杆值普遍偏高 | 参数过多、样本过少 | 精简模型；谨慎解释 |
| VIF 很高 | 共线性 | 删变量、合并变量或做主成分回归 |
| D-W 检验显著 | 残差自相关 | 时间序列模型；广义最小二乘 |
| 训练 $R^2$ 很高但预测差 | 过拟合 | 交叉验证；正则化 |
