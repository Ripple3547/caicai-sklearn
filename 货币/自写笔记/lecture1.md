联邦储备包括资产和负债。

负债分为**流通中的现金 Cash** 和**准备金 Reserves**
- 流通中的现金，即货币，公众持有
- 准备金包括银行在美联储的存款和银行持有的现金，是银行的资产和美联储的负债。
- 基础货币 MB = C + R
- C 和 R 之间可以相互转换

准备金分为两类
1. 法定准备金 **RR**，美联储规定银行持有
2. 超额准备金 **ER**，银行自愿持有
3. 存款机构每吸收一单位的存款，需要将其中的一部分以**准备金**形式持有，该比率称为**法定准备金率**

资产：
1. **证券**，美联储通过购买证券为银行提供准备金
2. 向金融机构发放的**贷款**，发放贷款也可以提供准备金。金融机构借入的贷款称为**贴现贷款**，其利率称为**贴现率**

公开市场操作
- 公开市场购买
- 公开市场出售

基础货币的增加可由 C 和 R 导致
- 公众卖出证券，无银行参与，C 增加
- 银行参与，R 增加

MB = MB<sub>n</sub> + BR
- MB<sub>n</sub> 为非借入基础货币，主要来自公开市场操作
- BR 为借入准备金，银行向美联储的借款

现金流损、法定准备金的留存会使得多倍存款创造的过程受阻，无法达到理想的创造量



现金留存越多、法定存款准备金率越高、非借入基础货币/借入准备金越少，最终的存款减少，存款创造倍数减小。

货币供给 M；基础货币 MB = C + R = MB<sub>n</sub> + BR
