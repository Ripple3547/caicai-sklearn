# 五、长期的 IS–LM 模型

> [!info] 范围与记号
>
> 本节对应课件 P28–P32，讨论物价水平由固定转为可调整之后，IS–LM 的均衡如何变化。前四节把价格视为给定，本节放开这一假定。记号沿用前文：$Y$ 为实际产出，$i$ 为利率，$P$ 为物价水平，$\bar M$ 为名义货币供给，$\bar M/P$ 为实际货币余额，$k$ 与 $h$ 分别为货币需求对收入与利率的敏感度，$Y_n$ 为自然产出水平（*natural output level*）。

| 小节 | 核心问题 |
| :--- | :--- |
| 1. 价格作为长期调节变量 | 短期与长期的分界由哪个变量承担 |
| 2. 扩张性货币政策的长期结果 | 货币供给增加为何不能提高长期产出 |
| 3. 扩张性财政政策的长期结果 | 财政扩张的产出效应为何被价格抵消 |
| 4. 长期货币中性与政策的时间维度 | 两种政策的长期效力如何统一表述 |

## 1. 价格作为长期调节变量

前四节的分析都假定物价水平固定，产出由总需求单方面决定，这对应价格尚未调整的短期。到了长期，价格有足够的时间调整，于是它从给定参数变为**调节变量**（*adjusting variable*），产出也不再由需求单方面决定（课件 P28）。

调整方向由产出与自然产出水平的缺口决定。当 $Y>Y_n$，总需求强于经济的供给能力，物价上升；当 $Y<Y_n$，需求不足，物价下跌。也就是说，价格变动的方向取决于 $Y-Y_n$ 的符号，而它的作用总是缩小这一缺口。

前四节的商品市场与货币市场条件可以改写成以利率为因变量的形式，即 (1) 式与 (2) 式。其中 $\bar C$、$\bar I$、$\bar G$、$\bar T$ 与 $\overline{NX}$ 分别为自主性消费、自主性投资、政府购买、税收与自主性净出口，$f$ 为金融摩擦，$mpc$ 为边际消费倾向，$d$ 与 $x$ 分别为投资与净出口对利率的敏感度，$b=d+x$。

$$i=\frac{\bar C+\bar I-df+\bar G+\overline{NX}-mpc\,\bar T}{d+x}-\frac{1-mpc}{d+x}Y \tag{1}$$

$$i=\frac{1}{h}\left(kY-\frac{\bar M}{P}\right) \tag{2}$$

(1) 式的截距由自主性支出 $A=\bar C+\bar I-df+\bar G+\overline{NX}-mpc\,\bar T$ 与 $b$ 共同决定，斜率为 $-(1-mpc)/b$；(2) 式则表明，给定收入与实际货币余额，货币市场只对应一个利率。$k$ 越大，收入上升引起的货币需求增加越多；$h$ 越大，吸收同样的货币需求变动所需的利率调整越小。

关键在于**价格只进入 LM 而不进入 IS**。IS 曲线由实际变量决定，物价不在其中；LM 曲线的位置取决于 $\bar M/P$，物价上升使实际货币余额下降，LM 左移。因此长期调整的全部传导都经过实际货币余额这一项，IS 曲线在调整过程中保持不动。

> [!tip] 要点
>
> 长期分析与短期分析的差别不在方程，而在哪一个变量被允许调整：短期固定价格、让产出调整，长期固定自然产出、让价格调整。两组方程完全相同，结论的差异来自调整对象的不同。

## 2. 扩张性货币政策的长期结果

设初始均衡位于 $Y=Y_n$、利率为 $i_0$。货币当局增加名义货币供给，$\bar M$ 上升使 $\bar M/P$ 在原有价格下上升，由 (2) 式 LM 右移。短期均衡移动到更高的产出与更低的利率，记这一产出为 $Y_2$，则 $Y_2>Y_n$（课件 P30）。

产出高于自然水平，价格开始上升。价格上升使 $\bar M/P$ 下降，LM 随之左移，产出与利率回移。这一过程持续到产出回到 $Y_n$ 为止；此时的价格水平 $P'$ 满足 $\bar M'/P'=\bar M/P$，即价格与货币供给同比例上升。

于是长期结果是：产出回到自然水平，利率回到 $i_0$，实际货币余额不变，唯一变化的是物价水平。这一性质称为**长期货币中性**（*long-run monetary neutrality*，课件 P32）。

> [!warning] 注意
>
> LM 右移是短期现象。价格上升会把 LM 推回原位，两条曲线的交点最终落回自然产出水平；把短期交点当作长期结果，就会得出货币供给可以永久提高产出的结论。

货币政策的长期基准由此确定，下一节讨论财政政策时，只需把被移动的曲线从 LM 换成 IS。

## 3. 扩张性财政政策的长期结果

政府购买增加使 (1) 式中的 $\bar G$ 上升，IS 右移，短期产出升至 $Y_2>Y_n$，利率上升。产出高于自然水平，价格随之上扬，$\bar M/P$ 下降，LM 左移，产出回落到 $Y_n$（课件 P31）。

与货币政策不同的是，长期均衡的利率不再回到 $i_0$。IS 已经右移，在 $Y=Y_n$ 处对应的利率比初始水平高 $\Delta G/b$；这一利率变化代入投资函数与净出口函数后，得到 (3) 式。

$$\Delta I+\Delta NX=-d\cdot\frac{\Delta G}{d+x}-x\cdot\frac{\Delta G}{d+x}=-\Delta G \tag{3}$$

也就是说，投资与净出口合计减少的规模正好等于政府支出的增量。财政扩张在长期被价格上升完全抵消：产出回到 $Y_n$，留下的是更高的物价、更高的利率与更低的私人投资。这一结果称为**完全挤出**（*complete crowding out*）。

> [!warning] 注意
>
> 长期无效不等于政策没有作用。财政扩张在短期改变了产出与利率，在长期改变了物价与利率结构，只是不能改变自然产出水平；长期结论界定的是政策的边界，而非否定其短期功能。

两种政策的差别因此集中到一点：长期中移动的是哪一条曲线。

## 4. 长期货币中性与政策的时间维度

两种政策在长期收敛到同一产出水平，但路径与终值不同。货币扩张只改变物价，利率与实际货币余额回到原值；财政扩张同时改变物价与利率，实际货币余额下降，私人投资被政府支出取代。这一对照归纳为表 1。

表 1　两种政策的短期与长期效应

| 项目 | 扩张性货币政策 | 扩张性财政政策 |
| :--- | :--- | :--- |
| 短期产出 | 高于 $Y_n$ | 高于 $Y_n$ |
| 短期利率 | 下降 | 上升 |
| 长期产出 | 回到 $Y_n$ | 回到 $Y_n$ |
| 长期利率 | 回到原水平 | 高于原水平 |
| 长期物价 | 同比例上升 | 上升 |
| 长期实际货币余额 | 不变 | 下降 |
| 长期私人投资 | 不变 | 减少 |

表 1 中两种政策的长期差异，根源在于 IS 是否移动。货币政策只移动 LM，价格调整把 LM 推回原位，实际变量于是全部复原；财政政策移动了 IS，价格调整只能把经济推回自然产出，无法把 IS 推回原位，利率与投资结构因此发生永久变化。

由此得到本节的方法论结论：短期比较静态（*comparative statics*）回答的是政策能否改变当期产出，长期分析回答的是政策能否改变自然产出。**两者不是同一问题的两个不同答案，而是两个不同问题的答案**；混淆二者，就会把短期有效的政策误判为长期有效。

> [!tip] 要点
>
> 长期分析的全部机制可以写成一条链：产出缺口决定物价方向，物价通过实际货币余额决定 LM 位置，LM 位置把产出推回自然水平。IS 曲线在这一过程中不动，这是价格只影响 LM 的直接推论。

每一个物价水平对应的 IS–LM 均衡产出连起来，就是下一节的总需求曲线；长期分析因此成为从短期均衡走向总需求曲线的中间一步。
