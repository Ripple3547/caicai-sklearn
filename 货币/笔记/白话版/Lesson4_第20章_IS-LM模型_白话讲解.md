## 0. 三分钟速览：这一章在讲什么

这一章要回答两个问题：**一个国家一年能卖出多少东西（产出 Y），以及利率 i 由什么决定。** 答案是两个市场同时均衡。

**第一个市场：商品市场。** 一年生产出来的东西，要有人买。买的人有四类：家庭买消费品、企业买设备建厂房、政府买办公用品发工资、外国人对本国产品的净购买（出口减进口）。这四类人**打算**花的钱加起来叫**计划支出**（Y^ad），也就是总需求。如果生产出来的正好被买走，企业就没有理由增产或减产，这就叫均衡。这里的关键是：**计划支出取决于利率**。利率高，企业借钱买设备不划算，投资就少；利率高，外资想进来，本币升值，出口就少。所以在利率高的时候，均衡的产出就低。把"每个利率对应的均衡产出"画成一条线，就是 **IS 曲线**，它向下倾斜。

**第二个市场：货币市场。** 人们手里要留多少现金，取决于两件事：要花多少钱（收入 Y），以及留着现金少赚多少利息（利率 i）。收入越高，要留的现金越多；利率越高，愿意留的越少。央行的货币供给是给定的，所以当收入上升、大家想多留现金时，只能靠利率上升来让大家少留一点。把"每个收入对应的均衡利率"画成一条线，就是 **LM 曲线**，它向上倾斜。

**交点**：两条线的交点，是唯一一个同时让商品市场和货币市场都均衡的（产出，利率）组合。

**这一章的意义**：它让"利率"和"产出"互相决定，从而能分析两件事——政府增加支出会怎样，央行增加货币会怎样。

## 1. 先把字母认全

### 1.1 四条记号规则（先看这个）

1. **字母上面加一横 = 这个数被假定为固定不变**，由模型外面给定，不由模型算出来。读作"某某 bar"。例如 C̄ 读"C bar"，意思是"这部分消费是给定的，不随收入变"。
2. **没有横线的字母 = 由模型内部算出来的**。例如 C 是自己会随收入变化的消费。
3. **上标和下标都是英文单词的缩写**，不是运算。Y^ad 的 ad = aggregate demand（总需求）；Y_D 的 D = disposable（可支配）；M^d 的 d = demand（需求）；M^s 的 s = supply（供给）。
4. **右上角加星号 = 均衡值**，例如 Y*、i* 就是模型解出来的均衡产出和均衡利率；**Δ（读"德尔塔"）= 变化量**，例如 ΔY 表示"产出变了多少"，ΔG 表示"政府购买变了多少"。

前两条合起来叫"横线规则"，非常有用：看到一个公式，先看哪些字母带横线，就知道哪些是政府或外部给定的，哪些是要解出来的。

### 1.2 字母表

| 符号 | 怎么读 | 白话意思 | 谁决定它 |
|---|---|---|---|
| Y | 歪 | **总产出**，也等于**总收入**。一个国家一年生产出来的最终产品和服务总量（用钱衡量） | 模型解出来 |
| Y^ad | "Y ad" | **计划支出 / 总需求**：家庭、企业、政府、外国人**打算**花在国内产品上的钱 | 模型解出来 |
| Y_D | "Y D" | **可支配收入**：交完税以后自己能安排的那部分收入，Y_D = Y − T | 由 Y 和 T 决定 |
| C | 西 | **消费支出**：家庭买消费品和服务的钱 | 随收入变 |
| C̄ | "C bar" | **自主性消费**：跟当前收入无关的那部分消费。哪怕这个月没收入，饭也要吃、房租也要交；对未来的信心、家里的存款也会影响它 | 外部给定（外生） |
| mpc | 读字母 | **边际消费倾向**：可支配收入每多 1 元，会多花掉多少元。是一个 0 到 1 之间的常数 | 参数 |
| I | 艾 | **计划投资支出**：企业买设备、建厂房、买新住宅的钱，加上存货增加 | 随利率变 |
| Ī | "I bar" | **自主性投资**：跟产出、利率都无关的那部分投资，由企业对未来的信心决定 | 外部给定 |
| d | 迪 | **投资对利率的敏感程度**：利率每上升 1 个单位，投资减少多少个单位 | 参数 |
| i | 艾 | **利率**。课件里也写作 r，指借钱要付的百分比 | 货币市场决定，央行影响 |
| r_i | "r 下标 i" | **投资实际面对的借款利率**，等于 i + f | 由 i 和 f 决定 |
| f | 艾弗 | **金融摩擦**：银行因为搞不清借款人靠不靠谱，在无风险利率之上额外多收的那一块 | 金融体系状况 |
| G / Ḡ | "G"、"G bar" | **政府购买**：政府买产品和服务、给公务员发工资的支出。不含养老金、低保这类转移支付 | 政策决定（外生） |
| T / T̄ | "T"、"T bar" | **税收总额**。课件里假设是定额税，跟收入无关 | 政策决定（外生） |
| NX | "N X" | **净出口** = 出口 − 进口 | 随利率变 |
| NX̄ | "NX bar" | **自主性净出口**：跟利率无关的那部分净出口，由外国人的需求决定 | 外部给定 |
| x | 艾克斯 | **净出口对利率的敏感程度**：利率每上升 1 个单位，净出口减少多少 | 参数 |
| A | 诶 | **自主性支出**：计划支出里跟收入和利率都无关的那一大块。A = C̄ + Ī − d·f + Ḡ + NX̄ − mpc·T̄ | 由上面几个外生量合成 |
| b | 比 | **支出对利率的总敏感程度**，b = d + x：利率上升 1 个单位，投资少 d、净出口少 x，总需求一共少 b | 由 d 和 x 合成 |
| α | 阿尔法 | **支出乘数**，α = 1 ÷ (1 − mpc)。自主性支出每增加 1 元，均衡产出增加多少元 | 由 mpc 决定 |
| I^u | "I u" | **非计划存货投资** = 生产出来但没被计划买走的部分 = Y − Y^ad。正数表示库存被动积压 | 由供需差决定 |
| M / M^s / M^d | — | 货币量 / 货币供给 / 货币需求，与第 19 章相同 | 央行 / 公众 |
| M/P | — | **实际货币余额**：货币量除以物价水平，表示这些钱能买到多少东西 | — |
| k | 凯 | 货币需求对收入的敏感程度（课件没出现，在 3.14 节补一句里用到） | 参数 |
| h | 艾尺 | 货币需求对利率的敏感程度（同上） | 参数 |

## 2. 再把词听懂

| 术语 | 白话解释 |
|---|---|
| 产出 / 收入 / GDP | 这三个在模型里指的是同一件事的三种说法：一年生产了多少东西（产出）、生产这些东西让多少人拿到了钱（收入）、这些东西值多少钱（GDP）。生产 1 元的东西，就有人得到 1 元的收入，所以产出和收入总是相等。 |
| 总需求 / 计划支出 | 大家**打算**花多少钱买东西。注意"打算"两个字：这是意愿，不是事后统计。 |
| 实际支出 | 事后真正发生的支出。生产出来没卖掉的部分会被算作"存货投资"，所以事后的 C + I + G + NX 一定等于 Y。这是会计恒等式，永远成立，**不能用它来决定 Y**。决定 Y 的是"计划支出 = 产出"这个均衡条件。 |
| 均衡 | 生产出来的东西正好被打算买的人买走，企业没有意外的库存变化，因此没有理由改变产量。 |
| 消费 | 家庭买消费品和服务。买房不算消费，算投资（住宅投资）。 |
| 可支配收入 | 交完税以后剩下的收入，Y_D = Y − T。消费取决于这个，不是取决于税前收入。 |
| 边际消费倾向 mpc | 可支配收入每多 1 元，多花多少。mpc = 0.6 表示多 100 元收入，多花 60 元，剩下 40 元存起来。它是消费函数的斜率。 |
| 平均消费倾向 | 消费 ÷ 可支配收入，是"总共花了收入的百分之几"。它跟 mpc 不是一回事，别混。 |
| 投资 | 企业买设备、建厂房、买新住宅，加上存货增加。**买股票、债券、二手房都不算投资**，因为那只是换手，没有造出新的机器和房子。 |
| 资本 | 机器、设备、厂房这些用来生产的东西。投资就是增加资本。 |
| 名义利率 / 实际利率 | 名义利率是银行牌子上写的百分比；实际利率是扣掉物价上涨以后的真实成本。借 100 元、利率 5%、物价涨 3%，实际成本约 2%。这一章假设物价不变，所以两者数值相同，课件里 i 和 r 混着用。 |
| 金融摩擦 | 银行搞不清借款人能不能还钱，只好在无风险利率上加一块风险补偿。两种来源：**逆向选择**（最急着借钱的人，往往是最可能还不上的人）、**道德风险**（借到钱以后可能拿去干风险更大的事）。 |
| 动物精神 | 凯恩斯的说法：企业对未来的信心忽高忽低，跟利率、产出都没关系，投资因此大幅波动。 |
| 政府购买 | 政府买产品和服务、发公务员工资的支出。**不含转移支付**（养老金、低保、失业救济），因为转移支付是把钱从一个人手里转到另一个人手里，政府没有直接买东西。 |
| 净出口 | 出口减进口。出口是外国人买本国的东西，进口是本国人买外国的东西，两者相减才是外国对本国产品的净需求。 |
| 汇率 / 升值 | 汇率是一单位本国货币能换多少外国货币。升值就是能换更多，本国货币更值钱。 |
| 乘数 | 自主性支出增加 1 元，最终产出增加不止 1 元。因为拿到这 1 元的人会花掉一部分，花钱又变成别人的收入，如此一轮一轮下去。 |
| 凯恩斯交叉 | 一个横轴是产出、纵轴是计划支出的图。图上有一条 45° 线（表示"计划支出正好等于产出"），计划支出线和它的交点就是均衡产出。 |
| IS 曲线 | 名字来自 Investment = Saving（投资等于储蓄）。在产品市场均衡时，投资和储蓄相等，所以叫 IS。在这章里它表示：**每个利率水平下，商品市场均衡对应的产出**。 |
| LM 曲线 | 名字来自 Liquidity preference = Money supply（流动性偏好等于货币供给）。表示：**每个收入水平下，货币市场均衡对应的利率**。 |
| 外生 / 内生 | 外生 = 由模型外面给定，模型不解释它怎么来的（带横线的字母）。内生 = 由模型算出来的（不带横线的字母）。 |
| 沿曲线移动 / 曲线平移 | 利率变导致产出变，是**沿着** IS 曲线走；政府支出、税收、信心这些变，是整条曲线**平移**。 |

## 3. 课件逐页讲

### 3.1 课件 P2–P3：先看中国的消费

**P2 表 1：中外居民消费率对比**

居民消费率 = 居民消费 ÷ GDP，也就是"一年生产出来的东西里，有多大比例被居民买走"。

- 中国：2000 年 46.69%，2008 年 34.94%，2000–2008 年平均 40.29%
- 美国：平均 70.07%
- 世界平均：61.27%
- OECD 国家平均：62.49%

读出来的事实：**中国的产出里由居民消费买走的部分明显偏低**，相应地，投资和出口在总需求中的份额更高。

**P3 图 3：中国居民平均消费倾向与储蓄率（1960–2000）**

- 平均消费倾向（消费 ÷ 可支配收入）从 1960 年前后约 0.95 下降到 2000 年前后约 0.60；
- 储蓄率从约 0.20 上升到约 0.32。

读出来的事实：**消费倾向在长期里一路下降，不是常数。**

（注意：这两个指标的分母不一样，平均消费倾向以居民可支配收入为分母，储蓄率在不同文献里常以 GDP 或居民收入为分母，所以它们相加不等于 1，不要拿来做加减。）

**为什么这两页放在这一章开头**：这一章马上要写消费函数 C = C̄ + mpc × Y_D，凯恩斯假设 mpc 是一个 0 到 1 之间的**常数**。如果现实中平均消费倾向在几十年里持续下降，说明消费函数本身在移动，那么"mpc 是常数"只能当作短期简化。这两页是对这个假设的一个提醒。

### 3.2 课件 P4：计划支出与总需求

课件给的定义：

> **计划支出**：家庭、企业、政府以及外国人**希望**用于本国生产的产品和服务的支出。

凯恩斯认为：在给定价格水平下，整个经济对本国产品和服务的总需求量就等于计划支出。

计划支出由四项组成：

> **Y^ad = C + I + G + NX**

逐项解释：

| 项目 | 谁在花 | 具体是什么 |
|---|---|---|
| 消费支出 C | 家庭 | 买吃的、穿的、家电、理发、看病、旅游 |
| 计划投资支出 I | 企业 | 买机器设备、建厂房办公楼、买新住宅，加上存货增加 |
| 政府购买 G | 政府 | 买办公用品、修路、给公务员和教师发工资。**不含**养老金、低保等转移支付 |
| 净出口 NX | 外国人（净） | 出口减进口 |

**三个容易错的地方**：

1. **政府购买不含转移支付**。养老金发下去，收到的人可能会花掉，但那是"把钱从纳税人手里转到退休者手里"，政府没有直接买任何东西。转移支付只通过影响可支配收入间接影响消费。
2. **投资不含买股票、买债券、买二手房**。这些只是换手：钱从买方到卖方，社会上没有多出一台机器。只有新造出来的设备、厂房、住宅才算投资。
3. **计划支出不等于实际支出**。计划是"打算花多少"，实际是"事后花了多少"。生产出来没卖掉的东西，事后会被记成"存货投资"，所以事后的 C + I + G + NX 永远等于 Y。这是会计恒等式，不能用来决定 Y。

### 3.3 课件 P5：消费函数

**第一步，可支配收入**：

> **Y_D = Y − T**

交完税以后自己能安排的收入。消费看的是这个，不是税前收入。

**第二步，消费函数**：

> **C = C̄ + mpc × Y_D = C̄ + mpc × (Y − T)**

这个式子要拆成两半看：

- **C̄（自主性消费）**：收入为 0 时也要花的钱。吃饭、房租、水电，还有对未来的信心、家里的存款，都会影响这一块。它被假定为外生，也就是不由收入决定。
- **mpc × Y_D**：跟着收入走的那部分。mpc 是边际消费倾向，凯恩斯假定它是 0 到 1 之间的常数。

**mpc 到底是什么意思**：可支配收入每多 1 元，消费多花多少元。mpc = 0.6 就是多 100 元收入、多花 60 元，剩下 40 元存起来。

**mpc 是斜率，不是比例**。消费占收入的比例叫平均消费倾向（C ÷ Y_D），那是另一个概念。P3 那张图画的正是平均消费倾向在长期下降。

### 3.4 课件 P6–P11：投资

投资是这四部分里最麻烦的一项，课件用了 6 页，因为它是利率影响总需求的主要通道。

**P6：投资分两块**

- **固定资产投资**：企业买设备（机器、电脑、飞机）、建建筑物（工厂、办公楼、购物中心），以及新住宅。
- **存货投资**：企业增加原材料、零部件、产成品的持有量，按一定时期内这些物品持有量的变动来算。

**P7：企业什么时候才投资**

判断标准只有一条：**预期的投资回报率 > 借钱的利息成本，才投资。**

课件给了两个数字情形：

- 实际利率是 10% 时，大多数实物投资的回报率超不过 10% 的借款成本，所以计划投资水平很低。
- 实际利率是 1% 时，很多项目的回报率都超过 1%，所以计划投资提高。

用一句话概括：

> 投资回报率 > 融资利率 → 投资划算 → 会投资
>
> 投资回报率 < 融资利率 → 投资不划算 → 不投资

**P8：由此得到投资与利率负相关**

> 融资利率上升 → 投资减少 → 总需求下降
>
> 融资利率下降 → 投资增加 → 总需求上升

这就是"投资函数向下倾斜"的原因，也是**货币政策通过利率影响总需求、产出和就业**的机制：央行降低利率 → 企业借款成本下降 → 投资增加 → 总需求增加 → 产出增加。

**P9：预期与"动物精神"**

企业对未来的判断会影响投资：对未来盈利乐观的企业愿意多花钱，悲观的会削减支出。

所以投资里有一部分完全无法用产出、利率解释，课件把它叫**自主性投资 Ī**，是外生变量。

凯恩斯认为，自主性投资的波动主要来自企业情绪的忽高忽低，他称之为**"动物精神"**。这也是 IS 曲线会整体移动的主要原因。

**P10：投资函数**

> **I = Ī − d × r_i**

r_i 是投资实际面对的利率。d 是"投资对实际利率的响应程度"：利率每上升 1 个单位，投资减少 d 个单位。d 越大，投资对利率越敏感。

**P11：金融摩擦**

课件指出：企业实际面对的借款利率，不只是央行控制的那个安全短期利率 i，还要加上一块**金融摩擦 f**。

f 是怎么来的：银行搞不清借款人到底靠不靠谱，只好多收一块风险补偿来保护自己。两种典型情况：

- **逆向选择**：最急着借钱的人，往往正是最可能还不上的人。银行分不清谁好谁坏，只好对所有人加价。
- **道德风险**：借到钱以后，借款人可能拿去干风险更大的事。银行防不住，也只好加价。

所以：

> **r_i = i + f**
>
> **I = Ī − d × (i + f)**

注意 f 是加在利率上的"加价"，不是利率本身的一部分。

**这一页的现实意义**：央行只能控制 i，控制不了 f。金融危机时 f 会大幅上升，即使央行把 i 降到接近 0，企业实际借款成本还是很高，投资仍然不恢复。这是货币政策传导会中断的一个原因。

### 3.5 课件 P12：政府购买和税收

课件直接假设两者都是外生：

> **G = Ḡ，T = T̄**

意思是：政府买多少、收多少税，由政策决定，模型不去解释它。带横线就是"给定"。

（这一章假设是定额税，也就是税额跟收入无关。现实中的税是按比例从收入里收的，那样乘数会变小，但课件没有涉及。）

### 3.6 课件 P13–P15：净出口

**P13：利率通过汇率影响净出口**

课件以美国为例，链条要一步一步走：

1. 美国实际利率上升；
2. 美元资产的回报率相对外币资产变高，人们更愿意持有美元；
3. 想买美元的人变多，美元升值；
4. 美元升值后，美国商品用外币标价变贵，外国人少买，美国出口减少；
5. 同时外国商品用美元标价变便宜，美国人多买，美国进口增加；
6. 出口减、进口增，**净出口下降**。

所以：**实际利率上升 → 本币升值 → 净出口下降。**

**P14：自主性净出口**

出口还取决于外国人对本国商品的需求，进口取决于本国居民对外国商品的需求。这些跟利率无关。

课件举了两个例子：

- 中国收成不好，需要多买美国小麦 → 美国出口增加；
- 巴西经济繁荣，巴西人更有钱买美国商品 → 美国出口增加。

这两类因素合起来叫**自主性净出口 NX̄**，当作外生变量。

**P15：净出口函数**

> **NX = NX̄ − x × i**

x 是净出口对利率的响应程度：利率每上升 1 个单位，净出口减少 x。所以净出口与自主性净出口正相关、与利率负相关。

**P36 会把这个链条用中国讲一遍**，见 3.13 节。

### 3.7 课件 P16–P17：产品市场均衡

**P16：均衡条件**

> **Y = Y^ad**

当这个条件满足时，生产出来的产品和服务正好被计划买走，企业能卖出全部产出，没有计划外的存货变化，所以没有理由调整生产。

三种情况的调整方向：

| 情况 | 含义 | 企业怎么办 |
|---|---|---|
| Y > Y^ad | 生产出来的比大家想买的多 | 库存积压 → 减产 → 产出下降 |
| Y < Y^ad | 大家想买的比生产出来的多 | 供不应求、库存被买空 → 扩大生产 → 产出上升 |
| Y = Y^ad | 正好相等 | 没有计划外库存变动 → 不调整，均衡 |

**P17：凯恩斯交叉图**

图的横轴是产出 Y，纵轴是计划支出 Y^ad，里面有两条线：

- **45° 线**：这条线上每一点都满足"计划支出 = 产出"。因为横纵轴刻度相同，所以是 45°。
- **计划支出线**：Y^ad =（自主性支出）+ mpc × Y。二部门时就是 C̄ + I + mpc × Y，截距是自主性支出，斜率是 mpc。

因为 mpc 在 0 和 1 之间，计划支出线比 45° 线平，所以两条线一定相交，而且只交一次。交点就是均衡产出。

**为什么只交一次**：计划支出线的斜率小于 1，两条线的差距会随 Y 增大而不断缩小并越过 0，所以只有一个交点。这一点很重要——它保证均衡存在且唯一。

### 3.8 课件 P18–P19：无政府封闭经济的算例

**假设**：没有政府（G = T = 0）、没有对外贸易（NX = 0）、投资给定为 300。

**消费函数**：因为没有税，Y_D = Y，所以

> C = 200 + 0.5 × Y

这里 C̄ = 200，mpc = 0.5。

**计划支出**：

> Y^ad = C + I = (200 + 0.5Y) + 300 = 500 + 0.5Y

**求均衡**：令 Y = Y^ad

> Y = 500 + 0.5Y
>
> Y − 0.5Y = 500
>
> 0.5Y = 500
>
> **Y = 1000**

**P19 的图怎么读**：图上横轴是产出，纵轴是计划支出，45° 线与计划支出线交于 Y = 1000。图上还标了两个点：

- 当 Y = 800 时，Y^ad = 500 + 400 = 900。大家想买 900，只生产了 800，差 100 要卖库存，库存被动减少 100。课件记作 I^u = −100。企业看到库存下降，会扩大生产，Y 上升。
- 当 Y = 1200 时，Y^ad = 500 + 600 = 1100。生产 1200，只想买 1100，多出 100 变成库存积压，I^u = +100。企业会减产，Y 下降。

这里 I^u = Y − Y^ad 叫**非计划存货投资**：正数表示被动积压，负数表示被动减少，等于 0 就是均衡。所以"Y = Y^ad"和"I^u = 0"是同一件事的两种说法。

### 3.9 课件 P20–P22：投资增加与乘数

**P20 的问题**：投资从 300 增加到 400，产出增加多少？为什么？

**先算**：

> 新计划支出：Y^ad = 200 + 0.5Y + 400 = 600 + 0.5Y
>
> 均衡：Y = 600 + 0.5Y → 0.5Y = 600 → **Y = 1200**

产出从 1000 增加到 1200，**增加了 200**，而投资只增加了 100。

**为什么投资增加 100，产出增加 200？** 一轮一轮看：

| 轮次 | 这轮多出来的支出 | 累计产出增加 |
|---|---|---|
| 第 1 轮 | 投资多买 100 元的设备 | 100 |
| 第 2 轮 | 造设备的人多拿 100 元收入，按 0.5 花掉 50 元 | 150 |
| 第 3 轮 | 卖东西的人多拿 50 元，再花掉 25 元 | 175 |
| 第 4 轮 | 再花 12.5 元 | 187.5 |
| … | … | … |
| 合计 | 100 + 50 + 25 + 12.5 + … | **200** |

这是一个等比数列求和：100 ÷ (1 − 0.5) = 200。

乘数就是：

> **α = 1 ÷ (1 − mpc) = 1 ÷ 0.5 = 2**

意思是：自主性支出每增加 1 元，均衡产出增加 2 元。

**P21 的文字链条**：投资增加 → 产出增加 → 收入增加 → 消费增加 → 最终产出更大的增加。这就是乘数过程的文字版。

**P22：通式**

把上面的算法写成一般形式：

> Y = C̄ + mpc × Y + I
>
> Y × (1 − mpc) = C̄ + I
>
> **Y =（C̄ + I）÷ (1 − mpc) = A × 1/(1 − mpc)**

其中 A = C̄ + I 叫**自主性支出**（不随收入变的那部分）。这个式子是后面所有推导的母式，后面每一步只是往 A 里加东西、往方程里加利率项。

**一个前提**：mpc 必须小于 1。如果 mpc 大于等于 1，每一轮花掉的钱不比拿到的少，级数不收敛，乘数不存在，也没有稳定均衡。

### 3.10 课件 P23–P25：政府与税收

**P24：三部门的代数解**

现在加上政府：Y^ad = C + I + G，其中 C = C̄ + mpc × (Y − T)，G 和 T 都是给定的。

> Y = C̄ + mpc × (Y − T) + I + G
>
> Y = C̄ + mpc × Y − mpc × T + I + G
>
> Y − mpc × Y = C̄ + I + G − mpc × T
>
> **Y = 1/(1 − mpc) ×（C̄ + I + G）− mpc/(1 − mpc) × T**

从最后的式子能读出两个乘数：

- **政府购买乘数 = 1/(1 − mpc)**：政府多花 1 元，产出增加 1/(1 − mpc) 元。
- **税收乘数 = −mpc/(1 − mpc)**：政府多收 1 元税，产出减少 mpc/(1 − mpc) 元。

**为什么税收乘数的绝对值比政府购买乘数小**？因为：

- 政府花 1 元，这 1 元全部直接变成对产品的需求；
- 政府少收 1 元税，居民的可支配收入多 1 元，但居民只会把其中的 mpc 花掉，剩下的存起来。

所以政府购买的第一轮效应是 1，减税的第一轮效应只有 mpc。因为 mpc < 1，所以 1/(1 − mpc) > mpc/(1 − mpc)。

**P25：三线图**

课件画了三条计划支出线，mpc = 0.5：

| 线 | 表达式 | 组成 | 与 45° 线的交点 |
|---|---|---|---|
| 第一条 | 500 + 0.5Y | 200（C̄）+ 300（I） | 1000 |
| 第二条 | 900 + 0.5Y | 再加 400 的政府购买 G | 1800 |
| 第三条 | 700 + 0.5Y | 再加 400 的税 T，计划支出下移 mpc × T = 200 | 1400 |

验算：

- 只增加 G = 400：乘数 2，产出增加 800，从 1000 到 1800 ✓
- 再征税 T = 400：税收乘数 −1，产出减少 400，从 1800 到 1400 ✓
- 合计：产出增加 400，正好等于政府支出增加额 ✓

注意征税让整条线**向下平移 200**（mpc × T），而不是改变斜率，因为定额税不影响 mpc。

**P23 的思考题：政府增加 4 万亿支出，同时增税 4 万亿，这个刺激方案有效吗？**

这是这一节最重要的一道题。设 ΔG = ΔT = 4 万亿：

> 产出的变化 = 政府购买乘数 × ΔG + 税收乘数 × ΔT
>
> = 1/(1 − mpc) × 4 − mpc/(1 − mpc) × 4
>
> = 4 × (1 − mpc) ÷ (1 − mpc)
>
> = **4 万亿**

所以方案**有效**，产出增加 4 万亿。但要注意增加的量：正好等于政府多花的钱，乘数等于 1，而不是政府购买乘数 1/(1 − mpc)。

**为什么正好是 1 倍**：政府多花 4 万亿，全额变成需求；多收 4 万亿税，让居民少花 4 × mpc 万亿；两者相抵后净增加 4 × (1 − mpc) 万亿；再乘上乘数 1/(1 − mpc)，正好又回到 4 万亿。

**课件用不等式说明"有效"，方向是对的，但它只证明了净效应为正，没有给出确切大小。** 严格结论是：**支出和税收同方向、同幅度变动时，产出变化恰好等于政府支出的变化，与 mpc 无关。** 这个结论叫"平衡预算乘数等于 1"。

### 3.11 课件 P26–P28：开放经济与 IS 曲线

**P26：完整方程组**

> Y^ad = C + I + G + NX，且 Y = Y^ad
>
> C = C̄ + mpc × (Y − T̄)
>
> I = Ī − d × (i + f)
>
> G = Ḡ，T = T̄
>
> NX = NX̄ − x × i

课件在这里问"Y = ?"，也就是要求出均衡产出。

**这一步的关键变化**：投资和净出口都带上了利率 i。之前 i 只是一个参数，现在它变成了变量。

**P27：代入并整理**

> Y = C̄ + mpc(Y − T̄) + Ī − d(i + f) + Ḡ + NX̄ − x·i

展开：

> Y = C̄ + mpc·Y − mpc·T̄ + Ī − d·f − d·i + Ḡ + NX̄ − x·i

把含 Y 的项移到左边：

> Y − mpc·Y = C̄ + Ī − d·f + Ḡ + NX̄ − mpc·T̄ − (d + x)·i

两边除以 (1 − mpc)：

> **Y = 1/(1 − mpc) × [ A − b × i ]**

其中：

> **A = C̄ + Ī − d·f + Ḡ + NX̄ − mpc·T̄**
>
> **b = d + x**

**A 和 b 是什么意思，逐项看**：

A 是"自主性支出"，也就是跟收入和利率都没关系的那一大块：

- C̄：自主性消费
- Ī：自主性投资
- − d·f：金融摩擦对投资的抑制。注意 f 跟利率无关，所以在任何利率下都压着投资，属于截距项
- Ḡ：政府购买
- NX̄：自主性净出口
- − mpc·T̄：税收对消费的折减。税只影响消费里 mpc 那一部分，所以乘上 mpc

b 是"支出对利率的总敏感程度"：利率每上升 1 个单位，投资减少 d，净出口减少 x，总需求一共减少 d + x。

**P28 的简写形式**：

> **Y = 1/(1 − mpc) × [ A − b·i ]**

这就是 IS 曲线的方程。它其实在第 22 页的通式上只多做了一件事：把 i 放进来。

### 3.12 课件 P29–P34：读懂 IS 曲线

**P29：这个式子的两项各有分工**

> Y = 1/(1 − mpc) × [ A − b·i ]

- **第一项（A 那部分）说明曲线在什么位置**。在任何一个给定的利率下，自主性消费、投资、政府购买、净出口增加，或者税收、金融摩擦下降，都会让产出上升，也就是整条线向右移动。
- **第二项（b·i 那部分）说明沿着曲线怎么走**。利率上升，产出下降，也就是在曲线上从左上往右下移动。

课件把这两层意思总结成一句话，值得记住：**第一项说明 IS 曲线位移的信息，第二项说明沿着 IS 曲线移动的信息。**

**P30：算例**

给定参数（单位：万亿美元）：

> C̄ = 1.4，Ī = 1.2，Ḡ = 3.0，T̄ = 3.0，NX̄ = 1.3，f = 1，mpc = 0.6，d = 0.3，x = 0.1

先算 A：

> A = 1.4 + 1.2 − 0.3×1 + 3.0 + 1.3 − 0.6×3.0
>
> = 1.4 + 1.2 − 0.3 + 3.0 + 1.3 − 1.8
>
> = 4.8

再算乘数和 b：

> 1/(1 − 0.6) = 2.5
>
> b = d + x = 0.3 + 0.1 = 0.4

代入：

> Y = 2.5 × (4.8 − 0.4 × i) = 12 − 1.0 × i

所以 **Y = 12 − i**。

**P31：图形和两个区域**

把 Y = 12 − i 画出来，是一条向下倾斜的直线：

- i = 0 时 Y = 12；i = 3 时 Y = 9；i = 1 时 Y = 11。
- 曲线**上方**的点：产出比均衡多，产品卖不掉，属于**超额产品供给**（生产过剩）。
- 曲线**下方**的点：产出比均衡少，不够卖，属于**超额产品需求**（供不应求）。

比如 i = 3、Y = 10 这个点：按 IS 方程，i = 3 时均衡产出应该是 9，现在生产了 10，多了 1，所以在 IS 上方，属于超额供给，企业要减产。

**P32–P33：政府购买从 3.0 增加到 4.0**

A 变为：

> A = 1.4 + 1.2 − 0.3 + 4.0 + 1.3 − 1.8 = 5.8

IS 变为：

> Y = 2.5 × (5.8 − 0.4i) = **14.5 − i**

对比 Y = 12 − i：在任何一个利率水平上，产出都多了 2.5 万亿（因为政府购买乘数 2.5 × 增加 1 万亿 = 2.5 万亿）。整条线**向右平移 2.5 万亿**。

课件的图：i = 3 时产出从 9 变成 11.5，i = 1 时从 11 变成 13.5，两处都移动 2.5，说明是平移而不是转动。

结论：**政府购买增加 → 总需求增加 → 任一利率下均衡产出上升 → IS 右移；政府购买减少则左移。**

**P34：哪些因素会让 IS 移动**

课件的汇总表列了六个变量。课件上这张表只渲染出前两列，"IS 曲线如何位移"和"推理"两列是空的，这里补上：

| 变量 | 变动 | IS 怎么动 | 移动幅度（给定利率下） |
|---|---|---|---|
| 自主性消费 C̄ | ↑ | 右移 | 乘数 × 变化量 |
| 自主性投资 Ī | ↑ | 右移 | 乘数 × 变化量 |
| 政府购买 Ḡ | ↑ | 右移 | 乘数 × 变化量 |
| 自主性净出口 NX̄ | ↑ | 右移 | 乘数 × 变化量 |
| 税收 T̄ | ↑ | 左移 | 乘数 × mpc × 变化量 |
| 金融摩擦 f | ↑ | 左移 | 乘数 × d × 变化量 |

一句话记：**凡是让总需求变大的，IS 右移；让总需求变小的，左移。** 税收和摩擦都是通过"抑制需求"起作用的，所以是左移。

**顺带记斜率**：IS 的斜率取决于 mpc、d、x。mpc 越大、d 越大、x 越大，曲线越平；反过来越陡。f 和 T̄ 只改变位置，不改变斜率。

### 3.13 课件 P35–P37：为什么利率和产出负相关

**P35**：课件列出两条负相关关系，然后问"为什么？"

- 利率与计划投资支出负相关；
- 利率与净出口负相关。

**P36：用中国讲一遍净出口这条链**

> 中国利率上升 → 人民币资产相对外币资产更有吸引力 → 对人民币的需求增加 → 人民币汇率上升（升值）→ 本国产品用外币标价变贵 → 出口下降；外国产品用人民币标价变便宜 → 进口增加 → **净出口下降**

结论：利率与净出口负相关。

（「补一句」这条链条成立的前提是资金能自由进出、汇率由市场决定。中国有资本项目管制、汇率也有管理，所以这个渠道比美国弱，利率影响总需求主要还是通过投资渠道。）

**P37：图形推导**

课件用两个图把 IS 推出来：

- 左图：横轴产出 Y，纵轴计划支出，三条不同利率下的计划支出线。
- 右图：横轴产出 Y，纵轴利率 i，把左图的交点搬过来。

推理链：

> 假设 i1 < i2 < i3
>
> → 投资 I1 > I2 > I3，净出口 NX1 > NX2 > NX3（利率越低，投资和净出口越多）
>
> → 计划支出 Y^ad1 > Y^ad2 > Y^ad3（支出线整体上移）
>
> → 由均衡条件 Y = Y^ad，交点对应 Y1 > Y2 > Y3
>
> → 所以在均衡点上，利率越低、产出越高

把三个点 (Y1, i1)、(Y2, i2)、(Y3, i3) 连起来，就是一条向下倾斜的曲线，即 IS 曲线。

图上还标了两个区域：曲线**上方**是超额产品供给（Excess Supply of Goods），**下方**是超额产品需求（Excess Demand for Goods）。

### 3.14 课件 P38：货币市场与 LM 曲线

**课件的假设**：货币供给量固定不变。

**左图：货币市场**（横轴实际货币余额 M/P，纵轴利率 i）

- **M^s 是一条竖线**：货币供给由央行给定，不随利率变化。
- 三条向下倾斜的线是货币需求 M^d，对应三个不同的收入水平。收入越高，同一利率下人们想持有的货币越多，所以整条线越靠右。
- 三条货币需求线与竖线 M^s 分别交于 1、2、3 三点，对应的利率是 i1 < i2 < i3。

课件在这张图上写了一句关键的话：**在给定的利率水平下，更高的总产出水平意味着更多数量的货币需求。**

**右图：把三个点搬到"横轴产出、纵轴利率"的图上**

- 点 1：(Y1, i1)，点 2：(Y2, i2)，点 3：(Y3, i3)
- 连起来，就是一条向上倾斜的曲线，即 **LM 曲线**。

**LM 为什么向上倾斜**，用一句话说：

> 收入上升 → 人们要做更多交易，需要持有更多货币 → 货币供给没变 → 只有利率上升，才能让人们愿意少持有一些货币 → 货币市场重新均衡。

利率上升为什么能让人少持币？因为利率高了，把钱留在手里放弃的收益就多，人们宁愿把钱存起来或买债券。

**图上两个区域**：

- LM **上方**：超额货币供给（Excess Supply of Money）。钱太多，人们拿钱去买债券，债券价格上升、利率下降。
- LM **下方**：超额货币需求（Excess Demand for Money）。钱不够，人们卖债券换钱，债券价格下跌、利率上升。

**「补一句」** 如果用字母写，货币需求可以写成 M^d/P = kY − h·i：k 是收入敏感度，h 是利率敏感度。令它等于给定的 M̄/P，解出：

> **i = (k/h) × Y − (1/h) × (M̄/P)**

这就是 LM 的方程，斜率是 k/h。k 越大（收入一涨就要很多钱）LM 越陡；h 越大（人们对利率很敏感）LM 越平。课件没有给这个式子，但考试里常用来判断曲线的陡缓。

### 3.15 课件 P39：IS-LM 的交点与四个区域

把 IS 和 LM 画在同一张图上（横轴产出 Y，纵轴利率 i），交点 E 就是**唯一同时让两个市场均衡**的（Y*, i*）组合。

- IS 上除 E 以外的点：商品市场均衡，但货币市场不均衡。
- LM 上除 E 以外的点：货币市场均衡，但商品市场不均衡。

**四个区域和调整方向**：

| 位置 | 商品市场 | 货币市场 | 往哪走 |
|---|---|---|---|
| IS 上方的任意点 | 生产过剩，产出要降 | — | 向左 |
| IS 下方的任意点 | 供不应求，产出要升 | — | 向右 |
| LM 上方的任意点 | — | 货币太多，利率要降 | 向下 |
| LM 下方的任意点 | — | 货币太少，利率要升 | 向上 |

**课件 P39 标出的四个点**，正好说明"已经均衡的那个市场不用再动"：

- **A 点**在 IS 上、LM 上方：商品市场已经均衡，企业没有增减产的理由；但货币太多，人们买债券，利率下降。所以沿着 IS 向下走，到 E。
- **B 点**在 LM 上、IS 上方：货币市场已经均衡，利率没有变动压力；但产品卖不掉，企业减产。所以沿着 LM 向下走，到 E。
- **C 点**在 IS 上、LM 下方：商品市场均衡；货币不够，人们卖债券换钱，利率上升。沿 IS 向上走，到 E。
- **D 点**在 LM 上、IS 下方：货币市场均衡；产品不够卖，企业增产。沿 LM 向上走，到 E。

一句话记：**在 IS 上就动利率，在 LM 上就动产出。**

**顺着课件再推一步（考试常问的方向）**：

- 政府支出增加 → IS 右移 → 交点沿 LM 向右上移 → 产出增加、利率上升。
- 货币供给增加 → LM 右移（下移）→ 交点沿 IS 向右下移 → 利率下降、产出增加。

这就是这一章最后的用途：**用两条线的移动，判断财政政策和货币政策对产出和利率的影响方向。**

## 4. 课件思考题的解法

（P23 的"4 万亿方案"已在 3.10 节解完，这里解 P40 的三道题。下面反复出现的 Δ 表示"变化量"，ΔY 就是"产出变了多少"。三道题都取 mpc = 0.5，所以乘数 = 1 ÷ (1 − 0.5) = 2，税收乘数 = −0.5 ÷ 0.5 = −1。）

### P40 第 1 题

> 假设边际消费倾向为 0.5，为使产出水平增加 10000 亿美元，政府支出需要增加多少？

用政府购买乘数：

> ΔY = 2 × ΔG
>
> 10000 = 2 × ΔG
>
> **ΔG = 5000 亿美元**

意思是：因为乘数是 2，政府只需要多花一半的钱，就能让产出多 10000 亿。

### P40 第 2 题

> 如果 mpc = 0.5，政府决定调整税收，使总产出增加 4000 亿美元，税收应当变化多少？

用税收乘数：

> ΔY = −1 × ΔT
>
> 4000 = −ΔT
>
> **ΔT = −4000 亿美元**

也就是**减税 4000 亿美元**。

注意：这里减税 4000 亿正好让产出增加 4000 亿，是因为 mpc = 0.5 时税收乘数的绝对值恰好是 1，属于数字上的巧合。如果 mpc = 0.8，税收乘数是 −4，只需要减税 1000 亿就够了。

### P40 第 3 题

> 当 mpc = 0.5 时，如果政府支出与税收同时减少 3000 亿美元，总产出水平如何变化？

分两步算，再相加：

1. 政府支出减少 3000 亿：直接少 3000 亿需求，乘数 2，产出 **−6000 亿**。
2. 税收减少 3000 亿：居民可支配收入多 3000 亿，按 0.5 花掉，消费多 1500 亿，乘数 2，产出 **+3000 亿**。

合计：

> −6000 + 3000 = **−3000 亿美元**

也就是**产出下降 3000 亿美元**。

这也可以用平衡预算乘数验证：政府支出和税收同方向、同幅度变动时，产出的变动恰好等于政府支出的变动，所以 ΔY = ΔG = −3000 亿。**"平衡预算乘数等于 1"对同增和同减都成立。**

## 5. 一页纸复习

### 公式清单

| 公式 | 意思 |
|---|---|
| Y^ad = C + I + G + NX | 计划支出（总需求）的四个组成部分 |
| C = C̄ + mpc × (Y − T) | 消费函数：一部分固定，一部分随可支配收入变 |
| I = Ī − d × (i + f) | 投资函数：利率越高、金融摩擦越大，投资越少 |
| NX = NX̄ − x × i | 净出口函数：利率越高，净出口越少 |
| Y = Y^ad | 商品市场均衡：产出 = 计划支出，等价于非计划存货为 0 |
| α = 1 ÷ (1 − mpc) | 支出乘数 |
| Y =（C̄ + I）÷ (1 − mpc) | 两部门（无政府、封闭）均衡产出 |
| Y = 1/(1−mpc) ×（C̄ + I + G）− mpc/(1−mpc) × T | 三部门均衡产出 |
| ΔY = ΔG（当 ΔG = ΔT） | 平衡预算乘数等于 1 |
| Y = 1/(1−mpc) × [A − b·i]，A = C̄ + Ī − df + Ḡ + NX̄ − mpc·T̄，b = d + x | IS 曲线 |
| Y = 12 − i（课件参数下的算例） | IS 的具体例子 |
| i = (k/h)Y − (1/h)(M̄/P) | LM 曲线（补一句，课件只给了图） |
