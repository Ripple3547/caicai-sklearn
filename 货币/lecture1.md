联邦储备包括资产和负债。

负债分为货币 Cash 和准备金 Reserves
- 货币公众持有
- 准备金为银行存款
- 基础货币 MB = C + R
- C 和 R 之间可以相互转换

公开市场操作
- 公开市场购买
- 公开市场出售

基础货币的增加可由 C 和 R 导致
- 公众卖出证券，无银行参与，C 增加
- 银行参与，R 增加

MB = MB<sub>n</sub> + BR
- MB<sub>n</sub> 为非借入基础货币
- BR 为借入准备金

现金流损、法定准备金的留存会使得多倍存款创造的过程受阻，无法达到理想的创造量



现金留存越多、法定存款准备金率越高、非借入基础货币/借入准备金越少，最终的存款减少，存款创造倍数减小。

货币供给 M；基础货币 MB = C + R = MB<sub>n</sub> + BR
