## 一、问题设定与核心思想

### 1. 两个集成范式的差别

设训练样本为 $(x_1,y_1),\dots,(x_n,y_n)$，基学习器是同一个算法的多个副本，例如深度固定的回归树或分类树。**集成**（*ensemble*）把这 $M$ 个副本的输出按
$f_M(x)=\sum_{m=1}^{M}\beta_m G(x;\gamma_m)$ 组合。两种范式的分野在于 $\beta_m$ 与各个副本的拟合顺序。

装袋法（*bagging*）对副本平行拟合，每个副本各自在自助样本上训练，最终等权平均或投票，因而主要削减方差；提升法（*boosting*）串行拟合，第 $m$ 轮针对前 $m-1$ 轮组合模型的残余误差修正，最终按各轮表现加权组合，因而主要削减偏差。二者的差别可归纳如下：

| 维度 | 装袋法 | 提升法 |
| :--- | :--- | :--- |
| 副本拟合顺序 | 平行，互不依赖 | 串行，后一轮依赖前一轮 |
| 数据使用 | 自助抽样（*bootstrap*）重采样 | 原样本；或只调整样本权重 |
| 主要削减 | 方差 | 偏差 |
| 组合系数 | 相等 | 按各轮加权错误率确定 |
| 对过拟合的敏感性 | 低 | 随轮数增加而上升，需控制 |

提升法的三条技术路线分别对应三种修正当前模型的机制：**自适应提升**（*adaptive boosting*，AdaBoost）通过调整样本权重，间接最小化**指数损失**（*exponential loss*）；**梯度提升**（*gradient boosting*）通过拟合负梯度，直接最小化任意可微损失；现代实现则在后者基础上加入二阶信息与正则化。

### 2. 提升有效的条件

若第 $m$ 个基学习器在加权样本上的错误率为 $\varepsilon_m$，且 $\varepsilon_m<1/2$，则组合分类器的 0-1 训练误差满足

$$\frac{1}{n}\sum_{i=1}^{n} I\big[y_i\neq \operatorname{sign}(f_M(x_i))\big]\le \prod_{m=1}^{M}2\sqrt{\varepsilon_m(1-\varepsilon_m)} .$$

若每个 $\varepsilon_m=1/2-\delta_m$ 且 $\delta_m>0$，则由 $\log(2\sqrt{\varepsilon_m(1-\varepsilon_m)})\le -2\delta_m^2$ 可得上界为 $\exp\{-2\sum_m\delta_m^2\}$，随 $M$ 指数衰减。**这个上界成立的前提是每一轮基学习器都比随机猜测略好**；一个仅略优于随机猜测的基学习器，便足以保证训练误差指数下降。

上界约束的是训练误差。测试误差另有保证机制（ESL 10.13 的间隔理论），但实践上取决于轮数与其他复杂度参数的选择，这是第六、七节的主题。

### 3. 弱学习器的定位

基学习器被称为**弱学习器**（*weak learner*），指其错误率仅需低于随机猜测即可。ESL 第 10 章的多数实验取允许两次分裂的树，训练速度与表示能力之间取得折中；仅允许一次分裂的**决策树桩**（*stump*）则更弱，但所需轮数随之增加。弱不等于越弱越好：第六节实验 3 显示，树深度超过某一水平后测试误差不再改善。

> **要点** 本节交代了提升法的定位：它不是一类新的模型，而是一种"逐轮修正"的拟合策略；其有效性依赖弱学习器条件，其复杂度由轮数而非单一模型的形式决定。

## 二、自适应提升算法

### 1. 记号与目标

设响应变量 $y_i\in\{-1,+1\}$，基学习器输出 $G_m(x)\in\{-1,+1\}$；第 $m$ 轮的样本权重记为 $w_i^{(m)}$，满足 $w_i^{(m)}\ge 0$ 且 $\sum_i w_i^{(m)}=1$。目标是给出系数 $\alpha_m$ 与基学习器 $G_m$，使组合函数
$f_M(x)=\sum_{m=1}^M\alpha_m G_m(x)$ 的损失尽可能小。初始权重取 $w_i^{(1)}=1/n$。

### 2. 算法流程

对 $m=1,\dots,M$ 依次执行以下三步：

(a) 以权重 $\{w_i^{(m)}\}$ 拟合基学习器 $G_m(x)$；

(b) 计算加权错误率与加权系数

$$\varepsilon_m=\frac{\sum_{i=1}^{n}w_i^{(m)}\,I\big[y_i\neq G_m(x_i)\big]}{\sum_{i=1}^{n}w_i^{(m)}},\qquad
\alpha_m=\frac{1}{2}\log\frac{1-\varepsilon_m}{\varepsilon_m}; \tag{2}$$

(c) 更新样本权重并归一化

$$w_i^{(m+1)}=w_i^{(m)}\exp\big\{-\alpha_m y_iG_m(x_i)\big\},\qquad w_i^{(m+1)}\leftarrow \frac{w_i^{(m+1)}}{\sum_j w_j^{(m+1)}}. \tag{3}$$

最终分类器为
$$G(x)=\operatorname{sign}\big(f_M(x)\big),\qquad f_M(x)=\sum_{m=1}^M\alpha_m G_m(x).$$

式 (2) 中 $\alpha_m$ 是第 $m$ 个基学习器的**加权系数**，其大小由 $\varepsilon_m$ 决定：错误率越低，加权系数越大，在最终表决中话语权越重。若 $\varepsilon_m=1/2$，则 $\alpha_m=0$，该轮不参与组合。

### 3. 权重更新的含义

式 (3) 的指数因子分为两种情形。分对的样本满足 $y_iG_m(x_i)=+1$，权重乘以 $e^{-\alpha_m}<1$ 被下调；分错的样本满足 $y_iG_m(x_i)=-1$，权重乘以 $e^{+\alpha_m}>1$ 被上调。因此，**每一轮被上一轮分错的样本，会在下一轮获得更大的权重**，把后续的学习能力集中到困难区域。$\alpha_m$ 越大，这种聚焦越强，因为加权系数同时反映了该轮学习器的可信度。

$\varepsilon_m$ 的取值范围决定了 $\alpha_m$ 的符号。当 $0<\varepsilon_m<1/2$ 时 $\alpha_m>0$，学习器正常参与；当 $\varepsilon_m=1/2$ 时 $\alpha_m=0$；当 $\varepsilon_m>1/2$ 时 $\alpha_m<0$，此时该学习器比随机猜测更差，Freund 与 Schapire (1997) 的处理是将其丢弃。实验 1 给出三轮权重更新的数值演示：两个样本、初始权重各为 $0.5$，前两轮某基学习器的加权错误率均为 $0.50$，加权系数均为 $0.0000$，权重序列保持不变；第三轮加权错误率降为 $0$ 时，加权系数升至 $18.4207$（见附录 B）。

### 4. 多分类推广：SAMME

二分类之外的推广需要修正 $\alpha_m$ 的形式。**SAMME**（*Stagewise Additive Modeling using a Multi-class Exponential loss*）取

$$\alpha_m=\log\frac{1-\varepsilon_m}{\varepsilon_m}+\log(K-1),$$

其中 $K$ 为类别数。当 $K=2$ 时 $\log(K-1)=0$，上式退化为二分类形式。SAMME 要求基学习器输出硬标签；若基学习器给出各类概率估计，可用 SAMME.R 的变体，其加权系数为
$\alpha_m=(K-1)\big(\log\frac{1-\varepsilon_m}{\varepsilon_m}+\log(K-1)\big)$，通常收敛更快。

> **注意** scikit-learn 1.6 之后的版本已移除 `algorithm="SAMME.R"` 选项，`AdaBoostClassifier` 默认即 SAMME；需要 SAMME.R 的行为可改用 LightGBM 或 XGBoost。实验 9 在四类 digits 数据集上以树桩为基学习器：$M=10$ 时测试准确率 $0.8194$，$M=50$ 时达到 $0.9630$，$M=100$ 后趋于平稳。

> **要点** 本节给出了自适应的完整流程。值得留意的是，权重更新式 (3) 与加权系数式 (2) 的形式并非经验设计，而是指数损失最小化的逐轮最优解，第三节给出这一推导。

## 三、指数损失与贪心优化的等价性

### 1. 指数损失

**指数损失**（*exponential loss*）定义为

$$L_{\exp}\big(y,f(x)\big)=\exp\big\{-y\,f(x)\big\},\qquad y\in\{-1,+1\},\ f(x)\in\mathbb{R}. \tag{4}$$

其合理性可由数值看出（实验 1）：当 $f(x)=+3$ 时，正确分类的代价为 $e^{-3}=0.050$，错误分类的代价为 $e^{3}=20.1$；当 $f(x)=+1$ 时两者分别为 $0.368$ 与 $2.7$；当 $f(x)=0$ 时均为 $1.0$。可见该损失对分类正确的样本代价趋近于零，对分类错误的样本代价随 $-yf$ 指数增长，且与 0-1 损失 $I[y\neq\operatorname{sign}(f)]$ 同向，同时保持光滑可微。

### 2. 前向分步加法模型

**前向分步加法建模**（*forward stagewise additive modeling*）把组合函数限制为加性形式
$$f_M(x)=\sum_{m=1}^{M}\beta_m\,G(x;\gamma_m),$$
训练目标是
$$(\beta_m,\gamma_m)=\arg\min_{\beta_m,\gamma_m}\sum_{i=1}^{n}L\Big(y_i,\sum_{\ell=1}^{M}\beta_\ell G(x_i;\gamma_\ell)\Big).$$

由于 $M$ 项联合优化不可行，采用贪心策略：第 $m$ 步固定已得的前 $m-1$ 项，只优化当前一对 $(\beta_m,\gamma_m)$，即
$$\sum_{i=1}^{n}L\Big(y_i,f_{m-1}(x_i)+\beta_m G(x_i;\gamma_m)\Big).$$

### 3. 逐轮最优解与权重的来源

将指数损失 (4) 代入上式，得
$$\sum_{i=1}^{n}\exp\big\{-y_if_{m-1}(x_i)\big\}\exp\big\{-\beta_m y_iG(x_i;\gamma_m)\big\}.$$

记 $w_i^{(m)}=\exp\{-y_if_{m-1}(x_i)\}$，它只依赖已经确定的 $f_{m-1}$，因此对当前 $(\beta_m,\gamma_m)$ 而言是常数。目标函数化为
$$\sum_{i=1}^{n}w_i^{(m)}\exp\big\{-\beta_m y_iG(x_i;\gamma_m)\big\}.$$

对固定的 $\beta_m$，最小化上式只需让基学习器在加权意义下错分最少，也就是最小化式 (1) 中的 $\varepsilon_m$。把使 $\varepsilon_m$ 最小的 $G_m$ 代回并对 $\beta_m$ 求导置零，得到
$$\beta_m=\frac{1}{2}\log\frac{1-\varepsilon_m}{\varepsilon_m},$$
恰为式 (2) 的 $\alpha_m$。而第 $m+1$ 轮的权重满足
$$w_i^{(m+1)}=\exp\{-y_i[f_{m-1}(x_i)+\alpha_mG_m(x_i)]\}=\exp\{-y_if_{m-1}(x_i)\}e^{-\alpha_my_iG_m(x_i)},$$
其中第一个因子正是 $w_i^{(m)}$，于是得到第二节的更新式 (3)。

也就是说，自适应提升并不是一套启发式的样本重加权技巧，而是**指数损失下的前向分步加法模型**：ESL 第 10.4 节"Boosting Fits an Additive Model"表述的正是这一结论。样本权重 $w_i^{(m)}$ 是历史模型的指数投影，只在每一轮内部作为常数出现。

### 4. 指数损失的代价

指数损失的一个直接后果是对极端值敏感。错分样本的代价 $\exp\{+yf\}$ 随 $-yf$ 指数增长，没有上界；一个异常的或标签错误的样本会获得极大的权重或梯度，主导后续若干轮基学习器的拟合。**因此，同为提升法，指数损失比对数损失更易被噪声左右**，这既是自适应提升的弱点，也是梯度提升在实践中更常用的原因之一。

> **要点** 本节补齐了理论链条：自适应提升 = 指数损失 + 前向分步。这条链条同时解释了它的优点（训练误差指数下降）与代价（对错分样本的惩罚无上界）。

## 四、梯度提升：函数空间中的下降

### 1. 从参数空间到函数空间

普通梯度下降在参数空间更新 $\beta\leftarrow\beta-\eta\nabla_\beta L(\beta)$：每一步沿损失函数的负梯度方向移动，步长为 $\eta$。提升法面临的是另一类问题：待求量不是有限维参数，而是函数本身，因此下降发生在函数空间。

设当前组合模型为 $f_{m-1}(x)$，考虑加入一个新的基函数 $h(x)$，使
$$\sum_{i=1}^{n}L\big(y_i,f_{m-1}(x_i)+h(x_i)\big)$$
下降。对 $h$ 在零点作一阶展开，目标近似为
$$\sum_{i=1}^{n}\Big[L\big(y_i,f_{m-1}(x_i)\big)+g_i\,h(x_i)\Big],$$
其中
$$g_i=-\left[\frac{\partial L\big(y_i,f(x_i)\big)}{\partial f(x_i)}\right]_{f=f_{m-1}} \tag{5}$$
为损失对当前函数的负梯度。由于第一项与 $h$ 无关，最小化上式等价于让 $h$ 以最小二乘拟合这 $n$ 个数 $g_i$。于是得到每一步的构造：**基学习器拟合负梯度，组合函数沿拟合方向前进一步**，即
$$f_m(x)=f_{m-1}(x)+\nu\,h_m(x), \tag{6}$$
$\nu\in(0,1]$ 是**收缩率**（*shrinkage*）。

### 2. 残差是平方损失的负梯度

对平方损失 $L(y,f)=\tfrac12(y-f)^2$，负梯度为
$$g_i=-(y_i-f_{m-1}(x_i))=f_{m-1}(x_i)-y_i,$$
其相反数即**残差** $y_i-f_{m-1}(x_i)$。因此"梯度提升拟合残差"是"梯度提升拟合负梯度"在平方损失下的特例；换成其他损失，拟合目标随之改变。

常用损失的负梯度可归纳为下表：

| 损失 $L(y,f)$ | 负梯度 $-[\partial L/\partial f]_{f_{m-1}}$ | 适用场景 |
| :--- | :--- | :--- |
| 平方误差 | $y_i-f_{m-1}(x_i)$ | 回归 |
| 绝对偏差 | $\operatorname{sign}(y_i-f_{m-1}(x_i))$ | 离群点较多的回归 |
| Huber | 残差，且按阈值截断 | 介于两者之间的稳健回归 |
| 分位数 | 超出分位一侧为 $\tau$，另一侧为 $\tau-1$ | 分位数回归 |
| Bernoulli 对数 | $y_i-p(x_i),\;p=(1+e^{-2f})^{-1}$（$y_i\in\{0,1\}$） | 二分类 |
| 多分类对数 | $y_{ik}-p_k(x_i)$ | 多分类 |
| Poisson | $y_i-\mu_i$ | 计数数据 |

以二分类为例（$y_i\in\{0,1\}$）：当 $p(x_i)=0.3$ 且 $y_i=1$ 时，负梯度为 $1-0.3=0.7$，基学习器以 $0.7$ 为目标值，拟合结果倾向于抬高该点的概率；当 $y_i=0$ 时，负梯度为 $-0.3$，倾向于压低概率。实验 8 验证了这一链路。

### 3. 梯度提升算法

梯度提升算法（*gradient boosting MART*，ESL 算法 10.2）的步骤如下。

初始化模型
$$f_0(x)=\arg\min_{c}\sum_{i=1}^{n}L(y_i,c),$$
平方损失下 $f_0(x)\equiv\bar y$，对数损失下取先验概率的对数几率。

对 $m=1,\dots,M$：

(a) 计算负梯度 $g_i=-\big[\partial L(y_i,f(x_i))/\partial f(x_i)\big]_{f=f_{m-1}}$，$i=1,\dots,n$；

(b) 以 $\{(x_i,g_i)\}_{i=1}^n$ 为训练集拟合基学习器，得到对负梯度的逼近
$$h_m(x)=\arg\min_{h}\sum_{i=1}^{n}\big[g_i-h(x_i)\big]^2; \tag{7}$$

(c) （可选）线搜索更新步长
$$c_m=\arg\min_{c}\sum_{i=1}^{n}L\big(y_i,f_{m-1}(x_i)+c\,h_m(x_i)\big); \tag{8}$$

(d) 更新 $f_m(x)=f_{m-1}(x)+\nu\,c_m\,h_m(x)$（实现中常取 $c_m=1$，由收缩率 $\nu$ 承担步长控制）。

最终输出 $\hat f(x)=f_M(x)$。回归任务直接取该值；二分类取 $p(x)=\big(1+e^{-2f_M(x)}\big)^{-1}$；多分类对每个类别各维护一个 $f_k(x)$，以 softmax 归一化为概率。

### 4. 与自适应提升的关系

两种算法的差别只在损失函数：自适应提升固定损失为指数损失，把梯度写入样本权重并求解闭式的逐轮最优系数；梯度提升允许任意可微损失，直接以基学习器拟合负梯度，并把步长交给收缩率。ESL 由此把自适应提升视为梯度提升在指数损失下的特例，而多分类 SAMME 则是多分类指数损失下的同一算法的改写。

> **要点** 本节的核心是把"提升"统一理解为函数空间中的下降。参数只有三个：损失函数、基学习器、步长（收缩率）；后续所有实践问题都可归结为对这三者的选择。

## 五、树作为基学习器

### 1. 分裂准则的推导

基学习器多取深度较小的回归树。ESL 算法 10.3 给出平方损失下树的逐层构造：设当前节点分裂为左右两个叶，对应区域分别记为 $R_\ell$ 与 $R_r$，叶内样本数记为 $N_\ell$ 与 $N_r$，叶值分别为 $c_\ell=-\bar g_\ell$ 与 $c_r=-\bar g_r$，其中
$$\bar g_\ell=\frac{1}{N_\ell}\sum_{x_i\in R_\ell}g_i,\qquad \bar g_r=\frac{1}{N_r}\sum_{x_i\in R_r}g_i \tag{9}$$
为该叶内负梯度的均值。

分裂后对负梯度的残差平方和为
$$\sum_{x_i\in R_\ell}(g_i-c_\ell)^2+\sum_{x_i\in R_r}(g_i-c_r)^2
=N_\ell\bar g_\ell^2+N_r\bar g_r^2.$$

对固定的切分变量 $j$ 与切分点 $s$，最小化上式等价于最大化
$$\mathcal{S}(j,s)=N_\ell\bar g_\ell^2+N_r\bar g_r^2, \tag{10}$$
其中 $j$ 遍历各候选变量、$s$ 遍历各候选切分点。也就是说，**最优分裂点由负梯度在两侧平方和的大小决定**，而非由响应 $y$ 直接决定；对平方损失，负梯度即残差，于是最优分裂等价于按残差平方和选择切分。

### 2. 叶节点取值与复杂度参数

得到叶区域后，叶值为该叶内负梯度均值的相反数，即 $c_\ell=-\bar g_\ell$；最终预测是对所有叶值的收缩后求和。树的复杂度由**交互深度**（*interaction depth*）控制：深度为 2 时每棵树含至多两次分裂，允许特征间的二阶交互而不强行引入高阶项。

### 3. 二阶项的引入

上述准则使用一阶信息。XGBoost (Chen & Guestrin, 2016) 的目标函数为
$$\mathcal{L}^{(m)}=\sum_{i=1}^{n}L(y_i,\hat y_i^{(m-1)}+f_m(x_i))+\Omega(f_m),\qquad \Omega(f)=\gamma T+\frac{1}{2}\lambda\sum_{\ell=1}^{T}c_\ell^2, \tag{11}$$
其中 $T$ 为叶数、$c_\ell$ 为叶值，$\gamma$ 与 $\lambda$ 为正则化系数。对其作二阶泰勒展开得
$$\mathcal{L}^{(m)}\approx\sum_{i=1}^{n}\bigg[g_if_m(x_i)+\frac{1}{2}h_if_m^2(x_i)\bigg]+\Omega(f_m),$$
$g_i$、$h_i$ 分别为损失在 $\hat y_i^{(m-1)}$ 处的一阶与二阶导数。此时叶 $\ell$ 的最优叶值与对应最小的目标函数值分别为
$$c_\ell^*=-\frac{\sum_{x_i\in R_\ell}g_i}{\sum_{x_i\in R_\ell}h_i+\lambda},\qquad
\mathcal{L}^{(\ell)*}=-\frac{1}{2}\frac{\big(\sum_{x_i\in R_\ell}g_i\big)^2}{\sum_{x_i\in R_\ell}h_i+\lambda}+\gamma T. \tag{12}$$

于是分裂增益为
$$\mathcal{G}=\frac12\left[\frac{(\sum_{R_{L}}g_i)^2}{\sum_{R_L}h_i+\lambda}+\frac{(\sum_{R_{R}}g_i)^2}{\sum_{R_R}h_i+\lambda}-\frac{(\sum_{R} g_i)^2}{\sum_{R}h_i+\lambda}\right]-\gamma . \tag{13}$$

对照式 (10)：一阶情形是二阶情形在 $h_i$ 恒为常数时的特例。正则项 $\Omega$ 使叶数 $T$ 与叶值 $c_\ell$ 同时进入目标，这是现代实现对过拟合的主要约束手段。

> **要点** 本节说明了为什么提升法常与树搭配：树的逐层构造恰好是对负梯度的分段常数逼近，分裂准则与叶值都有闭式；二阶信息则把同样的推导平移一次求导，不改变整体框架。

## 六、复杂度控制：收缩率、轮数与子采样

### 1. 收缩率与轮数的权衡

组合 $f_M=\sum_m\nu h_m$ 的复杂度由收缩率 $\nu$ 与轮数 $M$ 共同决定：$\nu$ 越小，每步移动越短，需要更多步才能到达同一个位置。由于步长短时数值优化的截断误差更小，小收缩率通常带来更低的测试误差，代价是计算量上升。

实验 5 在 Friedman#1 数据上给出了这一权衡的具体形态（$n=1000$，噪声标准差为 1，信号为 $10\sin(\pi x_1x_2)+20(x_3-0.5)^2+10x_4+5x_5$，其余五个变量为噪声；树深度为 3；评价指标为测试 RMSE）：

> **例** 不同收缩率与轮数下的测试 RMSE（见附录 B 实验 5a）
>
> | $\nu$ | $M$=10 | 50 | 100 | 300 | 500 | 1000 |
> | :--- | ---: | ---: | ---: | ---: | ---: | ---: |
> | 0.10 | 3.384 | 1.997 | 1.710 | 1.569 | **1.560** | 1.567 |
> | 0.05 | 3.988 | 2.522 | 2.011 | 1.629 | **1.584** | 1.561 |
> | 0.01 | 4.714 | 3.993 | 3.406 | 2.365 | 2.028 | **1.695** |
>
> 三个收缩率的最小值分别出现在 $M=500$、$M=1000$ 与 $M\ge 1000$，$\nu$ 越小最优轮数越大；同一收缩率下过大的 $M$ 使测试误差回升（$\nu=0.10$ 时 $M$ 由 500 增至 1000，RMSE 从 1.560 升至 1.567）。

固定轮数预算的比较更直接（实验 6）：$\nu=0.10, M=200$ 得测试 MSE $2.5848$；$\nu=0.02, M=1000$ 得 $2.4556$；$\nu=0.01, M=2000$ 得 $2.4105$。三者计算量不同，就最终精度而言小收缩率占优。ESL 10.12 给出的操作建议是先取一个较小的收缩率（例如 0.01），由验证误差确定轮数，再视精度需要调整两者。

### 2. 逐轮误差曲线与早停的可能位置

由于串行结构，梯度提升可以在任意 $M$ 处截断。实验 5b 取 $\nu=0.10$、$M=1000$，用逐轮预测考察误差随轮数的轨迹：

> **例** 逐轮 MSE（见附录 B 实验 5b）
>
> | $M$ | 1 | 2 | 5 | 10 | 25 | 50 | 100 | 200 | 400 | 700 | 1000 |
> | :--- | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
> | 训练 MSE | 22.09 | 19.56 | 14.40 | 9.46 | 3.88 | 1.72 | 0.87 | 0.42 | 0.13 | 0.031 | 0.0078 |
> | 测试 MSE | 22.16 | 20.00 | 15.72 | 11.45 | 6.19 | 3.99 | 2.92 | 2.58 | 2.45 | 2.44 | 2.46 |
>
> 训练误差单调下降并趋近于零，测试误差在 $M$ 约为 400 至 700 时达到最低，此后转而上升。这一分离现象说明超过该轮数后，模型开始把拟合容量分配给噪声而非信号，因此轮数本身构成一个需要选择的复杂度参数。

该数据的噪声方差为 1，测试 MSE 的下限约为 1；2.45 高于下限的部分来自采样波动与基学习器对 $\sin(\pi x_1x_2)$ 的逼近误差。增大 $M$ 无法消去这两项，只有更换基学习器或换问题设定才能改变。

### 3. 子采样

**随机梯度提升**（*stochastic gradient boosting*）在每一轮拟合前不放回地抽取比例 $\varphi$ 的子样本，只在该子样本上计算负梯度并拟合基学习器。子采样带来的额外随机性具有类似装袋法的平均效应，同时降低每轮计算量。实验 7 的结果（$\nu=0.05$、$M=500$、树深度为 3）为：$\varphi=1.0$ 时训练 MSE $0.3132$、测试 MSE $2.5100$；$\varphi=0.5$ 时训练 MSE $0.2936$、测试 MSE $2.4229$；$\varphi=0.3$ 时训练 MSE $0.3566$、测试 MSE $2.1501$。

可见子采样使测试误差改善，而训练误差不再单调下降（$\varphi=0.3$ 时反而上升）。代价是训练曲线震荡、早期停止的判据也变得嘈杂。ESL 10.12 给出的实践取值为 $\varphi=0.5$。

### 4. 基学习器复杂度

实验 3 在同一个二分类数据上（$n=500$，$M=200$，自适应提升）比较四种树深度：深度 1 时训练准确率 0.880、测试 0.853；深度 2 时训练 0.986、测试 0.873；深度 3 时训练 1.000、测试 0.900；深度 5 时训练 1.000、测试 0.887。深度 3 之后训练已饱和而测试下降，深度 5 相对深度 3 的额外复杂度只带来方差。
### 5. 诊断指引

| 现象 | 诊断 | 处置 |
| :--- | :--- | :--- |
| 训练与测试误差同时偏高 | 欠拟合：轮数不足、收缩率过大、树过浅 | 增加 $M$、减小 $\nu$、增大树深度 |
| 训练误差趋零，测试误差随 $M$ 上升 | 过拟合 | 减小树深度、增大叶节点最小样本数、取 $\varphi<1$、设早停 |
| 训练误差震荡不降 | 收缩率过大或基学习器过弱 | 减小 $\nu$；或提高基学习器容量 |
| 回归结果被少数点带偏 | 平方损失对离群点敏感 | 改用 **Huber 损失**（*Huber loss*）或绝对偏差损失 |

> **要点** 本节把调参归约为三个量的联合选择：步长 $\nu$、步数 $M$、每步方向的范围即树深度。三者的乘积关系由实验 5、6 给出，而停止步数的位置由实验 5b 的误差分离给出。

## 七、过拟合与早停

### 1. 提升法并非对过拟合免疫

一个流传的说法是提升法不易过拟合。该说法成立的条件是基学习器弱、收缩率小、轮数适中；条件不成立时，提升法与任何逐步增加模型容量的算法一样会过拟合。实验 10 取 $n=300$、$p=20$（其中 5 个为有效特征）、标签噪声比例 0.25，基学习器为深度 5 的树、$M$ 由 10 增至 400：训练准确率早在 $M=10$ 时即为 1.000，测试准确率在 0.700 至 0.756 之间徘徊，未随轮数改善。

原因可回到第三节的损失性质：指数损失或对数损失对困难样本的惩罚随预测偏移增长，噪声标签会持续产生较大的梯度，把后续轮次引向对噪声的拟合。Logistic 型损失的增长速度比指数损失慢，实践中同一设定下梯度提升通常比自适应提升更稳。

### 2. 早停的三种实现

其一，内置早停参数：`GradientBoostingClassifier(n_estimators=2000, n_iter_no_change=10, validation_fraction=0.1, tol=1e-4)` 会在验证损失连续 10 轮改善不足 $10^{-4}$ 时停止，训练结束后的 `n_estimators_` 给出实际使用的轮数。其二，逐轮评估：`staged_predict` 输出每个 $M$ 的预测，配合验证集取测试误差最低的 $M$，做法同实验 5b。其三，库原生支持：XGBoost 与 LightGBM 的 `early_stopping_rounds` 配合 `eval_set` 使用相同的逻辑。

### 3. 噪声敏感性的缓解

对噪声或重尾数据，Huber 损失（以阈值截断残差的负梯度）与分位数损失比平方损失更稳健；对数损失对离群点的响应比指数损失缓和；子采样通过平均效应降低对方差的依赖。这些手段可叠加，但都会增加一个超参数，因此仍需交叉验证。

> **要点** 本节给出的结论是：轮数 $M$ 是提升法中最重要的复杂度参数，它与收缩率 $\nu$ 共同决定训练停止的位置；实践上的早停方法，本质都是在验证误差曲线上寻找第六节实验 5b 所示的最低点。

## 八、基模型选择：单棵树、装袋法、提升法

三者的定位可从偏差与方差两个方向比较：

| 维度 | 单棵深树 | 装袋法（随机森林） | 提升法 |
| :--- | :--- | :--- | :--- |
| 偏差 | 低 | 低 | 逐轮修正，通常最低 |
| 方差 | 高 | 平均后最低 | 低，但受轮数与收缩率控制 |
| 训练方式 | 一次拟合 | 平行 | 串行，$O(Mn)$ |
| 超参数敏感度 | 低 | 低 | 高，三个量联动 |
| 概率输出 | 不可靠 | 由投票比例给出 | 天然由对数几率或 softmax 给出 |
| 对噪声的鲁棒性 | 中 | 高（噪声被平均） | 中，依赖损失选择 |
| 可解释性 | 整树可视化 | 变量重要性 | 变量重要性，辅以部分依赖图 |

装袋法与提升法的条件—结论关系可归纳如下：其一，当真实回归函数接近线性或低阶交互时，单棵较浅的树或线性模型即可取得接近的测试误差，此时提升法相对装袋法的优势有限；其二，当数据以高维稀疏为主、噪声比例大、或要求快速取得稳定基线时，装袋法的方差特性和低超参依赖更适合；其三，当特征间存在强交互、样本量足以支撑串行拟合、且允许交叉验证调参时，提升法通常取得最低的测试误差，ESL 10.7 的多种模拟给出这一方向的证据。

> **要点** 三者的差别不在模型类别而在组合方式：同一棵深树装袋后削减方差，串行加权后削减偏差；选择取决于数据中的方差与噪声哪一个更难降。

## 九、现代实现：二阶项、正则化与工程

### 1. XGBoost：把正则化写进目标函数

XGBoost 的改进集中在第五节给出的三处：目标函数加入 $\Omega(f)=\gamma T+\frac12\lambda\sum_\ell c_\ell^2$，使叶数与叶值同时受约束；分裂增益使用式 (13) 的二阶形式，比一阶近似更接近真实损失的下降量；配合列分块预排序、缺失值默认方向学习等工程手段。其中第二项是数值层面的改进，第一项才是正则化层面的改进：它把树深度与叶值大小一起罚，使之前只能靠收缩率间接控制的复杂度有了直接入口。

### 2. LightGBM：直方图与稀疏梯度抽样

LightGBM 的三个改进各有针对性。直方图算法把连续特征离散为固定数量的桶，分裂增益由直方图统计量估计，内存与时间开销与样本量和特征数解耦；**GOSS**（*Gradient-based One-Side Sampling*）保留梯度绝对值较大的样本，对梯度绝对值较小的样本按比例抽样，在保留大梯度信息的同时减少每轮计算量；**EFB**（*Exclusive Feature Bundling*）把互斥的稀疏特征打包，降低特征维数。此外 LightGBM 默认采用**叶优先生长**（*leaf-wise*），在 `num_leaves` 的约束下每次分裂增益最大的叶，同等叶数下通常更快达到较低损失，但也更容易过拟合，叶数上限需要显式调小。

### 3. CatBoost：类别特征与有序提升

CatBoost 的两处改进分别针对两类特征与估计偏差。对高基数类别特征，采用有序目标编码统计（*ordered target statistics*），用排列组合的方式估计每个类别的替代值，避免目标泄漏；对估计偏差，采用有序提升（*ordered boosting*）：每一轮训练时按样本排列构造无偏子集，缓解经典实现中训练子集与全数据集分布不一致造成的预测偏移（*prediction shift*）。其对类别特征的处理无需人工编码，参数默认值在较宽的数据范围上都能工作。

### 4. 选择的条件—结论

| 条件 | 结论 |
| :--- | :--- |
| 以教学与原理复现为目的，数据规模小 | 用 sklearn 的 `GradientBoosting*`，即 ESL 算法 10.2 的直接实现 |
| 中大规模表格数据，希望文档与生态成熟 | XGBoost |
| 样本量大、特征多且稀疏，速度优先 | LightGBM |
| 含大量高基数类别特征，希望减少预处理 | CatBoost |

> **要点** 三个实现在数学框架上一致，差别在近似与约束的具体形式：二阶项与正则项改进优化质量，直方图与采样改进计算效率，类别编码改进数据预处理。选定框架后，收缩率、轮数与基学习器复杂度仍需按第六节的方式确定。

## 十、小结

| 知识点 | 一句话要点 |
| :--- | :--- |
| 提升法的定位 | 串行拟合 + 加权组合，主要削减偏差 |
| 有效性条件 | 每轮基学习器的加权错误率小于 $1/2$，训练误差指数下降 |
| 自适应提升 | 指数损失下的前向分步加法模型，最优系数 $\alpha_m=\frac12\log\frac{1-\varepsilon_m}{\varepsilon_m}$ |
| 多分类 | SAMME 增加 $\log(K-1)$ 修正项 |
| 指数损失的代价 | 对错分样本惩罚无上界，对噪声敏感 |
| 梯度提升 | 基学习器拟合负梯度，组合函数以收缩率 $\nu$ 前进 |
| 负梯度表 | 平方损失为残差，二分类对数损失为 $y-p$ |
| 树的分裂准则 | 平方损失下最大化式 (10)，叶值取负梯度均值 |
| 二阶推广 | XGBoost 用一阶、二阶导数求和之比定叶值，把正则项写进目标 |
| 复杂度参数 | 步长 $\nu$、步数 $M$、步幅范围即树深度，三者联动 |
| 早停 | 寻找训练误差与测试误差分离点，即验证误差最低的 $M$ |
| 子采样 | 注入平均效应降方差，代价是训练曲线震荡 |
| 过拟合条件 | 基学习器强、收缩率大、轮数多、噪声大 |
| 三模型定位 | 方差主导选装袋，精度优先且可调参选提升，可解释优先选单树 |

贯穿全部内容的一条线索是：提升法的每一步都可以写成"以某个损失对当前函数求梯度，用一个弱学习器逼近该梯度，按步长前进"。自适应提升是取指数损失、以权重存储梯度的特例；树的分裂与叶值是同样推导的离散化版本；XGBoost 的二阶与正则项只是把这一推导多求一次导并加上约束。实践中的收缩率、轮数、深度、子采样，对应的正是步长、步数、步幅范围与抽样比例。

## 附录 A：代码

以下代码使用 scikit-learn，与第六、七节引用的数值对应。

```python
import numpy as np
from sklearn.ensemble import (AdaBoostClassifier, GradientBoostingClassifier,
                              GradientBoostingRegressor)
from sklearn.tree import DecisionTreeClassifier, DecisionTreeRegressor
from sklearn.datasets import make_classification, load_digits
from sklearn.model_selection import train_test_split
from sklearn.metrics import mean_squared_error, accuracy_score

rng = np.random.default_rng(42)

# ---- 数据: Friedman#1 (实验 5-7) ----
n = 1000
X = rng.uniform(0, 1, size=(n, 10))
y = (10 * np.sin(np.pi * X[:, 0] * X[:, 1]) + 20 * (X[:, 2] - 0.5) ** 2
     + 10 * X[:, 3] + 5 * X[:, 4] + rng.normal(0, 1, n))
Xtr, Xte, ytr, yte = train_test_split(X, y, test_size=0.3, random_state=42)

# 收缩率 x 轮数网格 (实验 5a)
for lr in (0.10, 0.05, 0.01):
    res = []
    for M in (10, 50, 100, 300, 500, 1000):
        gb = GradientBoostingRegressor(n_estimators=M, learning_rate=lr,
                                       max_depth=3, random_state=42).fit(Xtr, ytr)
        res.append(np.sqrt(mean_squared_error(yte, gb.predict(Xte))))
    print(lr, np.round(res, 3))

# 逐轮误差曲线, 即早停点的直观定位 (实验 5b)
gb = GradientBoostingRegressor(n_estimators=1000, learning_rate=0.1,
                               max_depth=3, random_state=42).fit(Xtr, ytr)
te = [mean_squared_error(yte, p) for p in gb.staged_predict(Xte)]
print("best M =", int(np.argmin(te)) + 1, "test MSE =", min(te))

# 内置早停 (第七节)
gb2 = GradientBoostingRegressor(n_estimators=2000, n_iter_no_change=10,
                                validation_fraction=0.1, tol=1e-4,
                                random_state=42).fit(Xtr, ytr)
```
