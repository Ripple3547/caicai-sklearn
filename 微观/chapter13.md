显性成本
– 需要企业支出货币的投入成本
• 隐性成本
– 不需要企业支出货币的投入成本
– 会计所忽略的，经济学分析需要考虑，因为影响
企业决策
• 总成本
= 显性成本 + 隐性成本


• 资本要素的机会成本（固定成本）
– 隐性成本
– 已经投资于企业的金融资本的机会成本
• 作为储蓄
• 投资于生意中
– 会计上不会作为成本
• 劳动、原材料等的机会成本（可变成本）
– 可以从事其他工作获得收入或价值
– 可以用于其他产品的生产


• 经济利润
–总收益减去总成本
• 总成本包括显性成本和隐性成本
• 会计利润
–总收益减去总显性成本
–通常比经济利润要大

TC = TVC + TFC
- 固定成本
- 可变成本

AC(AVC)平均总成本
AFC 平均固定成本
AVC 平均可变成本
MC：TC 的导数。
变化趋势？
生产函数的形状和总成本曲线的形状，分别反映了什么问题。


重点：MC 一定会穿过 ATC 的最低点。从两者的含义来看，当 MC 小于 ATC 时，代表边际成本小于平均总成本，增加产量会减小平均总成本；当 MC 大于 ATC 时，增大产量反而会增加平均总成本，因此两者相交的部分一定是 ATC 的最低点。

利润最大化点满足：MR = MC（ $\frac{ \partial \pi }{ \partial Q } = \frac{ \partial TR - TC }{ \partial Q } = MR - MC = 0$）
