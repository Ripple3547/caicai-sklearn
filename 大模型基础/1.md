n grams 语言模型：通过计算文本中的 n gram 和 n-1 gram 的相对频率来计算文本 $w_{1: N}$ 的出现频率。
$$
P_{n-grams}(w_{1:N}) = \prod_{i=n}^{N} \frac{C(w_{i - n + 1 : i})}{C(w_{i - n + 1 : i -1})}
$$
分子是 n 个长度的词序列 $w_{i - n + 1 : i}$ 在语料库中的出现次数。
- 当 $n=1$ 时，称为 unigram ，不考虑文本的上下文关系。即分子为 $C(w_{i})$，单个词在语料库中的出现次数；分母 $C(w_{i - n + 1: i-1}) = C_{total}$ 为语料库中的词总数
- $n=2$ 时，称为 bigrams，表示对前一个词考虑。
- 当 $n=3$ 时，称为 trigrams. 表示对前两个词考虑。

n grams 语言模型对未知文本有一定的泛化能力，但是当 n 比较大时，泛化能力会减弱，如此长度的词序列在语料库中难以找到，导致计算出的概率为 0 ；而 n 比较小时，模型无法承载语料库的特性和特征信息。

可以通过 Smoothing 技术改善 0 概率现象。
