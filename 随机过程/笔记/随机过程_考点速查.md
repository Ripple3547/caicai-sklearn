## 1　符号与约定

| 记号 | 含义 |
|---|---|
| $P_{ij}$ | 一步转移概率 $P\{X_{n+1}=j\mid X_n=i\}$（时齐，不依赖 $n$） |
| $\mathbf P$ | 转移矩阵，$(\mathbf P)_{ij}=P_{ij}$，**行和为 1** |
| $P_{ij}^{(n)}$ | $n$ 步转移概率，$P_{ij}^{(n)}=(\mathbf P^n)_{ij}$，$P_{ij}^{(0)}=\delta_{ij}$ |
| $f_i$ | 从 $i$ 出发、将来能再次回到 $i$ 的概率 |
| $m_i$ | 从 $i$ 出发首次返回 $i$ 的平均时间，$m_i=E[N_i\mid X_0=i]$ |
| $f_{ij}$ | 从 $i$ 出发、最终进入 $j$ 的概率（$i\ne j$ 时即首达概率） |
| $\pi_j$ | 长期比例 / 平稳概率（时间平均） |
| $\alpha_j$ | 极限概率 $\lim_{n\to\infty}P\{X_n=j\}$（逐项极限） |
| $s_{ij}$ | 从瞬时态 $i$ 出发、进入常返态之前停留在 $j$ 的**期望期数** |
| $\mathbf P_T$ | 转移矩阵限制在瞬时状态集合 $T$ 上的子矩阵（行和 $<1$） |
| $\mu,\sigma^2$ | 分支过程单个个体的后代数均值、方差 |

## 2　定义与基本事实

### 2.1 马尔可夫链

- **随机过程** $\{X(t),t\in T\}$：一族随机变量；固定 $t$ 是随机变量，固定样本路径是 $t$ 的函数。
- **马尔可夫链**：离散时间 $n=0,1,2,\dots$，状态取值**有限或可数无穷**，且对一切 $n$、一切状态
  $$P\{X_{n+1}=j\mid X_n=i,X_{n-1}=i_{n-1},\dots,X_0=i_0\}=P\{X_{n+1}=j\mid X_n=i\}=P_{ij}$$
- **两条基本性质**：$P_{ij}\ge0$；$\sum_{j}P_{ij}=1$（**行**和）。
- **时齐**：$P_{ij}$ 与 $n$ 无关（本章默认）。

### 2.2 建模：状态怎么选

| 情形 | 做法 |
|---|---|
| 未来只依赖"现在" | 状态 = 现在的状态（Example 4.1 天气，2 状态） |
| 未来依赖最近 $k$ 期 | 状态 = 最近 $k$ 期的**组合**（Example 4.4，$k=2$ → 4 状态） |
| 外部随机量驱动转移 | 把外部量（如泊松理赔次数 $a_k$）写进 $P_{ij}$（Example 4.7） |
| 有边界/吸收 | 边界状态设 $P_{ii}=1$（赌徒破产 0 与 $K$） |

> **判断能否建成一阶链**：问"给定现在状态，未来还与哪些历史信息有关？"若有关，就把那些信息并入状态。

### 2.3 常用模型一览

| 模型 | 状态 | 转移概率 |
|---|---|---|
| 两状态天气 | 雨/晴 | $P_{00}=\alpha,\ P_{01}=1-\alpha,\ P_{10}=\beta,\ P_{11}=1-\beta$ |
| 两天天气（扩维） | $(昨天,今天)$ | 4 状态，每行只有 2 个非零元（见笔记 4.4） |
| 随机游走 | $\mathbb Z$ | $P_{i,i+1}=p,\ P_{i,i-1}=1-p$ |
| 赌徒破产 | $0..K$ | 中间 $p$ / $1-p$，端点 $P_{00}=P_{KK}=1$ |
| Bonus–Malus | 1..4 | 由 $a_k=e^{-\lambda}\lambda^k/k!$ 查表 |
| 两球瓮 | 红球数 0,1,2 | 三对角，$P_{ii}=0.8$，$P_{i,i\pm1}=0.1$ 或 $0.2$ |

## 3　$n$ 步转移与 Chapman–Kolmogorov

$$\boxed{P_{ij}^{(n+m)}=\sum_{k=0}^{\infty}P_{ik}^{(n)}P_{kj}^{(m)}},\qquad \boxed{\mathbf P^{(n+m)}=\mathbf P^{(n)}\mathbf P^{(m)}},\qquad \boxed{\mathbf P^{(n)}=\mathbf P^{n}}$$

- 含义：$n+m$ 步 = 先走 $n$ 步到中间状态 $k$，再走 $m$ 步到 $j$，对 $k$ 全概率求和。
- $P_{ij}^{(n)}$ 是"**恰好**第 $n$ 步在 $j$"，中途可以已经过 $j$；**首达**是另一回事（$f_{ij}$）。
- $\mathbf P^n$ 仍行和为 1。

### 3.1 已知起点 vs 随机起点

| 已知 | 公式 |
|---|---|
| $X_0=i$ 已知 | 直接读 $P_{ij}^{(n)}$ |
| 初始分布 $P(X_0=i)=v_i$ | $P(X_n=j)=\sum_i v_iP_{ij}^{(n)}$（即 $v\mathbf P^n$ 的第 $j$ 分量） |

### 3.2 首次进入某集合的通用框架（讲义 p25）

把集合 $A$ 的所有状态**合并成一个吸收态 $A$**，得新链 $\mathbf Q$，则
$$\beta=P\{\text{$m$ 步内首次进入 }A\mid X_0=i\}=Q_{i,A}^{(m)}$$
- $P(N\le m)$ 型问题：把"成功"设为吸收态，答案就是 $m$ 步后落在吸收态的概率。
- $P(N=m)$ 型问题：要求第 $m-1$ 步**尚未**成功（停在"差一步"的状态），再乘最后一步的概率。

## 4　状态分类与常返性

### 4.1 分类链条

```
i 可达 j ：存在 n≥0 使 P_ij^(n) > 0        （单向！）
i ↔ j 互通：i 可达 j 且 j 可达 i            （双向，等价关系：自反/对称/传递）
类       ：互相互通的状态构成的子集          （任意两类相同或不相交）
不可约   ：只有一个类 ⇔ 所有状态两两互通
```

- 每状态与自身可达（$n=0$ 时 $P_{ii}^{(0)}=1$）。
- 可达**不是**等价关系（缺对称性），互通才是——这是分类的数学基础。
- 吸收态（$P_{ii}=1$）自成一类。

### 4.2 常返 / 瞬时

| 概念 | 定义 | 等价判据 | 直观 |
|---|---|---|---|
| 常返 | $f_i=1$ | $\sum_{n=1}^\infty P_{ii}^{(n)}=\infty$ | 一定回来，且无穷多次 |
| 瞬时 | $f_i<1$ | $\sum_{n=1}^\infty P_{ii}^{(n)}<\infty$ | 有正概率 $1-f_i$ 再也回不来 |

- 瞬时态：从 $i$ 出发停留在 $i$ 的期数 $\sim\mathrm{Geom}(1-f_i)$，期望 $1/(1-f_i)$。
- $\sum_nP_{ii}^{(n)}$ = 回到 $i$ 的**期望次数**（示性变量求和）。
- **常返、瞬时都是类性质**（$i$ 与 $j$ 互通则同类同性质）。

### 4.3 正常返 / 零常返

| 概念 | 条件 |
|---|---|
| 正常返 | $f_j=1$ 且 $m_j=E[N_j\mid X_0=j]<\infty$（等价于 $\pi_j>0$） |
| 零常返 | $f_j=1$ 但 $m_j=\infty$（等价于 $\pi_j=0$，会回来但要等无穷久） |

- **有限状态链：常返 ⇒ 正常返**；零常返只出现在无限状态链。
- 正常返、零常返也都是类性质。

### 4.4 判定流程（做题按这个顺序走）

```
① 画状态转移图，找闭类（进去出不来）与"有去无回"的箭头
② 有限链：闭类必常返 → 其余（能出去且回不来）瞬时
   有限 + 不可约 → 全部常返 → 全部正常返
③ 无限链：先看是否互通（全常返 or 全瞬时），再算 Σ P_ii^(n)
   · 一维随机游走 p=1/2 → 常返（零常返）；p≠1/2 → 瞬时
   · 返回概率 f_0 = 1-|2p-1| = 2min{p,1-p}
④ 求"是否正常返"：算 m_j 或 π_j（=1/m_j）
```

### 4.5 常返性结论表

| 链 | 结论 |
|---|---|
| 有限不可约 | 全常返、全正常返，$\pi$ 存在唯一 |
| 有限、有闭类 | 闭类内常返正常返；能逃出且回不来的状态瞬时 |
| 一维对称随机游走（$p=1/2$） | 常返，**零常返**（$m_0=\infty$），$\pi_j=0$ |
| 一维非对称（$p\ne1/2$） | 瞬时，$f_0=1-\lvert 2p-1\rvert=2\min\{p,1-p\}$ |
| 二维对称随机游走 | 常返（零常返） |
| 三维及以上对称 | 瞬时（三维返不回原点的概率约 $2/3$） |
| 分支过程 | 0 常返（吸收）；$j>0$ 全瞬时（$P_0>0$ 时） |

### 4.6 首达概率 $f_{ij}$ 的计算

1. **首步分析**（解方程）：$f_{ij}=P_{ij}+\sum_{k\ne j}P_{ik}f_{kj}$，边界 $f_{jj}=1$、$f_{ij}=0$（$j$ 不可达时）。
2. **用 $s_{ij}$**：$f_{ij}=\dfrac{s_{ij}-\delta_{ij}}{s_{jj}}$（见 §8）。
3. **赌徒破产公式**（有吸收壁的一维游走）：见 §6.4。

## 5　长期比例与平稳分布（最核心的一节）

### 5.1 定义与基本定理

- $\pi_j$ = 长期处于 $j$ 的**时间比例**。
- **Proposition 4.4**：不可约常返链 $\pi_j=\dfrac{1}{m_j}$，且 $j$ 正常返 $\iff\pi_j>0$。
- **Proposition 4.5**：正常返（零常返）是类性质。**有限 + 不可约 ⇒ 全正常返。**
- **平稳概率**：若 $P(X_0=j)=\pi_j$，则对一切 $n$，$P(X_n=j)=\pi_j$（分布不变，但**不独立**）。

### 5.2 求解方程（Theorem 4.1）

$$\boxed{\pi_j=\sum_i\pi_iP_{ij}\ (\forall j),\qquad \pi_j\ge0,\qquad \sum_j\pi_j=1}$$

矩阵形式：$\pi=\pi\mathbf P$（$\pi$ 为**行向量左乘**）。

- 不可约 + 正常返：解**存在且唯一**；解不出（只有全零解）⇒ 瞬时或零常返，$\pi_j=0$。
- 有限不可约链：一定有唯一解。

### 5.3 标准三步法（作业直接照抄）

1. **写** $\mathbf P$（注意行和为 1，$\sum_jP_{ij}^{(n)}$ 同理）。
2. **列** $n$ 个方程 $\pi_j=\sum_i\pi_iP_{ij}$，**删掉任意一个**（不独立），补 $\sum_j\pi_j=1$。
3. **解** 线性方程组（$n$ 元一次），检查 $\pi_j>0$ 且和为 1。

> 技巧：先用 $n-1$ 个平衡方程把各 $\pi_j$ 表成 $\pi_1$ 的倍数（流量法），再用归一化定常数。

### 5.4 长期比例点题结论

| 问题 | 答案 |
|---|---|
| Example 4.23（Gary 心情） | $(21/62,\,23/62,\,18/62)$ |
| Example 4.29（Bonus–Malus，$\lambda=1/2$） | $(0.3692,0.2395,0.2103,0.1809)$ |
| 习题 5 状态（$0\to4$ 型） | $(12,6,4,3,12)/37$ |
| 两状态天气（$P_{00}=\alpha,\ P_{10}=\beta$） | $\pi_0=\dfrac{\beta}{1-\alpha+\beta}$，$\pi_1=\dfrac{1-\alpha}{1-\alpha+\beta}$（$\alpha=\beta=1/2$ 时为 $1/2$） |
| 平均返回时间 | $m_j=1/\pi_j$ |

## 6　平均报酬与几个经典应用模型

### 6.1 平均报酬（Proposition 4.6）

不可约链、$r$ 有界：
$$\boxed{\lim_{N\to\infty}\frac{1}{N}\sum_{n=1}^{N}r(X_n)=\sum_j r(j)\pi_j\quad\text{a.s.}}$$
左边是**时间平均**，右边是**空间平均**（按平稳概率加权）。初始分布无关。

### 6.2 生产系统 up/down（Example 4.26）

- 故障率（up→down 速率）：
$$\text{rate}=\sum_{i\in A}\sum_{j\in A^c}\pi_iP_{ij}$$
- 通用关系：**速率 = 长期占比 ÷ 平均时长**，故
$$\bar U=\frac{\sum_{i\in A}\pi_i}{\text{rate}},\qquad \bar D=\frac{\sum_{i\in A^c}\pi_i}{\text{rate}}$$

### 6.3 PageRank

$$P_{ij}=\frac{1}{\text{网页 }i\text{ 的出链数}}\quad(\text{当 }i\text{ 链到 }j)$$
平稳分布 $\pi$ 即各页 PageRank；实际算法加阻尼因子（以概率 $\varepsilon$ 随机跳转）保证不可约、非周期、解唯一。

### 6.4 赌徒破产（带吸收壁的随机游走）

起始资本 $i$、总资本 $N$、每局赢的概率 $p$、$q=1-p$：

$$\boxed{P(\text{达到 }N\text{ 而非破产})=
\begin{cases}
\dfrac{1-(q/p)^i}{1-(q/p)^N}, & p\ne q\\[6pt]
\dfrac{i}{N}, & p=q=\frac12
\end{cases}}$$

- 对称情形（$p=1/2$）：公平游戏，胜率 = 资本占比。
- $p>q$ 时双方资本同比扩大，强者胜率上升（$0.87\to0.98$）。
- 药物检验（Example 4.31）：每对病人只有一人治愈时走 $\pm1$，条件概率
  $$p=\frac{P_1(1-P_2)}{P_1(1-P_2)+P_2(1-P_1)}$$
  于是"断言正确"的概率就是带壁 $\pm M$ 的赌徒破产概率；$M$ 越大两类错误越小、样本越多。

## 7　极限概率与周期性

| 概念 | 定义 | 要点 |
|---|---|---|
| 极限概率 $\alpha_j$ | $\lim_{n\to\infty}P\{X_n=j\}$ | 逐项极限，可能不存在 |
| 长期比例 $\pi_j$ | 时间平均占比 | Cesàro 平均，只要不可约常返就存在 |
| 周期 $d$ | 从 $i$ 可返回的步数的 gcd | 不可约链所有状态周期相同 |
| 非周期 | $d=1$ | 存在互质步数可返回；若 $P_{ii}>0$ 则必非周期 |

**核心结论**

- 不可约 + **非周期** ⇒ 极限概率存在且 $\alpha_j=\pi_j$，**与初始状态无关**（$\mathbf P^n$ 各行趋于同一个 $\pi$）。
- 不可约 + **周期** ⇒ 极限概率可能不存在，但 $\pi_j$ 仍存在。
- 判非周期：找能回到 $i$ 的两条长度互质的路径（如 2 步和 3 步）。

**典型例**：$\mathbf P=\begin{pmatrix}0&1\\1&0\end{pmatrix}$ 周期 $2$，$\lim P(X_n=j)$ 振荡；天气链 $\mathbf P^{2},\mathbf P^{4},\mathbf P^{8}\to$ 两行相同 $=(4/7,3/7)$。

## 8　瞬时状态中的期望停留时间（$s_{ij}$）

只对**有限链**、把常返态（吸收态）单独拎出来，$T=\{1,\dots,t\}$ 为瞬时状态集合。

$$\boxed{\mathbf S=(\mathbf I-\mathbf P_T)^{-1}=\mathbf I+\mathbf P_T+\mathbf P_T^2+\cdots},\qquad s_{ij}=(\mathbf S)_{ij}$$

- $s_{ij}$ = 从 $i$ 出发、进入常返态之前，停留在 $j$ 的**期望期数**（可 $>1$，不是概率）。
- 递推：$s_{ij}=\delta_{ij}+\sum_{k=1}^{t}P_{ik}s_{kj}$。
- $\mathbf P_T$ 的**行和 $<1$**（缺的概率流向吸收态）。

**首达概率（进入 $j$ 的概率）**

$$\boxed{f_{ij}=\frac{s_{ij}-\delta_{ij}}{s_{jj}}}\qquad\text{（由 }s_{ij}=\delta_{ij}+f_{ij}s_{jj}\text{）}$$

**顺带两个常用量**（由 $\mathbf S$ 直接读）

- 期望吸收时间：$E[\text{吸收时间}\mid X_0=i]=\sum_{j\in T}s_{ij}$（$\mathbf S$ 第 $i$ 行之和）。
- 吸收概率：给定吸收后具体进哪个常返类，用首步分析解 $h_i=\sum_jP_{ij}h_j$，吸收态处 $h=1$（或 $0$）。

**算例（Example 4.32/4.33，$p=0.4,K=7$）**：$s_{3,5}=0.9228$，$s_{3,2}=2.3677$，$f_{3,1}=1.4206/1.6149=0.8797$。

> 计算提示：手算时用 $(\mathbf I-\mathbf P_T)\mathbf S=\mathbf I$ 逐列解方程，比直接求逆快。

## 9　分支过程（Branching Process）

**模型**：每个个体独立产生 $j$ 个后代（概率 $P_j$），$X_n$=第 $n$ 代个体数，$X_0=1$。设 $P_0>0$。

**后代分布**：$\mu=\sum_j jP_j$，$\sigma^2=\sum_j(j-\mu)^2P_j$。生成函数 $g(s)=\sum_jP_js^j$。

| 量 | 公式 |
|---|---|
| $E[X_n]$ | $\mu^n$ |
| $Var(X_n)$ | $\sigma^2\mu^{n-1}\dfrac{1-\mu^n}{1-\mu}$（$\mu\ne1$）；$n\sigma^2$（$\mu=1$） |
| 灭绝概率 $\pi_0$ | $\mu\le1$ 时 $\pi_0=1$；$\mu>1$ 时 $\pi_0$ 为 $s=g(s)$ 在 $[0,1)$ 的**最小正根** |

- 状态 0 吸收且常返；$j>0$ 全瞬时（有正概率 $P_0^i$ 全部绝后）。
- $\mu>1$ 时"平均增长"与"正概率灭绝"并存：$0<\pi_0<1$。
- 解 $\pi_0$：先试 $g(s)=s$ 的根（$s=1$ 恒为根），取 $[0,1)$ 内最小者；常用二次方程手解。

## 10　时间可逆马尔可夫链

**设定**：平稳遍历链（不可约 + 非周期 + 正常返），平稳概率 $\pi$。

| 概念 | 公式 |
|---|---|
| 倒链转移 | $\boxed{Q_{ij}=\dfrac{\pi_jP_{ji}}{\pi_i}}$ |
| 时间可逆（细致平衡） | $\boxed{\pi_iP_{ij}=\pi_jP_{ji}\ \ \forall i,j}$ |
| 判定（充分条件） | 存在非负 $x$ 使 $x_iP_{ij}=x_jP_{ji}$、$\sum x_i=1$ ⇒ 可逆，且 $x=\pi$ |
| 判定（Theorem 4.2） | 在 $P_{ij}=0\Leftrightarrow P_{ji}=0$ 下：可逆 ⇔ 任意闭合路径概率 = 逆路径概率 |
| 求 $\pi$（不可逆也行） | 猜出倒链 $\mathbf Q$，用 $\pi_iP_{ij}=\pi_jQ_{ji}$ 反解（Prop 4.9） |

**必须记住的三句话**

1. **细致平衡 ⇒ 全局平衡**（对 $i$ 求和即得），**反之不成立**：可逆比平稳更强。
2. 细致平衡可能**无解**（此时链不可逆），但平稳分布仍可能存在——两者不是一回事。
3. 判可逆**不要**硬解细致平衡：先看结构（最近邻、无向图、闭合路径两侧对称）。

**常用结论**

| 模型 | 结论 |
|---|---|
| 有限状态、相邻转移（birth–death） | 必然可逆；$\pi_i\alpha_i=\pi_{i+1}(1-\alpha_{i+1})$ |
| 无向加权连通图上随机游走 | 可逆，$\pi_i\propto\sum_jw_{ij}$（节点加权度） |
| "向前移一位"链表 | 可逆（数每个元素前移/后移次数） |
| "移到最前"（move-to-front）链表 | **一般不可逆** |
| 灯泡寿命（Example 4.40） | $\pi_i=\dfrac{P\{L\ge i\}}{E[L]}$ |

## 11　马尔可夫决策过程（MDP）

### 11.1 模型要素

- 状态 $1..M$、行动 $a\in A$、转移 $P_{ij}(a)$、报酬 $R(i,a)$。
- 策略 $\beta=\{\beta_i(a)\}$：$\beta_i(a)\ge0$，$\sum_a\beta_i(a)=1$（只依赖当前状态，可随机化）。
- 诱导链：$P_{ij}(\beta)=\sum_aP_{ij}(a)\beta_i(a)$。**假设**：对任意 $\beta$ 诱导链遍历。

### 11.2 稳态联合概率 $\pi_{ia}$

$$\pi_{ia}=\lim_{n\to\infty}P_\beta\{X_n=i,a_n=a\}$$
必须满足 (i) $\pi_{ia}\ge0$；(ii) $\sum_{i,a}\pi_{ia}=1$；(iii) $\sum_a\pi_{ja}=\sum_i\sum_a\pi_{ia}P_{ij}(a)$，$\forall j$。

**反向**：任给满足 (i)–(iii) 的 $\pi_{ia}$，存在策略 $\beta_i(a)=\dfrac{\pi_{ia}}{\sum_a\pi_{ia}}$ 使其成为稳态概率。

### 11.3 最优平均报酬 = 线性规划

$$\max_{\pi}\ \sum_{i}\sum_{a}\pi_{ia}R(i,a)\quad\text{s.t. (i)(ii)(iii)}$$

- 解出 $\pi^*$ 后，最优策略 $\beta_i^*(a)=\pi_{ia}^*/\sum_a\pi_{ia}^*$。
- **最优策略总可取为非随机化**（每个状态至多一个 $a$ 使 $\pi_{ia}^*>0$）。
- 优点：可加线性约束（如"处于状态 1 的时间比例 $\le\alpha$"）。

## 12　隐马尔可夫链（HMM）

### 12.1 模型

- 底层链 $\{X_n\}$（不可观测，$P_{ij}$，初始 $p_i$）；信号 $S_n$ 由 $p(s\mid j)=P\{S_n=s\mid X_n=j\}$ 独立发出。
- 记 $\mathbf s_n=(s_1,\dots,s_n)$。$\{S_n\}$ **不是**马尔可夫链；但给定 $X_n$ 后未来与过去条件独立。

### 12.2 核心量

| 量 | 定义 / 递推 |
|---|---|
| 前向量 | $F_n(j)=P\{\mathbf S_n=\mathbf s_n,X_n=j\}$ |
| 初始 | $F_1(i)=p_i\,p(s_1\mid i)$ |
| 前向递推 | $\boxed{F_n(j)=p(s_n\mid j)\sum_iF_{n-1}(i)P_{ij}}$ |
| 滤波（当前状态概率） | $P\{X_n=j\mid\mathbf s_n\}=\dfrac{F_n(j)}{\sum_iF_n(i)}$ |
| 信号序列概率（前向） | $P\{\mathbf S_n=\mathbf s_n\}=\sum_iF_n(i)$ |
| 后向量 | $B_k(i)=P\{S_{k+1}=s_{k+1},\dots,S_n=s_n\mid X_k=i\}$ |
| 后向递推 | $B_k(i)=\sum_jP_{ij}p(s_{k+1}\mid j)B_{k+1}(j)$，$B_{n-1}(i)=\sum_jP_{ij}p(s_n\mid j)$ |
| 并行恒等式 | $P\{\mathbf S_n=\mathbf s_n\}=\sum_jF_k(j)B_k(j)$（任意 $k$） |
| 逐点最优预测 | $\hat X_k=\arg\max_jF_k(j)B_k(j)$ |
| Viterbi | $V_k(j)=p(s_k\mid j)\max_i[P_{ij}V_{k-1}(i)]$，$V_1(j)=p_jp(s_1\mid j)$，末尾回溯 |

- 前向算法复杂度 $O(nN^2)$（$N$ 为状态数），枚举法 $N^n$。
- **逐点最优**：允许序列出现不可能的转移；**Viterbi**：强制整条路径可行。

### 12.3 例题答案（Example 4.45，$\mathbf s_3=(a,u,a)$）

| 问 | 答案 |
|---|---|
| (a) $P(X_3=1\mid\mathbf s_3)$ | $0.364$ |
| (b) $P(X_4=1\mid\mathbf s_3)$ | $0.3276$ |
| (c) 第 4 件合格概率 | $0.9698$ |

| 用途 | 公式 |

| 有限不可约 | 全正常返，$\pi$ 存在唯一 |
| 极限概率 | 不可约非周期时 $\alpha_j=\pi_j$ |

| 倒链 | $Q_{ij}=\pi_jP_{ji}/\pi_i$ |
| 细致平衡 | $\pi_iP_{ij}=\pi_jP_{ji}$ |
| HMM | $F_n(j)=p(s_n\mid j)\sum_iF_{n-1}(i)P_{ij}$；$P(X_n=j\mid\mathbf s_n)=F_n(j)/\sum_iF_n(i)$ |

### 13.1 第 4 章易错点速查

1. 行和为 1，不是列和。
2. $P_{ij}^{(n)}$ 是"恰好 $n$ 步"，不是首达。
3. 不可约 ⇏ 常返（要"有限"）；常返 ⇏ 正常返。
4. 平稳方程是 $\pi=\pi\mathbf P$（行向量），不是 $\mathbf P\pi=\pi$。
5. 平稳 ≠ 独立；长期比例 ≠ 极限概率（周期链）。
6. 细致平衡比全局平衡强；解不出细致平衡不等于没有平稳分布。
7. $s_{ij}$ 是期望次数（可 >1），$f_{ij}$ 才是概率。
8. 最优策略不必随机化。
9. HMM 中滤波要归一化，$F_n$ 是联合概率。

## 14　指数分布（一切的地基）

### 14.1 基本量

$$f(x)=\lambda e^{-\lambda x},\quad F(x)=1-e^{-\lambda x},\quad \bar F(x)=e^{-\lambda x}\ (x\ge0)$$
$$\boxed{E[X]=\frac1\lambda,\qquad Var(X)=\frac{1}{\lambda^2}}$$

> $\lambda$ 是**速率**（单位时间事件数），不是平均时间。$P(X>t)=e^{-\lambda t}$。

### 14.2 无记忆性

$$\boxed{P\{X>s+t\mid X>t\}=P\{X>s\}=e^{-\lambda s}}$$

- 指数分布是**唯一**具有无记忆性的连续分布（离散对应物：几何分布）。
- 含义：已等待的 $t$ 作废，剩余等待时间与原分布同分布。
- 常见错算：$P(X>15\mid X>10)=e^{-5\lambda}$，**不是** $e^{-15\lambda}$。

### 14.3 失效率

$$r(t)=\frac{f(t)}{1-F(t)},\qquad P\{t<X<t+h\mid X>t\}\approx r(t)h$$
- 指数分布：$r(t)\equiv\lambda$（常数，正是无记忆性）。
- $r$ 递增 = 越老越易坏；递减 = 越老越耐用。

### 14.4 和、最小值、比较（必背三条）

| 命题 | 结论 |
|---|---|
| $n$ 个独立 $\mathrm{Exp}(\lambda)$ 之和 | $\mathrm{Gamma}(n,\lambda)$，密度 $\lambda e^{-\lambda t}\dfrac{(\lambda t)^{n-1}}{(n-1)!}$，均值 $n/\lambda$ |
| $X_i\sim\mathrm{Exp}(\lambda_i)$ 独立的最小值 | $\min_iX_i\sim\mathrm{Exp}\left(\sum_i\lambda_i\right)$ |
| 谁取到最小 | $P\{\min=X_i\}=\dfrac{\lambda_i}{\sum_j\lambda_j}$ |
| 两个指数比较 | $P\{X_1<X_2\}=\dfrac{\lambda_1}{\lambda_1+\lambda_2}$ |
| 最小值与秩次 | **相互独立**（"有多大"与"是谁"无关） |

### 14.5 指数分布的用法模板

| 题型 | 做法 |
|---|---|
| 截尾 $Y=(X-a)^+$ | 令 $I=\mathbf1_{\{X>a\}}$，用无记忆性：$E[Y\mid I=1]=E[X]$，再用条件期望/方差公式 |
| 多个指数时钟竞速 | 等待最早响铃 $\sim\mathrm{Exp}(\sum\lambda_i)$，期望 $1/\sum\lambda_i$ |
| "由谁服务" | 概率 $\lambda_i/\sum\lambda_j$，且与服务时间独立 |
| 贪心/序贯选择 | 第 $k$ 步最小值 $\sim\mathrm{Exp}(\text{剩余个数})$，期望增量 $1/(\text{剩余个数})$ |

**例 5.8（邮局）**：$E[T]=\dfrac{1}{\lambda_1+\lambda_2}+\dfrac{\lambda_1}{\lambda_1+\lambda_2}\cdot\dfrac1{\lambda_1}+\dfrac{\lambda_2}{\lambda_1+\lambda_2}\cdot\dfrac1{\lambda_2}=\dfrac{3}{\lambda_1+\lambda_2}$。

**例 5.4（免赔额）**：$E[Y]=1000e^{-0.4}\approx670.32$，$SD\approx944.09$。

**例 5.7（贪心指派）**：两种贪心期望总费用相同，$=\sum_{i=1}^n1/i$。

## 15　计数过程

**定义**：$N(t)$ = 到 $t$ 为止的事件总数，满足
1. $N(t)\ge0$；2. 取整数值；3. $s<t\Rightarrow N(s)\le N(t)$；4. $N(t)-N(s)$ = 区间 $(s,t]$ 内事件数。

**两个增量假设（互不蕴含！）**

| 假设 | 含义 | 被什么破坏 |
|---|---|---|
| 独立增量 | 互不相交区间内的事件数相互独立 | "热手效应"等有记忆的现象 |
| 平稳增量 | 区间内事件数的分布只依赖**长度** | 高峰/低谷时段 |

## 16　泊松过程的定义与等价面貌

### 16.1 $o(h)$ 记号

$$f(h)=o(h)\iff\lim_{h\to0}\frac{f(h)}{h}=0$$
- $h^2$ 是；$h$ 不是；有限个 $o(h)$ 的线性组合仍是 $o(h)$。

### 16.2 公理（Definition 5.2）

速率 $\lambda>0$ 的泊松过程 $\{N(t),t\ge0\}$ 满足
1. $N(0)=0$；
2. **独立增量**；
3. $P\{N(t+h)-N(t)=1\}=\lambda h+o(h)$；
4. $P\{N(t+h)-N(t)\ge2\}=o(h)$。

> 公理 (iii)(iv) 中概率不依赖 $t$，已隐含**平稳性**；平稳增量是推论，不必另设。

### 16.3 三个等价面貌（做题时自由切换）

| 视角 | 内容 | 适合问 |
|---|---|---|
| **计数视角** | 区间内事件数 $\sim\mathrm{Poisson}(\lambda\times\text{长度})$，独立增量 | "某段时间内发生几次""至少一次" |
| **间隔视角** | $T_1,T_2,\dots$ **独立同分布** $\mathrm{Exp}(\lambda)$ | "第 $n$ 次何时发生""间隔超过…" |
| **条件均匀视角** | 给定 $N(t)=n$，到达时刻 = $n$ 个 $U(0,t)$ 的次序统计量 | "已知共 $n$ 次，位置/落入子区间的个数" |

### 16.4 重新计时（Lemma 5.1）

对任意 $s$，$N_s(t)=N(s+t)-N(s)$ 仍是同速率泊松过程。
> 推论：任何时刻"从现在重新开始"，历史作废。这是指数无记忆性的过程版。

## 17　间隔时间、到达时间与 $N(t)$

$$\boxed{T_1,T_2,\dots\ \text{i.i.d.}\ \mathrm{Exp}(\lambda)},\qquad \boxed{S_n=\sum_{i=1}^nT_i\sim\mathrm{Gamma}(n,\lambda)},\qquad E[S_n]=\frac n\lambda$$

$$\boxed{P\{N(t)=n\}=e^{-\lambda t}\frac{(\lambda t)^n}{n!}},\qquad E[N(t)]=Var(N(t))=\lambda t$$

| 易混对 | 区别 |
|---|---|
| $S_n$ vs $T_n$ | $S_n$ 是**第 $n$ 次到达的时刻**（Gamma，均值 $n/\lambda$）；$T_n$ 是**第 $n-1$ 到第 $n$ 次的间隔**（Exp，均值 $1/\lambda$） |
| 到达时刻之间 | $S_1<\cdots<S_n$ **不独立**（递增）；独立的是 $T_n$。只有在"给定 $N(t)=n$、无序看"时才独立均匀 |
| 泊松过程 vs 泊松分布 | 过程是整个 $\{N(t)\}$；分布是固定 $t$ 的 $N(t)\sim\mathrm{Pois}(\lambda t)$ |
| 泊松 vs 二项 | 泊松是二项分布的极限（区间细分），故 $N(t)$ 边际为泊松 |

**算例**：移民速率 $\lambda$，第 10 位期望 $\dfrac{10}{\lambda}$；第 10 与 11 位间隔 $>2$ 的概率 $e^{-2\lambda}$；两个服务台都忙时下一系统事件等待 $\sim\mathrm{Exp}(\lambda+2\mu)$，期望 $\dfrac{1}{\lambda+2\mu}$。

## 18　分裂（thinning）与叠加（superposition）

### 18.1 Proposition 5.5（分裂，常数概率）

每个事件独立地以**常数** $p$ 标为 I 型、$1-p$ 标为 II 型，则
$$\boxed{\{N_1(t)\}\sim\text{速率 }\lambda p,\qquad \{N_2(t)\}\sim\text{速率 }\lambda(1-p),\qquad\text{且二者独立}}$$

- 两件事同时成立才算完整：**每个分量仍是泊松过程** + **分量相互独立**。
- 直觉反例澄清：虽然 $N=N_1+N_2$，$N_1$ 与 $N_2$ 仍**独立**（不相关）。
- 可推广到 $k$ 类：$N_i(t)\sim\mathrm{Poisson}(\lambda p_it)$ 且相互独立。

### 18.2 叠加

两个**独立**泊松过程合并 ⇒ 仍是泊松过程，速率 $\lambda_1+\lambda_2$；且每个合并事件来自过程 1 的概率
$$\frac{\lambda_1}{\lambda_1+\lambda_2}$$
> "叠加"与"分裂"是一体两面，这是解决"两个过程谁先到"问题的钥匙。

### 18.3 泊松世界的两条封闭性

| 运算 | 结论 |
|---|---|
| 分裂 | 独立泊松个体按概率分类 ⇒ 各类独立泊松 |
| 叠加 | 独立泊松之和 ⇒ 泊松（速率相加） |

> 凡是"随机个个体 + 每个个体独立地落入某类"的模型，先分裂再叠加，通常直接读出答案。

### 18.4 例题结论

- **Example 5.14**：二月（4 周）无英裔移民，$P=e^{-10/3}\approx0.0357$（参数 $4\cdot10\cdot\frac1{12}$）。
- **Example 5.16**：初始各状态人数独立泊松 $\lambda_i$，$n$ 步后各状态人数仍**相互独立**，
  $$\sum_iN_j(i)\sim\mathrm{Poisson}\left(\sum_i\lambda_iP_{ij}^n\right)$$
  注意用 **$n$ 步**转移概率；总人数随机 ⇒ 独立泊松（不是多项分布）。
- **Example 5.15**（最优卖价）：可接受报价速率 $\lambda\bar F(y)$，等待 $\sim\mathrm{Exp}(\lambda\bar F(y))$，
  $$\boxed{\int_{y^*}^\infty(x-y^*)f(x)\,dx=\frac{c}{\lambda}},\qquad \boxed{E[R(y^*)]=y^*}$$
  最优门槛 = 最大期望净收益。

## 19　两个泊松过程的竞赛

设两独立泊松过程速率 $\lambda_1,\lambda_2$，$p=\dfrac{\lambda_1}{\lambda_1+\lambda_2}$：

$$\boxed{P\{S_n^{(1)}<S_m^{(2)}\}=\sum_{k=n}^{n+m-1}\binom{n+m-1}{k}p^{k}(1-p)^{n+m-1-k}}$$

- 推导：合并成速率为 $\lambda_1+\lambda_2$ 的过程，每次事件"贴上标签"独立地以概率 $p$ 归过程 1。于是问题等价于**抛硬币，正面先累计到 $n$ 个**。
- **上限是 $n+m-1$**：到那时胜负必已判定（抽屉原理），不必加到 $\infty$。
- 特例：$m=1\Rightarrow p^n$；$n=m=1\Rightarrow p$。
- 互补：$P\{S_n^{(1)}<S_m^{(2)}\}+P\{S_m^{(2)}<S_n^{(1)}\}=1$（对换 $\lambda$、$n,m$ 即可）。
- 这正是负二项（Pascal）分布的尾概率。

**数值核查**：$\lambda_1=2,\lambda_2=3,n=2,m=3$，$p=0.4$，$P=0.5248$。

## 20　到达时刻的条件分布（高频考点）

### 20.1 单个事件

$$P\{S_1<s\mid N(t)=1\}=\frac st\quad\Longrightarrow\quad S_1\mid N(t)=1\sim\mathrm{Uniform}(0,t)$$
> 与 $\lambda$ 无关。

### 20.2 Theorem 5.2（给定总数）

给定 $N(t)=n$，$f(s_1,\dots,s_n\mid n)=\dfrac{n!}{t^n}$（$0<s_1<\cdots<s_n<t$）。

即：$S_1,\dots,S_n$ 与 **$n$ 个 i.i.d. $U(0,t)$ 的次序统计量**同分布。

### 20.3 "独立"的准确含义（最易错）

| 看法 | 结论 |
|---|---|
| **无序**看（$U_1,\dots,U_n$） | 相互**独立**，均 $U(0,t)$ |
| **有序**看（$S_1<\cdots<S_n$） | 次序统计量，**不独立** |

两者联合密度同为 $n!/t^n$，但定义域不同：立方体 $\{0<u_i<t\}$ vs 单纯形 $\{0<s_1<\cdots<s_n<t\}$。

### 20.4 三条必背推论（给定 $N(t)=n$）

| 推论 | 公式 |
|---|---|
| 落入子区间 $A$ 的个数 | $\mathrm{Binomial}\left(n,\ \lvert A\rvert/t\right)$ |
| 第 $k$ 个到达时刻 | $\dfrac{S_k}{t}\sim\mathrm{Beta}(k,\,n-k+1)$，$\boxed{E[S_k]=\dfrac{kt}{n+1}}$ |
| 对到达时刻求和的期望 | $E\left[\sum_{i=1}^ng(S_i)\right]=n\cdot\dfrac1t\displaystyle\int_0^tg(x)\,dx$ |

> "去排序"技巧：$\sum_ig(S_{(i)})=\sum_ig(U_i)$，排序不改变一组数的和。

### 20.5 Proposition 5.7（给定第 $n$ 次时刻）

给定 $S_n=t$：$\{S_1,\dots,S_{n-1}\}$ = **$n-1$ 个** $U(0,t)$ 的次序统计量。

| | 条件 | 结论 |
|---|---|---|
| Theorem 5.2 | $N(t)=n$（固定区间总数） | $n$ 个 $U(0,t)$ 的次序统计量 |
| Proposition 5.7 | $S_n=t$（固定第 $n$ 次时刻） | $n-1$ 个 $U(0,t)$ 的次序统计量 |

### 20.6 两个算例

- **Example 5.22（最优发货）**：$W(t)=\frac{\lambda t^2}{2}+\frac{\lambda(T-t)^2}{2}$ ⇒ $t^*=T/2$，最小值 $\lambda T^2/4$。
- **Example 5.21（贴现索赔）**：
  $$E[D(t)]=\frac{\lambda\mu}{\alpha}\left(1-e^{-\alpha t}\right)$$
  自检：$\alpha\to0$ 时 $\to\lambda\mu t$（次数 × 平均金额）。

## 21　泊松过程的抽样与 $M/G/\infty$

### 21.1 Proposition 5.6（时变分类概率）

事件发生在时刻 $y$ 时以概率 $P_i(y)$ 归为 $i$ 型（$\sum_iP_i(y)=1$），则
$$\boxed{N_i(t)\ \text{相互独立},\qquad E[N_i(t)]=\lambda\int_0^tP_i(s)\,ds}$$

**关键辨析**

| 分类概率 | 结论 |
|---|---|
| 常数 $p_i$ | 分量是**泊松过程**（且增量独立）——Prop 5.5 |
| 时变 $P_i(y)$ | 只有**固定 $t$ 的分布**是泊松；整条过程**不是**泊松过程 |

> 一句话：**常数 $p$ 给"过程"，时变 $P_i(y)$ 只给"固定时刻的分布"。**

**证明骨架**：$N(t)\sim\mathrm{Poisson}(\lambda t)$ + 给定总数下的标签服**多项分布**（单事件概率 $P_i=\frac1t\int_0^tP_i(s)ds$）⇒ 相乘因子化。

### 21.2 $M/G/\infty$（Example 5.18）

顾客按速率 $\lambda$ 到达、立即被服务（无穷多服务台，永不排队），服务时间 $\sim G$：

$$\boxed{X(t)\sim\mathrm{Poisson}\left(\lambda\int_0^tG(y)dy\right)},\qquad \boxed{Y(t)\sim\mathrm{Poisson}\left(\lambda\int_0^t\bar G(y)dy\right)}$$

- $X(t)$（已完成）与 $Y(t)$（正在服务）**相互独立**。
- $Y(t)$ 是"在 $t$ 时系统中人数"，$X(t)$ 是"到 $t$ 已完成服务的人数"。
- 独立性、泊松性都依赖**无穷多服务台**；有限台时二者都不成立。

**两时刻协方差**：把到达分四类，公共部分 $N_2$ = "两时刻都在系统中的人数"，
$$\boxed{\mathrm{Cov}[Y(t),Y(t+s)]=\mathrm{Var}(N_2)=\lambda\int_0^t\bar G(u+s)\,du}$$
联合分布：$P\{Y(t)=i,Y(t+s)=j\}=\sum_{\ell=0}^{\min(i,j)}P\{N_2=\ell\}P\{N_1=i-\ell\}P\{N_3=j-\ell\}$。

### 21.3 Example 5.20（HIV 无症状感染者估计）

$N_1(t)$ 可观测、$N_2(t)$ 不可观测，$\lambda$ 未知：
$$\hat\lambda=\frac{n_1}{\int_0^tG(y)dy},\qquad \boxed{\widehat{N_2(t)}=n_1\cdot\frac{\int_0^t\bar G(y)dy}{\int_0^tG(y)dy}}$$

指数潜伏期（均值 $\mu$）：$\widehat{N_2(t)}=n_1\dfrac{\mu(1-e^{-t/\mu})}{t-\mu(1-e^{-t/\mu})}$；$t=16,\mu=10,n_1=220$ ⇒ $218.96$。

> 陷阱：把 $G(t-s)$ 换成 $G(t)$ 会得到约 $55.6$，严重低估。模型最强假设是 **$\lambda$ 恒定**。

## 22　第 5 章公式总卡

| 用途 | 公式 |
|---|---|
| 指数分布 | $f=\lambda e^{-\lambda x}$，$E=1/\lambda$，$Var=1/\lambda^2$ |
| 无记忆 | $P(X>s+t\mid X>t)=e^{-\lambda s}$ |
| 失效率 | $r(t)=f/(1-F)$，指数分布 $r\equiv\lambda$ |
| 指数和 | $\sum_{i=1}^nX_i\sim\mathrm{Gamma}(n,\lambda)$，均值 $n/\lambda$ |
| 最小值 | $\min_iX_i\sim\mathrm{Exp}(\sum\lambda_i)$；$P(\min=X_i)=\lambda_i/\sum\lambda_j$ |
| 两指数比较 | $P(X_1<X_2)=\lambda_1/(\lambda_1+\lambda_2)$ |
| 泊松公理 | $N(0)=0$；独立增量；$P(1)=\lambda h+o(h)$；$P(\ge2)=o(h)$ |
| 计数分布 | $N(t)\sim\mathrm{Pois}(\lambda t)$，$E=Var=\lambda t$ |
| 间隔 | $T_n$ i.i.d. $\mathrm{Exp}(\lambda)$ |
| 到达时刻 | $S_n\sim\mathrm{Gamma}(n,\lambda)$，$E=n/\lambda$ |
| 重新计时 | $N(s+t)-N(s)$ 仍是同速率泊松过程 |
| 分裂 | $N_1\sim\mathrm{Pois}(\lambda pt)$、$N_2\sim\mathrm{Pois}(\lambda(1-p)t)$，**独立** |
| 叠加 | 速率 $\lambda_1+\lambda_2$；标签概率 $\lambda_1/(\lambda_1+\lambda_2)$ |
| 两过程竞赛 | $\sum_{k=n}^{n+m-1}\binom{n+m-1}{k}p^k(1-p)^{n+m-1-k}$ |
| 条件密度 | $f(s_1,\dots,s_n\mid n)=n!/t^n$ |
| 条件二项 | 落入 $A$ 的个数 $\sim\mathrm{Bin}(n,\lvert A\rvert/t)$ |
| 条件 Beta | $S_k/t\sim\mathrm{Beta}(k,n-k+1)$，$E[S_k]=kt/(n+1)$ |
| 去排序 | $E[\sum_ig(S_i)]=n\cdot\frac1t\int_0^tg$ |
| 抽样 | $N_i(t)$ 独立 $\mathrm{Pois}(\lambda\int_0^tP_i)$（仅固定 $t$） |
| $M/G/\infty$ | $X,Y$ 独立泊松，均值 $\lambda\int_0^tG$、$\lambda\int_0^t\bar G$ |
| 两时刻协方差 | $\lambda\int_0^t\bar G(u+s)du$ |
| 贴现总额 | $\lambda\mu(1-e^{-\alpha t})/\alpha$ |

### 22.1 第 5 章易错点速查

1. $\lambda$ 是速率，均值是 $1/\lambda$；算等待不要用 $\lambda$ 乘。
2. 条件概率分母是 $P(X>t)$，不是 $P(X>s)$。
3. $S_n$ 是 Gamma、$T_n$ 是 Exp；到达时刻**不独立**，间隔才独立。
4. $P(N(t)=0)=e^{-\lambda t}$，不是 $1-e^{-\lambda t}$。
5. 泊松公理不需要另设平稳增量。
6. 分裂：两分量**独立**（尽管和为 $N$）；概率必须恒定。
7. 时变分类 ⇒ 只有固定 $t$ 的分布，整条过程不是泊松。
8. 给定 $N(t)=n$：无序才独立，有序不独立。
9. Beta 第二参数是 $n-k+1$。
10. 两过程竞赛求和上限 $n+m-1$。

## 24　三个"三分钟自检"清单

**考前 3 分钟 · 第 4 章**

- 转移矩阵：**行**和为 1。
- 有限 + 不可约 ⇒ 全正常返，$\pi$ 唯一。
- 常返 ⇏ 正常返；一维对称 $p=1/2$ 是**零常返**。
- $\pi=\pi\mathbf P$（行向量），删一个方程 + 归一化。
- 周期链：$\pi$ 有、$\alpha$ 无。
- 可逆：细致平衡 ⇒ 全局平衡（反之不成立）。

**考前 3 分钟 · 第 5 章**

- $E[X]=1/\lambda$；$P(X>t)=e^{-\lambda t}$。
- 间隔 i.i.d. Exp；到达时刻 Gamma；$S_n$ 不独立。
- $N(t)\sim\mathrm{Pois}(\lambda t)$，均值 = 方差。
- 分裂：常数 $p$ ⇒ 独立泊松过程；时变 ⇒ 只有固定 $t$ 的分布。
- 给定 $N(t)=n$：无序独立均匀，有序不独立；$E[S_k]=kt/(n+1)$。
- 竞赛：合并成硬币，求和到 $n+m-1$。

**交作业前 1 分钟**

1. 概率是否都落在 $[0,1]$？分布/概率之和是否为 1？
2. 量纲对不对（速率 vs 时间、$\lambda$ vs $1/\lambda$）？
3. 边界情形自检：$p=1/2$、$\alpha\to0$、$t\to0$、$n=1$ 时公式是否退化为已知结果？
4. 矩阵题：行和是否为 1；$\pi$ 是否为行向量左乘。
